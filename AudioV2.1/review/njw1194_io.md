## 0. 結論

| 組 | 入口の C | 出口の C | バスの DC（音声 SET の瞬間の段） | 源の DC | 20 Hz（入口＋出口、最悪） | 端子→石の + 入力の直列 C | 判定 |
|---|---|---|---|---|---|---|---|
| A | なし | なし | チップの出力オフセット（**DS に無い**）がそのまま段になる | 音量の減衰器を通って出力へ。音量を動かすたびに DC が動く | −0.03 dB | 1 | 不可 |
| B | あり | なし | 同上（段の大きさはチップ次第） | 止まる | −0.04 dB（10 µF） | 2 | 実測しだいの控え |
| C | なし | あり | 0 V（100 kΩ で決まる） | バスには出ないが、**音量を段階で絞る間に DC が掃かれて聞こえる** | −0.04 dB（10 µF） | 2 | 不可（源を選ぶ） |
| **D** | **あり** | **あり** | **0 V** | **止まる** | **−0.09 dB（両方 4.7 µF film）／−0.05 dB（10 µF）** | 3（v2 と同じ数） | **推奨** |
| E | あり | バッファ | バッファのオフセット（C を足せば D と同じ） | 止まる | — | 3 以上 | 不要（駆動は足りている） |

- **推奨は D**: 入口にも出口にも結合 C。値は 4.7 µF の film（L/R で 4 個）、DS の応用回路どおりの 10 µF でもよい（有極性なら両側 DC 0 V なので無極性の方が素直〔推論〕）。**出口の C は 0 Ω を載せられる置き場**にして、実測でチップの出力オフセットが十分小さく TSW で動かないと分かれば B へ下げられる形にする
- 理由の核: (1) チップの出力 DC は DS が 0 V と書くだけでオフセットの規定が無い〔DS p3〜p6〕。出口の C があれば `TONE` バスの DC は 100 kΩ（§2-11）だけで 0 V に決まり、§2-10 の「接点の両側が DC 0 V」がチップの個体差に依らず構造で保たれる。(2) 音量の減衰器は入力セレクタの直後の抵抗の分圧で、帰還は DCCAP で DC 利得 1〔DS p8 の応用回路から読む＋推論〕。入口を直結すると源の DC が減衰器に乗り、切替の手順の「音量を段階で絞る／戻す」（§6-2）のたびに DC が階段で動いて、つながったままの経路に出る
- **どの組でも消えないもの**: TSW の切替の段（切替点はチップの中の増幅器の + 入力の前で、C は段の角を通す）。消すのは全リセットの中で書くこと（§1-6 の控え）。入口の結合 C は電源断のクランプの電流を**ほとんど絞らない**（1 kHz で 4.7 µF は 34 Ω）。絞るのは入口の直列抵抗だけ（1 kΩ で最悪 2.4 mA〔計算、源 100 Ω の仮定〕）
- **駆動は問題ない**: 選んだ娘が載った `TONE` バスの負荷は中域で約 41 kΩ・DC で 69 kΩ〔計算〕、容量は 200 pF 以下と見込む〔仮定〕。DS のグラフは約 400 Ω まで振幅が保たれる〔DS p24〕。出口のバッファは要らない
- **波及（要確認）**: 箱の電源が無い間に源が来ると、入力のクランプから ±7 V のレールが押し上げられ、±7 V を作る LDO の OUT–IN の絶対最大（TPS7A49 +0.3 V／TPS7A30 −0.3 V、[../ds_facts/power.md](../ds_facts/power.md)）に触れうる〔推論〕。§1-6 の未決「電源の無いチップの入力に源が来ることを受けるか」は、チップだけでなく LDO の側でも決める（§4.3）

### 1.2 今の図（v2 の回路のまま）

- ライン入力の端子（L / `A_GND` / R の 3 極）→ 2.2 µF → PT2314E → 2.2 µF → `TONE_L/R` 〔図〕
- `TONE_L/R` のネットに載っているのは、トーンチップからの結合 C と 8 ch の入力の結合 C（1 µF film）とスタックのコネクタだけで、**抵抗は 1 本も無い**〔図〕（§2-11 の 100 kΩ はまだ入っていない）
- ch の入力: `TONE` → 1 µF film → 石の + 入力（100 kΩ で `A_GND`）〔図〕。**入力側の TMUX と 220 kΩ はまだ無い**（v2 はブロードキャスト）
- ch の出力: 石 → 47 Ω → 2.2 µF film → 220 kΩ で `A_GND` → 出力の TMUX → 音声リレー → `AMP_SEL`（100 kΩ で `A_GND`、ポット A50k、ADC のタップのバッファ）〔図〕

### 1.3 v2.1 の決定で入る形（DECISIONS から。この評価の前提）

`TONE`（親、100 kΩ で GND、§2-11）→ スタック → 娘の音声リレー（NO＝バス側、COM＝娘側、NC は 10 kΩ で GND、§2-3）→ ch ごとの TMUX7612（§2-8）→ 節（220 kΩ で GND、§2-14）→ ch の入力の結合 C → 石の + 入力（100 kΩ で GND。今の図の形が残る〔仮定〕）。
音声リレーは `TONE_L/R` と `AMP_SEL_L/R` を同じ SET で同時に閉じる（§2-1・§2-6）。切替の手順は「音量を段階で絞る → 全リセット → … → 共通の音声 SET → 音量を段階で戻す」（§6-2）。

## 2. `TONE` バスの負荷と駆動

### 2.1 載るもの（選んだ娘が SET の間）

| もの | 値 | 根拠 |
|---|---|---|
| バスのプルダウン | 100 kΩ | §2-11 |
| 選んだ ch の入力の節 | 220 kΩ（TMUX の Ron 1.1〜1.4 Ω 越し。無視できる） | §2-14、TMUX7612 Ron〔[switch_control.md](../ds_facts/switch_control.md) §1〕 |
| 選んだ ch の入力の結合 C ＋ 石のバイアス | 1 µF ＋ 100 kΩ（中域では 100 kΩ） | 〔図〕〔仮定: v2.1 でも同じ値〕 |
| 娘の NC 10 kΩ | **載らない**（SET 中は NC が開く） | §2-3 |
| 選んでいない娘 | **載らない**。開いた NO 接点の容量 0.4 pF typ 越しに、10 kΩ で GND の節が見えるだけ | AZ850 の開接点間 0.4 pF〔[switch_control.md](../ds_facts/switch_control.md) §2〕 |
| 選んだ娘の中の TMUX | 選んだ 1 本の C(ON) 22 pF ＋ 選んでいない 3 本の CS(OFF) 27 pF ×3（typ、±15 V、VS=0 V） | TMUX7612〔switch_control §1〕 |
| スタックのコネクタ 4 段と配線、親の配線 | 合計 50〜100 pF〔仮定〕 | DS に無い（部品の DS を集めていない） |

- 抵抗性の負荷: DC で 100 k ∥ 220 k = **68.8 kΩ**、中域（1 kHz）で 100 k ∥ 220 k ∥ 100 k ≈ **40.7 kΩ**〔計算〕
- 容量: 約 100 pF（TMUX）＋ 50〜100 pF〔仮定〕 → **200 pF 以下**と見込む。20 kHz で 200 pF は約 40 kΩ〔計算〕
- 全リセットの間（どの娘もつながっていない）: 100 kΩ だけ

### 2.2 駆動に問題が無いか

- 2.3 Vrms（3.25 Vpk、音量 0 dB）を 40.7 kΩ に出す電流は 80 µA pk、容量ぶんを足しても 0.12 mA pk 程度〔計算〕。DS のグラフが振幅を保つ範囲（約 400 Ω まで〔DS p24〕）の 100 倍軽い → **駆動は問題ない**〔推論〕
- 容量負荷での安定: **DS に無い**。出力は 50 Ω を内側に持つエミッタ出力で、帰還はパッドから取る〔DS p6〕。数百 pF で発振する形ではないと見込む〔推論〕が、裏は無い → 出口に直列抵抗の置き場（0 Ω 実装、47〜100 Ω に替えられる）を足すのは安い保険〔推論〕。47 Ω と 200 pF の極は約 17 MHz で音声帯に効かない〔計算〕
- 振幅の天井: 最大出力 3.6 Vrms min は RL=47 kΩ の条件〔DS p3〕。40.7 kΩ はほぼ同じ条件で、ライン入力の上限 2.3 Vrms（§1-5）に対して 3.9 dB の余裕〔計算〕。先に頭を打つのは下流（§1-5）

## 3. 組み合わせの評価

### 3.1 DC

**源の DC**（ライン機器の出力は結合済みが普通だが、保証は無い〔仮定〕。DC 結合の DAC はサーボ付きでも mV 級、壊れた機器や自作機では V 級もありうる〔仮定〕）

- 入口の C なし（A・C）: 源の DC は 200 Ω → 100 kΩ ∥ 25 kΩ（20 kΩ）へ流れ、セレクタの後ろの減衰器に乗る〔DS p6・p8 から読む〕。増幅器の DC 利得は 1（DCCAP）なので、**出力の DC ＝ 源の DC × 減衰器の比**〔推論〕。つまり
  - 音量を 1 段動かすごとに DC が段で動く（源の DC が 10 mV なら、0 dB → Mute の掃引で出力の DC が 10 mV 動く〔計算〕）
  - 切替の手順は「音量を段階で絞る」「段階で戻す」を毎回、**経路がつながったまま**行う（§6-2）。この掃引がそのまま聴こえる経路に出る。出口の C（組 C）は掃引を高域通過で少し丸めるだけで、段の角は通す（τ ≈ 0.3 s 級に対して掃引は同じ桁〔仮定〕）
  - セレクタの Mute（GND へ）も同じ段を作る
- 入口の C あり（B・D）: 源の DC は C で止まる。チップ側の節は内部の 100 kΩ ∥ 25 kΩ で 0 V に決まる〔DS p6〕ので、C の両側の DC は外から決まり浮かない（チップの外に抵抗を足さなくてよい）〔推論〕

**チップの出力の DC**

- 出力の DC 電位は 0 V〔DS p6〕、オフセットの規定は **DS に無い**。DC 利得 1 の形なので、音量の設定では変わらず、増幅器とトーン段のオフセットで決まる〔推論〕。目安は PT2314E の規定の桁（数 mV〜10 mV）〔仮定〕
- 出口の C なし（A・B）: `TONE` バスの DC ＝ チップの出力オフセット。100 kΩ（§2-11）はそれを変えない（出力インピーダンスが低いので）
  - **音声 SET の瞬間の段**: 娘側は NC 10 kΩ で 0 V、バス側はオフセットの分だけ浮いている → 閉じた瞬間にその段が TMUX → ch の入力の結合 C → 石の + 入力に入り、τ ≈ 1 µF × 100 kΩ = 0.1 s で抜ける〔計算〕。`AMP_SEL` 側の接点は同じ SET で同時に閉じる（§2-1・§2-6）ので、この段は ch の利得（2 程度〔仮定〕）を掛けて**そのまま聴こえる経路に出る**。チップの音量の MUTE は DC 利得 1 の形では**このオフセットを消さない**〔推論〕。§2-10 の前提（両側 DC 0 V）が、DS に無い値に依存する
  - TSW でトーン段を通すかどうかでオフセットが変わるなら、バスの DC も TSW の状態で変わる〔推論〕
- 出口の C あり（C・D）: バス側の DC は 100 kΩ で 0 V に決まり、チップのオフセットは C の両端に掛かるだけ → **音声 SET の瞬間の段はチップの個体差・TSW の状態・温度に依らず 0**〔推論〕。§2-10 の前提が構造で保たれる
  - 代わりに、チップの出力の DC が動いたとき（電源投入、TSW、オフセットの温度変化）にバスの DC が戻るまで τ がかかる: 全リセット中（100 kΩ だけ）で 2.2 µF → 0.22 s、4.7 µF → 0.47 s、10 µF → 1.0 s。選んだ娘がつながった間は 68.8 kΩ で 0.15／0.32／0.69 s〔計算〕。効くのは主に電源投入の直後で、チップは常時系統（主電源の間ずっと ±7 V）なので切替ごとには起きない〔推論〕
- 電源投入: チップの立ち上がりで出力がどう動くかは **DS に無い**。DCCAP 100 µF は DC 利得 1 の形なら 0 V 付近から 0 V 付近へ動くだけ〔推論〕。どの組でも、規則①の全リセット（全娘がバスから離れている）の間に済ませ、出口の C があるなら最初の音声 SET の前に 5τ（4.7 µF で約 2.4 s）待つ〔計算〕

**TSW・音量の切替の段**

- TSW の切替点は増幅器の + 入力の前（ワイパ直とトーン段の戻りの間）〔DS p8〕。段の大きさは、2 つの節の DC の差（トーン段のオフセット、**DS に無い**）と切替そのものの注入。音量の MUTE は音楽を消すが、この段は消さない〔推論〕
- 結合 C は段の**角を通す**ので、どの組でも TSW の段は残る。出口の C の有無で変わるのは、段のあとバスの DC が 0 に戻るか（D・C: 戻る）、TSW の状態ごとに別の DC に居座るか（A・B）だけ
- 確実に消すのは、TSW を全リセットの中（全娘がバスから離れている間）で書くこと（§1-6 の控え）。出口の C があれば、書いてから音声 SET までに 5τ 待てばバスは 0 V に戻っている〔推論〕
- 音量の段: 入口の C があれば源の DC は乗らず、DC 利得 1 なので音量の段は音楽の段だけ〔推論〕。入口の C が無いと上の「源の DC」の段が加わる

| D（2.2／2.2 µF、v2 の値） | −0.30 dB | −1.13 dB | −0.37 dB |

- 極が重なる影響は、4.7 µF 以上なら 20 Hz で 0.1 dB 未満〔計算〕。2.2 µF を 2 つ重ねると 20 Hz で 0.3 dB、10 Hz で 1.1 dB で、ここだけは目に見える
- 出口の C が小さいほどバスの整定（§3.1）は速い。4.7 µF が低域（−0.05 dB）と整定（0.3〜0.5 s）の間の置き所〔推論〕

### 3.3 電源断（源が来ていて、チップの ±7 V が無い）

- クランプはパッドの直下で、チップの中にクランプより前の電流制限は無い〔DS p6、verify 行 97・118〕。電流を決めるのは外側だけ
- 2.3 Vrms（3.25 Vpk）の源で、クランプの Vf を 0.6 V〔仮定〕、源の出力インピーダンス Rs〔仮定〕として、ピークの電流〔計算〕:

| Rs | 直列 0 Ω | 直列 1 kΩ | 直列 2.2 kΩ |
|---|---|---|---|
| 47 Ω | 56 mA | 2.5 mA | 1.2 mA |
| 100 Ω | 27 mA | 2.4 mA | 1.2 mA |
| 600 Ω | 4.4 mA | 1.7 mA | 1.0 mA |

- **入口の結合 C はこの電流をほとんど絞らない**: 両極にクランプがあるので C に DC は溜まらず、音声帯では素通し（4.7 µF は 1 kHz で 34 Ω、20 Hz で 1.7 kΩ）〔計算〕。C が効くのは源の DC（DC でクランプを順方向にし続けない）と、20 Hz 付近の電流が少し減ることだけ〔推論〕
- **直列抵抗が効く**: 1 kΩ で 10 分の 1 前後。通常時の代償は平坦な −0.42 dB（RIN 20 kΩ）〜 −0.56 dB（15 kΩ）と、1 kΩ の熱雑音 4.1 nV/√Hz（20 kHz 帯域で約 0.55 µV、DS の TONE=OFF の雑音 1.41 µV は A 特性・Rg=0 なので直接は足せない）〔計算〕
- **レールの押し上げ（波及）**: 正の山は V+ へ、負の山は V−(sub) へ流れ込み、±7 V のレールを押し上げる。行き着く電圧はチップ自身の電流（±1.5 V 付近より下で急に落ち、±0.5〜1 V 付近で 0〔DS p19 のグラフ、ds_facts §1〕）と LDO の帰還の分圧などの負荷との釣り合いで決まり、**1 V 前後に上がりうる**〔推論〕。このとき LDO の IN（箱の ±15 V、電源断で 0 V 付近）に対して OUT が +1 V 級になり、TPS7A49 の OUT–IN +0.3 V、TPS7A30 の OUT–IN −0.3 V の絶対最大〔[power.md](../ds_facts/power.md) §2・§3〕を越えうる〔推論〕。直列抵抗は流れ込む電流を減らすが、電圧の上限を決めるのは負荷との釣り合いなので、これだけで 0.3 V 以下になるとは言えない〔推論〕
- 押し上げられた半端な電源でチップがどう振る舞うか（出力に何か出るか）は **DS に無い**。p11 の「初期状態の異常」はこれに当たると読め、電源投入時の全レジスタの書き直し（§1-6 の 4）で受ける〔推論〕。出力に出たとしても、半端なレールの振幅で、どの組でも結合 C はそれを止めない

### 3.4 部品点数と音

| 組 | 端子から石の + 入力までの直列 C | 増える部品（L/R） | 音への影響〔推論〕 |
|---|---|---|---|
| A | 1（ch の 1 µF film） | 0 | C は最少。ただし DC がチップと源の個体差で決まる |
| B | 2 | 入口 2 | 入口の C は全 ch に共通で乗る |
| C | 2 | 出口 2 | 同上 |
| D | 3 | 4 | **v2 の今の図と同じ数**（2.2 µF 2 段 ＋ ch の 1 µF）。film なら v2 の 2.2 µF の置き換え |
| E | 3 以上 | オペアンプ 1（2 回路）＋電源 | **全 ch に共通のオペアンプが 1 段増える**。装置の目的（石の差を聴く）に対して共通経路の色を足す |

- 電解か film か: DS の応用回路は 10 µF 有極性〔DS p8〕。両側の DC がどちらも 0 V なので有極性の向きに意味が無く、源の DC の極性も分からない〔推論〕。無極性（film、または両極性電解）が素直。聴感の優劣は耳で決める装置（NOW「装置」）なので、この評価では決めない
- 4.7 µF の film は 2.2 µF より大きい。親に置くので娘の外形の制約は受けない〔推論〕

### 3.5 出口のバッファ（E）

- 駆動（§2.2）は 100 倍の余裕があり、要らない〔推論〕
- 入れるなら、バッファ自身のオフセットがバスに乗るので結局 C が要り、D の上にオペアンプが増えるだけ
- 外れる条件: 実物で出口の波形が容量負荷で乱れる（リンギング・発振）とき。そのときもまず出口の直列抵抗の置き場（§2.2）を試す

## 4. 推奨・外れる条件・要実測

### 4.1 推奨

1. **組 D**: 入口の結合 C（端子 → 直列抵抗の置き場 → C → チップ）と、出口の結合 C（チップ → C → `TONE` バス＝100 kΩ の節）。値は 4.7 µF の film（10 µF でもよい）
2. **出口の C は 0 Ω を載せられる置き場**にする（実測で B へ下げる道を残す）
3. 出口に直列抵抗の置き場（0 Ω 実装、47〜100 Ω）— 容量負荷の保険。任意
4. 入口の直列抵抗は §1-6 の決めどおり置き場（0 Ω／1 kΩ）。電源断の電流を絞るのはこれだけなので、**値の判断は §3.3 の表と LDO の OUT–IN（§4.3）を合わせて**
5. 使わない入力（InA2〜4・InB2〜4）の扱いは **DS に無い**。内部の 100 kΩ で DC は 0 V に決まる〔DS p6〕。実装例には 0.47 µF で GND へ落とすものがある〔[njw1194_power_impl.md](njw1194_power_impl.md) §1.2、例〕。どちらでもよいと見るが裏は無い
6. ファームへの含意: 電源投入の後、最初の音声 SET の前にバスの整定を 5τ 待つ（4.7 µF・100 kΩ で約 2.4 s）〔計算〕。TSW を全リセットの中で書く形に下げたときも、書いてから音声 SET まで同じ待ち

理由（要約）: 入口の C は源の DC を減衰器から締め出し、毎回の「段階で絞る／戻す」を DC で汚さない。出口の C は §2-10 の「両側 DC 0 V」を DS に無い値から切り離す。低域の代償は 20 Hz で 0.1 dB 未満、部品は v2 と同じ数。

### 4.2 外れる条件

- **チップの出力オフセットが十分小さく、TSW・温度で動かない**（例えば 1 mV 未満〔仮定: 聴こえない段の目安も未検証〕）と実物で分かれば、出口の C を 0 Ω にして B でよい
- **入口の源が DC 0 V と分かっている**（自分の機器だけを挿す）なら入口の C を外せるが、ライン入力の端子に何が挿さるかは保証できないので勧めない
- 切替の手順が変わり、音量の段階の絞り・戻しを**経路が切れている間だけ**行う形になれば、入口の C の理由の半分（掃引が聴こえる）は消える（源の DC がバスに居座る問題は残る）
- `TONE` バスのプルダウン（100 kΩ）や ch の入力（220 kΩ・1 µF／100 kΩ）の値が変われば、§2・§3.2・整定の τ を計算し直す
- スタックの容量が仮定（200 pF 以下）より大きいと分かれば、§2.2 を見直す（それでも駆動の余裕は大きい）

### 4.3 要実測・要確認

1. **チップの出力 DC オフセット**（TSW=0／1、音量 Mute／0 dB、電源投入直後と温まったあと）— 組 B に下げられるかの判定。DS に無い
2. **TSW の切替の段**（§1-6 の実測項目と同じ）— 出口の C を入れても段の角は通るので、全リセットの中で書くかの判定
3. **電源投入のときの出力の動き**（±7 V の立ち上がりからの波形と、落ち着くまでの時間）— 最初の音声 SET までの待ちの判定。DS に無い
4. **電源断で源が来たときの ±7 V のレールの電圧**（2.3 Vrms・入口の直列 0 Ω／1 kΩ）— LDO の OUT–IN の絶対最大（+0.3 V／−0.3 V）に触れるか。触れるなら、LDO の OUT と IN の間の逆向きのショットキー、±7 V のレールのブリーダ、直列抵抗の増量のどれか〔推論〕。§1-6 の未決「受けるか」はここで決める
5. 出口の波形（容量負荷での安定）— 直列抵抗の置き場を 0 Ω のままでよいか

## 5. DS に無いこと（この評価で効いたもの）

- 出力の DC オフセット（TSW・音量・温度による変化も）
- 結合 C の要否の明文（応用回路に 10 µF が描かれているだけ）
- 最小負荷・出力の最大電流・容量負荷での安定
- 電源投入のときの出力の振る舞い
- 電源が無いときの入力の電流・許される電圧（VIM「V+/V−」と p11 の注記だけ）
- DCCAP の役の文（ピン名 "Switching noise rejection capacitor" と応用回路の接続だけ。DC 利得 1 の読みは推論）
- 使わない入力の扱い
- ZeroCross Detection が何に効くか
