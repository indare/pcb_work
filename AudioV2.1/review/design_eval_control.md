### 1.6 食い違い・足りないもの

1. **出どころ（§0.1 #1）**: 10 本の静的な出力は Pico の空きに入らない（上の表）。[AZB] §0.1 #14 と同じ結論（親に MCP を 1 個）。今の UI の MCP は RESET が `3V3` 直結 [SF pin U1610]（18 番ピン）なので、同じ作りで制御 MCP を置くと **Pico のリセットで出力が戻らない**。RP2350 のリセットで `RAIL_OK` は落ちる（下）ので ASET は娘でゲートされるが、PSET・PRST・ARST は固まる。コイル 1 個を 5 V で連続通電しても AZ850P2-5 の連続定格 10 VDC の内 [sw] §2 なので焼けはしないが、**再起動後に固まった PRST と新しい PSET が重なる**（同じリレーの両コイル）
2. **`MON` の形**: [DEC] §5-2 は「各娘の**分圧した**レールをダイオード OR」、出典の [RDR] §7.3 は「**ダイオードは生のレールの側**、親に分圧を 1 組ずつ」（VF の効きが 6 倍小さい）。どちらかに揃えないと娘・親の図が描けない。**[RDR] の形を推奨**（スタックに約 ±14 V の線が 2 本通るので、ピン配置では論理線の隣に置かない〔推論: 隣と短絡すると 3.3 V の論理へ 14 V〕）
3. **RP2350-E9**（§0.1 #7）: [RP2350 p.588] §9.3 のとおりリセット直後の pad は「出力 Hi-Z・入力無効・プルダウン」で、この状態では E9 は起きない [RP2350 p.1367]（"This doesn't affect the pull-down behaviour of the pads immediately following a PoR or RUN reset because the input enable field is initially clear."）。起きるのは**ファームが pad を入力にしたとき**と、ADC のピンで入力を有効にしたとき。対策は DS の Workaround（IE を落とす、外付け 8.2 kΩ 以下）
4. **ウォッチドッグとソフトリセット**: pad がリセットの形に戻るのは PADS のブロックがリセットされたとき。ISO（分離ラッチ）のビットはこのリセットでは戻らず、ラッチは電源投入・ブラウンアウト・RUN・デバッグのリセットで戻る [RP2350 p.596] §9.7。ウォッチドッグが何をリセットするかは WDSEL の設定による [RP2350、Watchdog の節]。MicroPython のソフトリセット（Ctrl-D）は pad を触らない〔推論〕。**「Pico が落ちたら `RAIL_OK` が落ちる」はリセットの種類で成り立ち方が違う** → ファームの要件（§3 F9）
5. **I²C の電源断**（§0.1 #8）: BSS138 のボディダイオード（ソース→ドレイン）は、9 V 側（`VCC_TONE`、+15 V → L7809）が 0 V のとき 3.3 V 側を引く。High ≈ 0.6 V ＋ (3.3 − 0.6) × 10 k / (10 k + 4.7 k) ≈ 2.44 V〔計算、VF 0.6 V と PT 側に 10 kΩ 以外の負荷が無いと仮定〕、MCP23017 の VIH 0.8 VDD = 2.64 V [sw] §4 D041 を割る。起こる状態: 主電源 OFF で USB だけ（ENC が読めない）、RS6 のヒカップ（制御 MCP に PRST を書けない）
6. **`PG_N`**（§0.1 #9）
7. **スタックの `3V3`**（新-7）: [DEC] §3-8 は「`+5V_COIL` は全娘へ配られ…BP5293 は 570 kHz の内部発振器」を理由に L7805C へ替えた。スタックの `3V3` も全娘へ配られ、源は Pico 基板の 3V3 出力（その前段も BP5293 の `+5V_D`、[SF pin U1607]）
8. **±15 V の有無**（§0.1 #2）: [DEC] §5-7 の前提自身が「SET を出す前には ±15 V の有無は分からない〔推論〕」「起動時の全リセットは `+5V_COIL` が無くて効かない…後から PD が来たことも見えない〔推論〕」と書いている。決定（±15 V が無い間は電源 SET も EN も出さない）と、選んだ形（`MON` で兼ねる）が噛み合っていない
9. **SET/RESET の同時通電**（§0.1 #6）: 電源リレーの両コイルを止めるゲートが [DEC] §6-1 の表に無い

### 2.4 (d) 電源断

- 主電源 OFF → `PD_12V_SW` が落ちる → RS6 は入力 7 V typ で止まる [pow] §1、L7805C は入力が約 7 V を割ると 5 V を保てない〔推論: L78 の一般的なドロップアウト。ds_facts に L7805C の行は無い〕、Pico は `+5V_D` から → **どれが先に落ちるかは決まらない**〔推論〕
- そのため、レールの喪失（B2・`RAIL_OK`）で音声リレーを戻す動作は、コイルの電源が残っている間に起きたときだけ効く。**リレーは前回の状態のまま残るのが普通**と見て、次の投入の P4 で消す（[DEC] §2-1 の決定と同じ扱い）
- ポップ: 娘の過渡は、音声リレーが戻ればバスから切れる。親の HP バッファ自身の電源の崩れは娘の設計では消せない。ミュート素子がラッチでも非ラッチ常開でも、電源断でミュートにはならない（[AZBR] §6.3-5 の素子の表）
- **新-2 の検知線を `PD_12V_SW` に置けば、RS6 が止まる前に予告が取れる**〔推論: 入口の電解の保持時間の分〕。予告でファームは ミュート → `CH_EN`=0 → `RAIL_OK`=0 まで出せる（I²C 1〜2 回）。間に合わなければそれまで

### 2.7 D10（音声 SET は全リセットから始まる手順の中でだけ）を守れるか

- **ファームで守る形（必須）**: ASET を書くコードは §2.1 の状態機械の S10 の 1 か所だけ。S10 に入れるのは「S2（`RAIL_OK`=0）→ S3 → S4 → S5 → S6 → S7 → S8 → S9」を同じ呼び出しの中で通ったときだけ。同じ娘の中の切替（§2.2）は ASET を出さず、`RAIL_OK` も落とさない。途中で失敗したら S2 からやり直す（1 回まで）
- **ハードの助け**: 娘の側で ASET は `RAIL_OK` と B1 でゲートされる（[DEC] §5-3・§5-4）。Pico が落ちれば `RAIL_OK` が落ちる（§2.6 の条件つき）。制御 MCP の RESET を Pico から取れば、固まった ASET が再起動後に `RAIL_OK`=1 と重なることも無い
- **任意のハード（親）**: 「PRST のパルスでセット、ASET の終わりでクリアされるフリップフロップ」で ASET をゲートすれば、D10 がファームのバグにも効く〔推論、部品 2 個程度〕
- **破綻する形**: (1) ジャンパの重複（2 枚が同じ段）— 全リセットでも消えない。§5.5 の線の回しで消せる。(2) 同じ娘の中の切替で ARST → ASET を使う実装 — 規則で禁止

## 4. 操作者から見た振る舞い

### 4.1 操作と表示

- **操作**: ENC×3（CH／BASS／TREBLE、押し SW 付き）・DEST スイッチ・ポット（[DEC] §7 V21-継-01〜04）。CH の ENC を回すと LCD に候補（例「→ 2-3」）が出て、押すと確定して切替が始まる（V21-継-01）

- **DEST の表示は食い違っている**: NOW.md の UI は「状態表示（CH / DEST / Bass / Treble）」だが、DEST は機械スイッチで位置センスは無い（V21-継-04「ファームが知る必要が無い」）。図には DEST の LED が 2 個あり、UI の MCP が駆動している [SF nets LED_DEST1/2]。ファームは DEST を知らないので LED も LCD も正しく出せない（骨格は `dest = "PHONE"` の仮置き、`firmware/main.py`）。**LCD から DEST を外すか、センスを足すかを決める**（2MD1 は DPDT で両極とも音声に使っている [SF pin SW501] ので、センスには極の多いスイッチが要る）

| (ii) 親で TONE バスのソースを切り替える、**ファームが操作** | PT2314E の出力とライン入力をラッチ（AZ850P2-5）で選ぶ。ENC の押し長押しなどで切替 | 制御 MCP に 2 本（§1.5 で入る）。ファームが DIRECT を知るので PT2314E のミュートの代わりにミュート素子を使い、LCD の Bass/Treble を無効表示にできる |

**推奨: (ii)、振幅は 2 Vrms 公称・2.3 Vrms 以下**（PT2314E 経路の Vimax min 2.3 Vrms [sw] §5 に揃えれば、ADC の入力抵抗（V21-継-08）とバスの振幅の検討をやり直さなくて済む〔推論〕）。**いちばん強い理由**: 切替の手順（§2）は「どの経路で聴いているか」をファームが知っている前提で組んである。

### 5.3 V21-未決-20 縦積みでの DIP の手の届き

| 案 | 長所 | 短所 |
|---|---|---|
| (i) まっすぐ積む・下の段は抜いて差し替える | コネクタ 1 種 | 差し替えのたびに電源断・再起動（[DEC] §6-2 運用、V21-未決-25）。装置の目的に反する |
| (ii) 段の間隔を広げ、ソケットを前縁に寄せる | コネクタ 1 種・まっすぐ | 背が高くなる。指と抜き具が入る間隔は模型でしか決まらない |
| (iii) **段をずらす（階段）** | 全段のソケットに上から届く | 上下のコネクタを別にする必要（下 x、上 x＋Δ）。筐体が 3Δ 広がる |

**推奨: 基板を起こす前に原寸の模型で (ii) と (iii) を比べる。第一候補は (iii)**。**いちばん強い理由**: 石の差し替えが装置の目的で（V21-継-22）、下の段を抜く運用は「電源を切ってから抜き挿し・挿したら再起動」（V21-未決-25）と重なって 1 回の比較が数分になる。(iii) を採ると上下のコネクタが別になるので、§5.5 の線の回しが追加の費用なしで入る。

### 5.4 新-1〜新-4

- **新-1 親のレベル線の出どころ**: (a) 制御専用 MCP23017（推奨）、(b) UI の MCP の空き 5 本＋Pico 4 本（9 本で足りない）、(c) シフトレジスタ（74HC595 級、SPI）— POR の出力が DS で決まらない品が多く、/OE のプルアップが要る〔推論〕。推奨 (a)、RESET は Pico の GPIO（外付けプルダウン 8.2 kΩ 以下）。**理由**: POR の状態（全ピン入力・OLAT 0）が DS にある [sw] §4
- **新-2 PD／±15 V の検知**: (a) `PD_12V_SW` の分圧 → GPIO（推奨。電源断の予告にもなる）、(b) 親の +15 V の分圧 → GPIO（RS6 の保護も見える）、(c) `MON` で兼ねる（今の決定。前もって分からない）。**理由**: [DEC] §5-7 の決定を前もって守れる
- **新-3 同じ娘の中の切替**: §2.2 の (A)／(B)。推奨 (A)＋§5.1 のミュート。**理由**: 電源リレーを動かさず、D10 に触れない
- **新-4 `PG_N`**: (a) 娘の B 信号（両レールがおおむねある）で NMOS を引く共通線にして `MON` の妥当性を見る（推奨）、(b) 外して予備にする。**理由**: `MON` の分圧の断線は「0 V ＝ 給電していない」と同じに見えるので、別の経路の 1 ビットで見分けたい

### 5.5 新-5 PSET の段の選び方

- 今の決定はジャンパで段を選ぶ（[DEC] §2-5）。[DEC] §2-5 の理由は「段ごとに違う線を通すなら番号をずらす仕掛けが要る」
- **線の回し**: 各娘は下のコネクタの `PSET1` を自分の電源 SET に使い、下の `PSET2`・`3`・`4` を上のコネクタの `PSET1`・`2`・`3` へ渡す（上の `PSET4` は空き）。基板は 1 種類のまま、ジャンパは要らず、**段の番号は積んだ順で決まり、重複が起きない**〔推論〕
- 代償: 下と上のコネクタを別にする（1 本の貫通ヘッダでは回せない）。§5.3 (iii) の階段と同じ作り
- 推奨: §5.3 で (iii) を採るなら線の回しも採る。(ii) で貫通ヘッダを使うならジャンパのまま、在庫確認（§2.3 P6）と組み立ての手順で重複を避ける

### 5.6 新-6〜新-8

- **新-6 差し替えの運用**: 選んでいない娘は電源ごと落ちている（コールドスタンバイ、[DEC] §1-1）ので、全リセットと放電の確認（§2.1 の S2〜S5）の後なら、箱の電源を入れたまま石を差し替えられる〔推論〕。「差し替えモード」として手順化するかを決める。娘そのものの抜き挿しは今の決定（電源を切ってから、V21-未決-25）のまま
- **新-7 スタックの `3V3`**: 娘の論理（単安定・ゲート・B1/B2）を `+5V_COIL` から娘ごとの小さな LDO で作ればスタックの `3V3` は要らない（1 ピン空く）。USB だけのときは娘の論理も落ちるが、そのときはコイルも無いので失うものは無い〔推論〕。親から来る 3.3 V の線は電源の無い論理に入るので Ioff 付きの品にする
- **新-8 I²C の分割**: PT2314E だけを BSS138 越しのバスに残し、MCP（UI・制御）を 3.3 V だけのバスへ。空きピンの組み合わせは実装で決める（例: タッチの `TP_SDA`/`TP_SCL` を使わないならその 2 本）〔推論〕

### 5.7 関連する後回しの未決

- **V21-未決-06**（リセットの順序をハードで、PRST を音声リセットの OR に、自動リセットを電源リレーにも）: 本評価の §0.1 #6 のゲート（PSET_eff = PSET_k AND NOT PRST）とは別件。娘のレールの短絡（22 Ω が約 10 W、[SRPR] §3 (b)）はファームの S7 の上限で止める前提で、ファームが止まっていればヒューズ抵抗が開くまで続く
