## 2. 指摘

### A-01 トーンのブーストでチップ・石・出力 TMUX の頭が足りない（前置きの減衰が決まっていない）

- **重さ**: 聴こえる／**起きやすさ**: ふつう（BASS/TREBLE を上げてふつうの音量の音楽を聴く）
- **種類**: 決定の穴（§1-5・§1-6）＋記述の誤り（§3-3 の 9.45 Vpk、§1-5 の「もう天井にならず」）
- **場所**: §1-5、§1-6、§3-3、V21-継-08
- **何が起きるか**: 源 2.3 Vrms・Bass +10 の設定で、20 Hz の成分は `TONE` で 15.9 Vpk 相当、`AMP_SEL` で 31.9 Vpk 相当を求める。先に石が頭を打つ。石が頭を打つブーストは、フルスケールの正弦で次のとおり〔計算〕:

| 源 | 推定 min の低い石（8.0 Vpk） | 推定 min 9.0 Vpk の石 | 保証の石（約 11.1 Vpk） | NJW1194（3.6 Vrms min） |
|---|---|---|---|---|
| 2.3 Vrms | +1.8 dB | +2.8 dB | +4.6 dB | +3.9 dB |
| 2.0 Vrms | +3.0 dB | +4.0 dB | +5.9 dB | +5.1 dB |

  Bass +10 なら、20 Hz の成分がフルスケールの −12 dB（2.3 Vrms の源）を越えると振幅の小さい石が頭を打つ。50 Hz なら −10.7 dB、100 Hz なら −8.2 dB〔計算〕。今の音楽の低音はこの帯に入る〔推論〕。出力 TMUX も平坦域の端（娘の VDD しだいで +8〜+10.6 V〔仮定、Fig 5-4 目読み〕）を越え、Fig 5-20 の容量は +9 V の外で急に増える〔DS p20 画像で目読み〕。MUSES01 は ±12 V で同相範囲が推定 ±5 V で〔[direct_bypass_review.md](direct_bypass_review.md) §3.3〕、ブーストで `TONE` が 5 Vpk を越えると外れる。ADC は `AMP_SEL` 7.74 Vpk で頭を打つ（表示だけ）
  → 石ごとに頭の打ち方が違う（どこで・どう崩れるか）。聴き比べが「クリップの比べ合い」になる〔推論〕
- **根拠**: §1.2 の DS の事実。石の振幅は [pm12_judgement_review.md](pm12_judgement_review.md) 要約 3・6（推定 min 9.0 V の石 8 つ前後、保証 2 石は 9.45 Vpk に +1.4〜+1.6 dB）と [direct_bypass_review.md](direct_bypass_review.md) §3.3（推定 min 8.0 Vpk）。§3-3 の 9.45 Vpk の出どころは「PT2314E の出力が 0〜VDD に収まる」天井で〔[direct_bypass_review.md](direct_bypass_review.md) #11・§3.1〕、PT2314E は §1-6 で却下された。NJW1194 の天井は `TONE` で 5.1〜6.1 Vpk（`AMP_SEL` で 10.2〜12.2 Vpk 相当）で、±12 V の石の振幅の上にある〔計算〕。同じ見落としは [tone_chip_bypass_review.md](tone_chip_bypass_review.md) M3 が「音量 ＝ −(最大の持ち上げ量)」の形で挙げたが、DECISIONS に入っていない
- **外れる条件**: ブーストを使わない（0 dB かカットだけ）／源が 1 Vrms 級以下で使う／頭打ちも聴き比べのうちとユーザーが受ける
- **直し方の案**:
  1. ファームで **NJW1194 の音量 ＝ −（その設定のトーン曲線の山）**。Bass は 20 Hz の値（+1 → 0.9、+5 → 5.6、+8 → 9.7、+10 → 13.8 dB〔DS p23 画像で目読み〕）、Treble は 20 kHz の値（+10 → 約 10.8 dB）、両方なら大きい方。DIRECT（TSW＝0）とフラットでは 0 dB。切替の「段階で絞る／戻す」はこの値から／この値まで
  2. 代わりに失うもの: フラットの音量が同じだけ下がる。HP は余る（V21-継-03）。LINE の最大は Bass +10 で 4.6 → 0.94 Vrms〔計算〕
  3. 50 Hz の値（+10 で 12.5 dB）で妥協する、ブーストの上限を +6 dB にする、も選べる
  4. §1-5 の「頭を打つ順」に「フラットのとき」と書き、§3-3 の 9.45 Vpk を「前置きの減衰があれば `AMP_SEL` の最大は源 × 2（2.3 Vrms で 6.5 Vpk）」に置き直す
- **ユーザーの判断**: 要（前置きの減衰の形・ブーストの範囲・LINE の最大）

### A-02 NJW1194 の音量の符号 — +31.5 dB の段と、3 線の 1 ビットの誤り

- **重さ**: 聴こえる（突然の大音量。LINE の能動スピーカは最大出力に張り付きうる）／**起きやすさ**: まれ（ファームの誤り、3 線の乱れ）
- **種類**: 決定の穴（§1-6・§2-10・§6-2 は「音量を段階で絞る」とだけ書き、符号の選び方と上限が無い）
- **場所**: §1-6、§2-10、§6-2
- **何が起きるか**:
  - 音量の符号〔DS p12・p16 のテキスト〕: 0x00 ＝ MUTE、**0x01 ＝ +31.5 dB**、0.5 dB ずつ下がり 0x40 ＝ 0 dB、0xFE ＝ −95 dB、0xFF ＝ MUTE（初期値）。MUTE が両端に 2 つある。0xFF から 1 つ進めると 0x00（MUTE）、もう 1 つで +31.5 dB。0x00 を MUTE に使うと、1 ビットの誤り 8 通りのうち 6 通りが +16〜+31.5 dB（0x01・0x02・0x04・0x08・0x10・0x20）になる。0xFF と 0x40 の 1 ビットの誤りは 8 通りとも 0 dB 以下
  - 語の番地（D7〜D4）: 音量 1 ＝ 0000、音量 2 ＝ 0001、セレクタ ＝ 0010、Treble ＝ 0011、Bass ＝ 0100〔DS p11〕。**セレクタ・Treble・Bass はどれも 1 ビットで音量の番地になる**（D5 か D6）。そのときのデータ: セレクタの Input1 ＝ 0x04 → **+30 dB**、Treble（TSW＝1）の 0 dB ＝ 0x04 → +30 dB・Cut −3 dB ＝ 0x1C → +18 dB、Bass Cut −3 dB ＝ 0x18 → +20 dB〔DS p16・p17 の符号から計算〕
  - §1-6 は「毎回全部を書く」ので、切替とトーンの変更のたびにこの語が流れる。3 線は読み返せない〔DS p11〕
  - 起きたとき: チップの出力は約 4.2 Vrms で張り付き、石が頭を打ち、HP・LINE は今のポットの位置のまま平均で +15〜+25 dB 級の歪んだ音になる〔推論〕
- **根拠**: 〔DS p11・p12・p16・p17〕。MCP23017 で打つ 3 線は、DATA と CLOCK を同じポートの 1 回の書き込みで動かすと t5／t6（1.6 µs min〔DS p11〕）を割りうる〔推論〕
- **外れる条件**: ファームが下の規則を守り、3 線に乱れが無いとき
- **直し方の案**（ファームの規則、部品なし）: ① MUTE は 0xFF だけを使う ② 音量の符号は 0x40〜0xFF に飽和させる（0 dB を超えない。A-01 の前置きの減衰とも合う） ③ 全語を書くときは音量 1・2 を**最後**に書く（化けて音量に入った語を 1〜2 語のうちに上書きする） ④ DATA を変える書き込みと CLOCK を変える書き込みを分ける ⑤ 聴取中も一定の周期（例 1 s）で全語を書き直し、化けた状態の長さを抑える
- **ユーザーの判断**: 不要（§6-2 に規則として入れる。② の 0 dB の上限は A-01 の決めと一緒に）

### A-03 切替の間、`AMP_SEL` から先は絞られない — 音声 SET の瞬間の DC の残り

- **重さ**: 聴こえる（整定待ちが短いとはっきりしたポップ、長ければかすか）／**起きやすさ**: ふつう（毎回の切替。入力バイアス電流の大きい石で）
- **種類**: 記述の誤り（§2-10 の前提）＋決定の穴（§6-2 の待ち、V21-実測-12 の中身）
- **場所**: §2-10、§6-2、V21-実測-12
- **何が起きるか**:

  - 段の大きさ（入力バイアス電流 Ib による出力 DC ＝ 180 kΩ × Ib、EN からの時間 t）〔計算、`dcres.py`〕:

| 石（Ib） | 出力 DC | t＝0.1 s | 0.2 s | 0.3 s | 0.5 s | < 0.5 mV まで |

- **外れる条件**: 比べる石が JFET 入力だけ／ファームの整定待ちが 0.6 s 以上／実測（V21-実測-12）で段が聴こえない
- **直し方の案**:
  1. S9（整定）の下限を **0.6 s** に決める（ファームは石を知らないので最悪の石で）。切替の所要は 0.8 s 級（参考の製品も約 1 秒、§2-10 の根拠）
  2. 短くしたいなら、ch の + 入力のバイアス 100 kΩ を 47 kΩ に（τ 57 ms、出力の DC は約 4 割〔計算: 2 × 47 k − 20 k ＝ 74 kΩ × Ib〕。代わりに入力の極 1.6 → 3.4 Hz で 20 Hz −0.12 dB、`TONE` の中域の負荷 28 kΩ〔計算〕。v2 からの値の変更）
  3. §2-10 の前提を「出力側の節の DC は入力結合の τ（110 ms）と石の入力バイアス電流で決まる」に直す
  4. V21-実測-12 に「無信号・AD797 か NJM5532 で、HP と LINE の出力を ARST・PSET・ASET の各エッジで記録」を足す。(i)(ii) が聴こえたら、切替の間だけポットの前の GND 落としを掛ける案（§2-10 で退けた形）が効く唯一のハードの手になる（ユーザーが退けた時点では (i)(ii) は見えていなかった）
- **ユーザーの判断**: 要（切替の所要が 0.25 s の側に寄せられないこと、または 100 kΩ の変更）

### A-04 聴く節（ポットの前）に外の負荷が直接載る — `AMP_SEL OUT` と LINE

- **重さ**: 聴こえる／**起きやすさ**: まれ（電源の切れた機器をつないだまま）〜ふつう（LINE を上げ切り、能動スピーカ 10 kΩ）
- **種類**: 決定の穴（§4-14 は端子から外を見た出力インピーダンスだけを書き、外の負荷が聴く経路へ返る向きを書いていない）
- **場所**: §4-14、§2-10（GND 落としの足場）、V21-継-03・V21-継-07・V21-継-10
- **何が起きるか**:
  - `AMP_SEL OUT` は節 X に直結で、HP・LINE のポットと並ぶ〔SF pin J_RAIL501・SW501〕。外の機器の入力がそのまま聴く経路の負荷になる
  - **電源の切れた外の機器**: 入力の保護ダイオードが外の入力抵抗 R_ext 越しに ±0.6 V でクランプし、源のインピーダンス越しに聴く経路のピークを削る。源 2.3 Vrms（6.5 Vpk）で〔計算、外の入力の形は〔仮定〕〕:

| 源のインピーダンス（節 X から） | R_ext 10 kΩ | R_ext 1 kΩ |
|---|---|---|
| 49 Ω（今: 47 Ω＋Ron） | 29 mV（ピークの −47 dB） | 276 mV（−27 dB） |
| 1.05 kΩ（GND 落としの R 1 kΩ を入れたとき） | 560 mV（−21 dB） | 3.0 V（−7 dB） |

  - **線形の負荷**: 出力結合 2.2 µF の極が負荷で動く〔計算〕

| 負荷 | 節 X の負荷 | 極 | 20 Hz | 40 Hz |
|---|---|---|---|---|
| HP（ポット 1 本） | 29 kΩ | 2.5 Hz | −0.08 dB | −0.03 dB |
| LINE 上げ切り＋能動スピーカ 10 kΩ、または HP＋`AMP_SEL OUT` 10 kΩ | 7.4 kΩ | 9.7 Hz | −0.97 dB | −0.30 dB |
| LINE 上げ切り 10 kΩ＋`AMP_SEL OUT` 10 kΩ | 4.3 kΩ | 17 Hz | −2.4 dB | −0.80 dB |

    この負荷では 2.2 µF の ±5 % が 20 Hz で 0.36 dB の **ch 間の差**になる（ポット 1 本なら 0.013 dB）。V21-継-10 の「公差の生む ch 間差は可聴帯に効かない」は軽い負荷の前提
  - GND 落としの R（1 kΩ）を入れると、外の 10 kΩ をつなぐ／外すで聴く音量が 0.85 dB 動く（−0.18 → −1.03 dB）〔計算〕
  - 石の負荷が 29 kΩ → 4〜7 kΩ に変わり、石の動作点が変わる。v2 でタップにバッファを置いた理由（V21-継-07、[tap_facts.md](tap_facts.md) §2「全 DUT の動作点が変わる」）と同じ筋。出力 TMUX の Ron の歪みは平坦域なら 4.3 kΩ でも −140 dB 以下で、ここは効かない〔計算、`sw_thd.py`〕
- **根拠**: 上の計算。§4-14 の前提の欄は「R を入れたら端子の出力インピーダンスも上がる」だけを書く
- **外れる条件**: `AMP_SEL OUT` に何もつながない／つなぐ機器はいつも電源が入っていて入力が 10 kΩ 以上／GND 落としの R を入れない
- **直し方の案**:
  1. 運用の約束（費用 0）: `AMP_SEL OUT` につなぐ機器は電源を入れておき、使わないときは外す。入力 10 kΩ 未満の機器はつながない
  2. GND 落としの R を実装するときは、端子を R の手前（`AMP_SEL`）へ戻すか、端子に専用のフォロア（タップのバッファと同じ考え、V21-継-07）を置く。§4-14 の「ミュートの内側」は専用のフォロアを R の後ろに置けば両立する
  3. V21-継-10 に「ポット 1 本の負荷のとき」と注記し、LINE の重い負荷では 2.2 µF の LCR の揃え（PARTS の MATCH）が 20 Hz で効くと書く
- **ユーザーの判断**: 要（運用で受けるか、端子の置き場かバッファか）

### A-05 箱の外との閉路と、`A_GND` の中の帰りの道が決まっていない

- **重さ**: 聴こえる（ハム・PC のノイズ・切替のクリック。配置しだい）／**起きやすさ**: ふつう（Pico の USB を PC につないで簡易分析をしながら、同じ PC の USB DAC を源にする）
- **種類**: 決定の穴（V21-継-19 は系統の間の木、V21-継-20・V21-未決-15 はシャーシ、V21-未決-19 は NetTie の置き場。`A_GND` の中の道と箱外の GND の入口は無い）
- **場所**: §3-9、§3-11、§4-3、§4-14、V21-継-19・-20、V21-未決-15・-19
- **何が起きるか**:
  - 今の図の星の中心は `D_GND`: `A_GND`–`D_GND`、`PD_GND`–`D_GND`、`GND_COIL`–`D_GND` の NetTie〔SF pin NT1603・NT1602・NT101〕。`D_GND` は Pico の USB の GND
  - `A_GND` に来る箱外の GND: 入力端子、HP 端子、LINE 端子、`AMP_SEL OUT`、FrontPanel の XH8（ポットの下端）〔SF〕。源が同じ PC につながっていれば「PC → 源 → 入力の `A_GND` → `A_GND–D_GND` の NetTie → Pico の USB → PC」の輪ができ、その電流は入力端子から NetTie までの `A_GND` の銅を流れる〔推論〕。LINE の能動スピーカ・`AMP_SEL OUT` の機器（商用電源の機器）と PD 充電器の間でも、`PD_GND–D_GND–A_GND` を通る輪ができる〔推論〕
  - `A_GND` の中の大きな電流: HP の帰り（32 Ω で最大 80 mA 級〔§3-11 の根拠〕）、電源 SET の突入 0.68 A（ms 級、A-03 (ii)）、RS6 の絶縁容量の電流（110 pF max〔[power.md](../ds_facts/power.md) §1〕、スイッチング周波数）。これらが NJW1194 の GND・`TONE`／`AMP_SEL` のプルダウン・ポットの下端・センス点と銅を共有すると、IR 降下が聴く経路に直列に入る〔推論〕。例: HP を上げ切って 80 mA 流れるとき、共有の銅 2 mΩ で 160 µV。入力の基準に入れば 3.25 Vpk に対して −86 dB で、NJW1194 の歪みと同じ桁〔計算、2 mΩ は〔仮定〕〕
  - 娘の `A_GND` は音声コネクタの ×6 と 2×12 の ×2 で親と並列につながる（§1.1）。聴取中に娘の `A_GND` を流れるのは帰還の 20 kΩ の電流（0.16 mA pk）と LDO の GND 電流だけで無害だが、電源 SET の突入はこの並列で分かれ、センス点（音声コネクタの `A_GND` ピン際、§4-3）の足元を通る〔推論、[adc_gnd_retree_review.md](adc_gnd_retree_review.md) §3.2 の表「並列路」〕
  - §4-3 の「本線が受け取るのもコネクタの電位差なので『聴いているもの』と揃う」は、聴く側の基準がポットの下端（FrontPanel）と HP 端子であって、センス点とは母板の `A_GND` の銅で離れているので半分〔推論〕。計測だけの話で本線には効かない
- **根拠**: 上の〔SF〕と計算。v1 の「USB を抜いた A/B で床の差 2.9 dB（n=1）」〔[rejected_review_review.md](rejected_review_review.md) #10 の引用、V21-継-28〕は効きがあることを示すが、源が同じ PC の形は測っていない（確かめられず）
- **外れる条件**: Pico の USB と源を同じ PC につながない／外の機器がどれも浮いた電源（電池・2 極の AC アダプタで Y コンデンサ無し）／配置で下の規則が守られる
- **直し方の案**:
  1. DECISIONS に規則を 1 つ足す: **`A_GND` を「幹」と「基準」に分ける**。幹 ＝ RS6 の COM・`A_GND–D_GND` の NetTie・HP の帰り（HP バッファのデカップへ寄せる、§3-11）・2×12 の `A_GND`・箱外の端子の GND。基準 ＝ NJW1194 の GND と ±7 V の LDO の GND・`TONE`／`AMP_SEL` のプルダウン・音声コネクタの `A_GND`・ポットの下端・センス点。基準は幹へ 1 点でつなぐ。娘の上でも、レールの容量の帰りは 2×12 の `A_GND` へ寄せる
  2. V21-実測-03 に「Pico の USB と入力の源（USB DAC）を同じ PC に」と「LINE に商用電源の能動スピーカ」の A-B-A を足す
  3. V21-未決-15（シャーシ）と V21-未決-19（NetTie の置き場）を決めるときに一緒に決める
- **ユーザーの判断**: 要（規則を DECISIONS に入れるか、未決-15・-19 と一緒に）

### A-06 聴取中に動く LCD の SPI と、ケーブルを渡るポットのワイパ

- **重さ**: 聴こえる（かすか、配線しだい）／**起きやすさ**: ふつう（スペアナ・VU は聴取中に更新し続ける、§4-2）
- **種類**: 確かめが要る
- **場所**: §4-2、V21-継-03、V21-継-21、NOW「パネル」
- **何が起きるか**: HP バッファの入力はポットのワイパで、源のインピーダンスは最大 12.5 kΩ（50 k の真ん中）〔計算〕。ワイパの線は母板 → FrontPanel（XH8）→ ポットの板（XH 6P、NOW）→ FrontPanel → 母板とケーブルを 2 回渡る〔SF nets PHONE_BUF_L・J_PNL_A…〕。同じ FrontPanel に LCD の SPI・タッチ・UI の I²C が来る〔SF nets LCD_SCK・TP_SDA〕。コネクタは分けてあるが、束ね方・FrontPanel の上の配線は決まっていない。高インピーダンスのワイパは SPI のエッジを容量で拾い、OPA1652 の入力で検波されて音声の帯のうなり（画面の更新の周期）になりうる〔推論〕。LINE のワイパは箱の外のケーブルまで高インピーダンスのまま〔SF〕
- **根拠**: 上の〔SF〕。FrontPanel のアナログの XH8 は 8 本のうち 4 本（5〜8）が空き、`A_GND` は 1 本だけ〔SF pin J_PNL_A1601_1・_2〕。V21-継-21 は LCD を計測のための雑音源として扱っている（「測定中に LCD を電源ごと切れること」）が、聴く経路の規則は無い
- **外れる条件**: 配線で SPI とワイパが離れている／実測で差が無い
- **直し方の案**: XH8 の空き 4 本を `A_GND` にして、`AMP_SEL`・ワイパ・LINE の線を GND で挟む。デジタルの XH10 と束ねない。FrontPanel の上で SPI とワイパの線を平行にしない。LCD の更新あり／止めたの A-B-A（無信号、HP を上げ切り）を実測に足す。必要なら HP バッファの入力に RF の小さな RC の置き場（例 100 Ω＋220 pF、12.5 kΩ と組んで 58 kHz〔計算〕）
- **ユーザーの判断**: 不要

### A-07 トーンの変更・音量の段のクリック（DS に無い）

- **重さ**: 確かめが要る（聴こえるかもしれない）／**起きやすさ**: ふつう（聴きながら BASS/TREBLE を回す、毎回の切替で音量を段階で動かす）
- **種類**: 確かめが要る
- **場所**: §1-6（実物で測る）、§2-10、§6-2、V21-継-01
- **何が起きるか**: トーンは 1 dB 刻みでトーン段の内部抵抗を切り替える〔DS p9・p10 の表〕。音楽が鳴っている最中の切替で、その瞬間の低音の瞬時値に比例する小さな不連続が出うる〔推論〕。音量の 0.5 dB 刻みも同じ（MCP 経由で 1 語 1〜15 ms〔[tone_chip_bypass_review.md](tone_chip_bypass_review.md) M4〕で刻むと、段の列が聞こえうる）。ゼロクロス検出は特長とブロック図にあるだけで、何に効くか・有効にする手段は DS に無い〔DS p1・p8、[verify_njw1194.md](../ds_facts/verify_njw1194.md) §7〕。DS の注が「TSW を切り替えるときはセット側で MUTE」〔DS p8〕を求めるのは、チップの中の切替に段がありうることをメーカーが見ている証と読める〔推論〕
- **外れる条件**: 実測で聞こえない
- **直し方の案**: §1-6 の「実物で測る」に足す: 50 Hz と 1 kHz の −10 dBFS の正弦で、BASS を 0 → +10 に 1 dB ずつ、TREBLE も同じ。音量の段の刻みの速さを変えて。聞こえたら、トーンの変更の前後だけ音量を数 dB 絞る、または刻みの速さを決める
- **ユーザーの判断**: 不要（測ってから）

### A-08 NJW1194 の L/R 分離は入口の源インピーダンスで決まる

- **重さ**: 無害／**起きやすさ**: ふつう
- **種類**: 記述の誤り（§1-6 の「スルー時に DS が保証するのは最大出力・利得・ch 分離だけ」）
- **場所**: §1-6（理由・前提、いったんの決め 3）
- **何が起きるか**: p22 の分離（INB1 → Aout）は Rg で大きく変わる。Rg 0 Ω で −112 dB 平ら、620 Ω で 1 kHz 約 −99・10 kHz 約 −81 dB、3.3 kΩ で 10 kHz 約 −66 dB〔DS p22 画像で目読み〕。20 dB/dec で、等価な結合 2.3 pF に当たる〔計算: 620 Ω と 3.3 kΩ の 2 本で同じ値〕。入口の直列 1 kΩ（既定、§1-6-3）と源 100 Ω で Rg ≈ 1.1 kΩ → 1 kHz −96 dB、10 kHz −76 dB、20 kHz −70 dB。源 600 Ω なら 10 kHz −73 dB〔計算〕。表の CS1（max −90 dB）は Rg ＝ 0 Ω・1 kHz・A 重みの条件で〔DS p3〕、1 kΩ を入れた形には当たらない
- **根拠**: 上。[tone_chip_bypass_review.md](tone_chip_bypass_review.md) #8・M2 が同じグラフを読んでいる（1 kΩ の決めはその後）
- **外れる条件**: 入口の直列を 0 Ω に戻す（1 kΩ の理由の電源断の電流と引き換え）
- **直し方の案**: §1-6 の書き方を「分離の保証（CS1）は Rg ＝ 0 のとき。直列 1 kΩ では 10 kHz で −76 dB 級（typ グラフから）」に直す。−70 dB 級の分離は聴こえる差ではない〔推論: ヘッドホンの 3 極のケーブルの共通の帰りだけで 32 Ω なら −44 dB 級〔計算: 0.2 Ω／32 Ω、ケーブルの抵抗は〔仮定〕〕〕。ADC で石の L/R 分離は見えない、と §4-2 の範囲に記録
- **ユーザーの判断**: 不要

### A-09 鎖に共通の歪みは石の差より大きい（記録）、DIRECT とトーン 0 dB の差は周波数特性の公差の方が大きくなりうる

- **重さ**: 無害／**起きやすさ**: ふつう
- **種類**: 記述の補足（§1-6 の DIRECT の理由）
- **場所**: §1-6、§4-2
- **何が起きるか**: §1.3 の表のとおり、共通の歪みの主は NJW1194（1 kHz −96 dB、10 kHz −86 dB typ、保証なし）で、次が出力 TMUX の容量の非線形（10 kHz H2 −100 dB）。比べる石の THD（DS で 10⁻⁵〜10⁻³ %）と ch 自身の床（−121 dB）はその下。聴こえる帯ではないので目的（耳で比べる）は損なわない〔推論〕。§1-6 はスルーとトーン 0 dB の差を THD（10 kHz 0.005 ／0.01 %）と雑音（1.41／2.2 µV）で「ほぼ誤差」としたが、トーン 0 dB の利得は **100 Hz と 10 kHz で ±2 dB max**〔DS p5 GVBASS1・GVTREB1〕で、トーンの外付けの網（3.3 nF・100 nF・4.7 µF・4.7 kΩ）の公差もここに乗る〔推論〕
- **外れる条件**: —
- **直し方の案**: 記録だけ（§1-6 の前提の欄に「スルーとトーン 0 dB の差は周波数特性の公差 ±2 dB max もある」と 1 行）。トーンの外付けの網は 1〜2 % の film／C0G で L/R を揃える。DS の応用回路の 4.7 µF は有極性だが、両端の DC は 0 V〔DS p7〕なので無極性でよい〔推論〕
- **ユーザーの判断**: 不要

### A-10 入口の結合 C の端子側の 1 MΩ は「置き場」のまま

- **重さ**: 無害〜聴こえる（源を挿すときの段）／**起きやすさ**: まれ（DC を持つ源を抜いて、別の源を挿す）
- **種類**: 決定の穴（実装か DNP か）
- **場所**: §1-6-3
- **何が起きるか**: 端子に何もつながないと、4.7 µF の端子側は浮き、前の源の DC を抱えたまま残る。次に挿した源との差がチップへ段で入り、聴いている経路に出る〔[njw1194_io_review.md](njw1194_io_review.md) §8 (a)〕。§1-6-3 は 1 MΩ を「置き場」と書き、実装するかを決めていない
- **外れる条件**: DC 0 V の源しか挿さない
- **直し方の案**: 1 MΩ を実装を既定にする（源の負荷としては 20 kΩ に対して無視できる）
- **ユーザーの判断**: 不要
