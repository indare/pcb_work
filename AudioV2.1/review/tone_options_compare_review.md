### 0.2 統合した推奨

1. **順位を 1 本にせず、決め方の木で示す**〔推論〕:
   - **Q1 トーンは要るか** — 決める前に、今の基板で PT 経由（0 dB・フラット）と入力直の A-B を ADC と耳で取る（対象 §3.3 の最後の行。安い）
   - **要らない** → X。**Q2 硬い端を受けるか**: 受ける → X＋入口の直列 R の足場（または X-b）。受けない → X-c（絞れる素子: NJW1194 をトーン無しで／PGA2310。V21-継-02 の読みを先に決める）
   - **要る** → **Q4 NJW1194 を 2 個以上、受けられる納期で買えるか**: 買える → N。買えない → **Q2 と「A/D を受けるか」で P か D**（端を受ける、または A/D を受けない → P。端を受けず A/D を受ける → D。フラットの DIRECT を含む）
   - P を選んだら **Q3「DIRECT＝チップと無縁」か** で T-a×R-a（形 2）か T-b×R-a（形 1）
2. **N を採るなら、DIRECT（TSW）を置かない形をまず検討する**。トーン 0 dB の経路が 1 kHz でスルーとほぼ同じ〔DS NJW1194 p4・p22〕なので、DIRECT の得は高域の数 kHz 以上と雑音 1.41 → 2.2 µV（typ）だけ。置かなければ TSW の段・書き込みの窓・切替の代償がまとめて消える。置くなら TSW は全リセットの**始めに**書き（結合 C の整定を窓の中で稼ぐ）、「窓の外で音量 MUTE → TSW → 戻す」の段は実測で決める
3. **対象の冒頭表・§3.1 の書き換え**: N の軸 2 を「音楽の硬い端 0（音量が TSW の前）。TSW 自身の段は大きさ不明、窓の中で書くなら切替に全リセット 1 回」に。P の軸 1 は「比べる石より 30〜7000 倍」をやめ、「ch 自身の床（約 0.0001 %）の 300〜1000 倍、N のトーン経由より 23〜36 dB 悪い」に。§2.1 の雑音の段落から「石の雑音の違いが PT の床の下に隠れる」を外す（ch の 10 kΩ ですでに隠れている）
4. **D の行を問い 3 に連動させる**: 前者（チップの中を通ってよい）なら D はフラットの係数で DIRECT を取れ、DIRECT のリレー・端・電源断の DIRECT の枝が消える。「どの条件でも最後」は外し、「聴く経路をディジタルにしてよいか」をユーザーの問いに足す
5. **X-c の候補に PGA2310 を並べ、V21-継-02 を N と PGA2310 に同じ読みで当てる**。「0 dB 固定で切替の絞りだけに使うなら反しない」（[TCBR] M6 の読み）を採るなら両方に効き、採らないなら N も見直しになる
6. **ユーザーへの問いを 9 つにする**（§2 の M8）。順は Q1 → Q2 → Q4 → Q3 → A/D → DIRECT の要否（N）→ DIRECT の切替の代償 → X-c の素子 → 電源断（B6）

### 0.3 外れる条件・要実測（対象 §3.2・§3.3 に足すもの）

| 条件・実測 | 何が変わるか |
|---|---|

## 2. 作業メモ（調べた順。§0 の根拠）

### M1. N の「硬い端 0」と TSW（疑う点 1）

- **ブロック図**〔DS NJW1194 p1 画像〕: In → セレクタ（GND の位置あり）→ 音量ラダーのワイパ（●の節）→ **2 接点のスイッチ**（上＝ワイパ直、下＝TONE ブロックの戻り）→ 出力アンプの＋入力。TONE ブロックの入力は同じワイパの節から取っている。**応用回路**〔p8 画像〕も同じで、音量は入力側のラダーと帰還側の可変抵抗（帰還の足に 100 µF → GND）の組。注 "When switching TSW (Tone Control By-pass Switch), use MUTE on the set." は p8 の下
- したがって音量を MUTE（または十分絞る）にすれば、**TSW の両接点とも音楽を運ばない**〔推論、図から〕。対象の定義（§2.2 冒頭「硬い端 ＝ 生きた信号を接点で切る・つなぐ瞬間の段。DC のポップではない」）では、**N の DIRECT の切替は窓の外でも端 0** と言える
- [TCBR] #16・M5 が言ったのは別の種類: TSW の切り替わりで出る**段（ワイパの節と TONE の戻りの節の DC の差、スイッチの電荷）はラダーで減らない**。これは対象の定義では「端」でなく「ポップ」で、大きさは DS に無い。DS の注は「セット側で MUTE」を求めている（[TCBR] の読み）ので、メーカーは聞こえうる段を想定している〔推論〕
- よって**中身は食い違っていない**。対象 §2.2 の表の「窓の中で書けば 0（代わりに石の電源が 1 回落ちる）。窓の外は要実測」も [TCBR] と同じ。問題は冒頭表の太字「**全場面 0**」と §3.1 の「硬い端が全場面で 0」で、ポップの種類と代償が落ちていること
- **代償の比較（見落とし）**: [DBR] §0.2-4 は P の DIRECT の切替を「全リセットを回さず、娘をつないだまま DIRECT のリレーだけ（端 1、約 20 ms、石の電源は落ちない）」とした。N の「窓の中で書く」は全リセット 1 回（[DEC] §6-2 の 0.25〜0.75 s、比べている石の電源が落ち熱の整定をやり直す）。端の数だけで比べると N が一方的に良く見える
- **窓の中でも段が残りうる**〔計算・仮定〕: 窓の間、`TONE` バスは娘から切れて 100 kΩ（[DEC] §2-11）だけ。チップの出力に段が出れば出力の結合 C を通ってバスに出て、τ ＝ 2.2 µF × 100 kΩ ≈ 0.22 s で減る〔仮定: 今の図の 2.2 µF を N でも残す〕。窓 0.25 s なら e^−1.1 ≈ 33 %、0.75 s なら約 3 % が音声 SET の瞬間に残る。DS の応用回路の 10 µF なら τ ≈ 1 s。段そのものは I/O の DC が 0 V〔DS p6、[TCBR] M6〕なので mV 級の見込み〔推論〕だが、DS には無い。TSW は窓の始めに書くのが筋
- ch 替え（TSW＝0 のまま）の端 0 は支持: 音量ラダーが TSW の前にある〔p1・p8〕

### M2. P の数値と「30〜7000 倍」（疑う点 2）

- 表〔DS PT2314E p12〕: 共通条件 "Ta=25℃, VDD=9V, RL=10KΩ, Rg=20Ω, all controls flat, F=1KHz"。THD "All Gain=0, Vin=1Vrms" 0.03 typ／0.07 max %。帯域・THD か THD+N かの記載は無い。S/N 100 dBV typ（A 重み）。p11 の早見表も同じ値
- グラフ〔p13 "Output THD VS VDD Voltage"、RL 10 kΩ、400 dpi で切り出して目読み〕: 9 V の線は 200 mV 付近で底（約 0.006 %）、**1 V で約 0.03 %、2 V で約 0.1 %**（2 V 付近に小さな山）、約 3 V で急増。1 mV で約 0.7 %＝約 7 µV の床に当たる傾きなので、**グラフの実体は THD+N**〔推論〕。対象の「2 Vrms で約 0.1 %」は支持

### M8. ユーザーへの問い（疑う点 8）

対象の 5 つ（トーンの要否／硬い端／DIRECT の意味／NJW1194 の納期／電源断）は決めるのに**必要だが足りない**。足りない問いと理由:

| 足す問い | なぜ要るか |
|---|---|
| (a) N を採るとき、DIRECT（TSW）は要るか | トーン 0 dB とスルーが 1 kHz でほぼ同じ（M3）。要らなければ TSW の段と切替の代償が消える |
| (b) DIRECT の切替に全リセット（0.25〜0.75 s の無音と石の電源断）を使ってよいか | N の「端 0」の代償。V21-未決-14 の論点「DIRECT の切替を全リセットに入れないか」そのもの（NOW の DIRECT の項） |
| (c) 比べる石の手前の経路を A/D・D/A に通してよいか | D の成否はこれで決まる（M4）。対象は §2.1 で「ユーザーの判断」と書いたが §4 に入れていない |
| (d) X-c の絞る素子（NJW1194／PGA2310）と、V21-継-02 をどう読むか | 「N は X-c を含む」は一択ではない（M5） |

- 問い 5（電源断）は B6（[DEC] §2-10、V21-未決-14）の決めで、X を選ぶときだけ順位に効く。ほかの案では足場の話
- 問いの順は Q1 トーンの要否 → Q2 端 → Q4 納期 → Q3 DIRECT の意味 → (c) A/D → (a)(b) N の DIRECT → (d) X-c → Q5 電源断。Q1 の前に、今の基板で PT 経由と入力直の A-B を取ると Q1 が答えやすい
