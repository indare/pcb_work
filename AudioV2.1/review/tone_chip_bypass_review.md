### 0.2 統合した推奨

1. **順位は 1. NJW1194、2. PT2314E のまま＋DIRECT のリレー（今の査読どおり）、3. NJW1119A** に入れ替える。NJW1119A はバイパスの数値が最良でも、音量が無いので [DEC] §2-10・§6-2 の「段階で絞る」が通常の経路でも失われる（M5）。NJW1119A を上げるのは、ユーザーが全経路の硬い端を受けるときだけ
2. **NJW1194 を採る前に確かめること**（どれか 1 つでも外れたら 2 位へ）: (a) 少量で正規に買えるか（本査読では確かめられず）、(b) ユーザーが「DIRECT＝トーンを通さない（チップの中は通る）」を受け、V21-未決-14 の方針（PT2314E を迂回する経路を足す）を「チップを替えて迂回を無くす」に置き換えるか、(c) 電源の無い NJW1194 に源が入る運用を受けるか（p11 の注は「初期状態がおかしくなりうる」だけで、NJW1119A p3 のような禁止の書き方ではないが、入力の電流の規定も無い）
3. **制御は UI の MCP（0x22）の空き（GPB3〜GPB7 のうち 3 本）から**。Pico のピン・制御 MCP・A1 の決定はそのまま。3 本に外付けのプルダウン。PT2314E が居なくなれば BSS138 ×2 と 9 V のプルアップが外れ、I²C は 400 kbit/s にでき、MCP の Byte mode（BANK の設定に注意）で 1 語 約 1 ms〔計算〕。3 線は書くだけなので、ファームは状態を持ち、切替の手順の最後とトーンの変更のたびに全語を書き直す
4. **電源**は ±15 V から正負の LDO で ±7 V（±7.5 V を越えない品）、チップの近くに置き、特に −7 V（ロジックの基準）を近くで。LDO の DS を集める。−15 V の負荷が増えるのは [DEC] §3-10 に良い向き
5. **DIRECT の切替（TSW）は、既定では全リセットの窓の中で書く**（全娘の音声リレーが開いている間。出口の硬い端 0、代償は石の電源が 1 回落ちること）。「音量を絞る → TSW → 戻す」で窓を使わずに済むかは要実測で、済めば [DBR] §5.5 (5) と同じく全リセットを回さない形にできる
6. **起動と電源断**: 起動のたびに（規則①のきっかけで）全語を書き直す。任意で、`PD_12V_SW` の検知の立ち下がりで音量を MUTE に書く（DS p11 の注の手当て。コイルのパルスではないので規則②に触れない〔推論〕）
7. **決め直すもの**: V21-継-05（PT2314E・BSS138）、V21-継-08（ADC 前段の 6.19 k の前提）、[DEC] §6-2 の「PT2314E に 50 ms は I²C を送らない」「100 kbit/s」の行、トーンの外付けの網、SOIC-28W → SSOP32。**DIRECT のリレー一式（AZ850・TBD62083A 2 ch・AHCT・C_D・R_D・R_P）は外れ、制御 MCP は 13/16**
8. **少量で正規に買えないとき**は PT2314E＋DIRECT のリレー（[DBR] §0.2 のまま）。振幅の余裕だけを直したいなら PT2033（バイパス無し、min 2.5 Vrms、+0.7 dB〔計算〕）

### 0.3 外れる条件・要実測（対象 §5 に足すもの）

| 条件・実測 | 何が変わるか |
|---|---|
| 「音量を絞る → TSW → 戻す」で TSW の切替の段が聴こえない | 窓を使わない形（全リセットを回さない DIRECT の切替）にできる。聴こえるなら窓の中で |
| 使う源の出力インピーダンス（Rg）での L/R 分離 | NJW1194 の分離の数字の置き方（p22 のグラフ） |
| 電源の無い NJW1194 に源が鳴っているときの入力電流・出力への抜け、V+/V− の立ち上がりの順、電源投入から書き込みを受け付けるまでの時間 | 入口の直列抵抗の足場、起動の待ち |
| ロジック入力の電流（p7 の等価回路のトランジスタと 8 kΩ）、チップに電源が無い間に High を掛けたとき | 3 本の直列抵抗の足場（0 Ω で実装など）とプルダウンの値 |
| NJW1194 が少量で正規に買えない | 順位 1 が外れ、2（PT2314E＋リレー）が推奨になる |
| ユーザーが「DIRECT＝チップと電気的に無縁」を求める | どの候補でも足りない（対象のとおり）。形 1 |

## 2. 作業メモ（調べた順。§0 の根拠）

### M1. バイパスの有無（DS の画像で確かめた分）

- **NJW1194**〔DS p1 ブロック図・p8 応用回路、画像〕: 音量の抵抗ラダーのワイパ → **2 接点のスイッチ**（片方はワイパ直、片方は TONE ブロックの戻り）→ 出力アンプの＋入力、と**描かれている**。TONE ブロックの入力はワイパの節に付いたまま。制御は Treble 語の D10 `TSW`、0＝Tone Control OFF（初期値）〔p17〕。**TSW は 1 ビットで L/R 共通**（Treble 語は ch を分けていない〔p11・p17〕）。対象の「TSW で飛ぶ範囲の図は無く、ブロック図から読んだ〔推論〕」は**図がある**ので〔DS p1・p8〕に上げてよい
- 出力アンプの帰還の足に `DCCAP`（100 µF → GND）が入っている〔p8 画像〕。= 音量の段の切替の DC を止めるコンデンサで、**バイパスでも信号の帰還路にある**〔推論、図から〕
- 初期状態〔p11・p16・p17〕: 音量 2 本とも `11111111`＝MUTE、セレクタ `000`＝MUTE、TSW＝0（OFF）。対象と一致
- **NJW1119A**〔DS p1 ブロック図・p11 応用回路、画像〕: 入力 → **3 接点のスイッチ**（入力直／3Band TONE の戻り／GND）→ ユニティのフォロア → 出力、と描かれている。TSWa/TSWb（D10）と Mutea/Muteb（D9）は ch ごと〔p9〕。初期値は TSW＝0（OFF）、Mute＝1（ON）〔p9〕。**MUTE はフォロアの入力を GND へ倒す 1 接点**〔p1 画像〕→ 1 回で落ちる硬いミュート〔推論〕
- NJW1119A の `SWCA/B` は応用回路で 10 µF → **V−**（信号路ではない）〔p11 画像〕。DC は V−(sub)+0.7 V（TONE=OFF）〔p5〕。何の切替をどれだけ柔らかくするかは DS に無い（確かめられず）
- NJW1119A のチップアドレスは D3 D2 ＝ `11`（4 通り）〔p8〕、NJW1194 は `00`〔p11〕。**同じ 3 線に両方ぶら下げられる**〔推論〕
- 反証探し（除外品）:
  - ROHM BD37033FV-M・BD37512FS: レジスタ表（Select Address 01〜FE）に Bass/Middle/Treble の gain と setup しかなく、飛ばすビットは無い〔BD37033FV-M p11、BD37512FS p12〕。Advanced switch は「段の切替を柔らかくする」機能で、切替の経路ではない〔同〕 — 対象を支持
  - BD3490FV・BD3491FS: レジスタ表・機能説明に飛ばすモードは無い（"Surround off" "Gain=OFF" は surround の話）〔BD3491FS p4・p9〜p13〕 — 支持
  - NJW1201A: ブロック図（p1 画像）に TONE の周りのスイッチは無い。MonOut／RecOut／VOLIn（p20）は 1st 音量の外出しのループで、トーンを飛ばす経路ではない — 支持
  - TDA7439・TDA7468: `MUXOUT` → 外付け C → `IN` の外出しのループがある〔TDA7439 p1・p2〕。**MUXOUT は音量とトーンの両方の前**で、使うなら外で源を選ぶ素子（＝リレー）が要る。PT2314E の `LOUT/ROUT` と同じ類 — 支持（バイパスとして数えないのは正しい）
  - PT2033: データバイトの表は Volume・Speaker ATT・Audio switch・Bass・Treble だけ〔p7〕 — 支持
  - NJU7391A: トーンの符号は符号＋絶対値で `1000`＝+0 dB・`0000`＝−0 dB（初期値）〔p7〕。"BYPASS" は surround と入力利得の名だけ〔p8〕。EC の "TONE=OFF" はこの表のどれか定義されていない — 対象の「保留」を支持
  - PT2322: 抜粋 3 頁は特長と応用回路だけ〔抜粋 p1・p2〕。対象の「確かめられず」を支持。**リポジトリに無いので、Tone Defeat の中身・現行かは判断しない**

### M2. 性能の値の条件（NJW1194 p3〜p5 の画像、NJW1119A p3・p4 の画像）

- NJW1194 の EC の見出し "(Ta=25°C, V+/V−=±7V, RL=47kΩ, Volume=0dB, **TONE=OFF**, …)" は p3・p4・p5 の 3 表とも同じ〔画像〕。行の条件に TONE=ON と書いたもの（CS3・CS4・VNO1・THD1〜8・トーンの利得）だけが ON。**対象の読みを支持**
- ただし「保証」の中身: TONE=OFF の行で **min/max があるのは VOM（min 3.6 Vrms）・GV1（±0.5 dB）・CS1（max −90 dB）だけ**。VNO2（1.41 µV）・CT1・CT2・CS2 は **typ だけ**、THD は TONE=OFF の行が無い〔p3・p4〕。対象 §5 の「DS がバイパスの条件で振幅・雑音・分離を保証」は**雑音について言い過ぎ**（修正）
- NJW1119A は各行が条件を持つ（共通の見出しに Tone は無い）〔p3〕。Tone=OFF で min/max があるのは VOM（min 3.0）・GV（±0.5）・VNO1（**max 3.2 µV**）・CS1（max −90）。THD1 0.0002 % は **typ だけ**〔p4〕。ミュートは −116 typ / −104 max dB〔p3〕（対象に無い）
- PT2314E（[sw] §5）は THD に max（0.07 %、1 Vrms）がある。**保証値どうしで比べると、歪みは PT2314E にだけ上限があり、NJW の 2 品のバイパスには無い**。「歪みではっきり上」は typ どうし（またはグラフ）の比較と書くべき（修正、向きは変わらない）
- グラフ: NJW1194 p22「THD+N vs Frequency」2 Vrms・BW 10–80 kHz、TONE=OFF で 1 kHz 約 0.0015 %・10 kHz 約 0.004〜0.005 %〔画像で目読み〕— 対象と一致。p21「THD+N vs Input Voltage」TONE=OFF・1 kHz は約 1 Vrms で底（約 0.001 %）、約 3 Vrms で段が付いて約 0.006 % に上がり、約 4 Vrms で急増〔目読み〕。10 kHz は約 2 Vrms から上がり始める
- **L/R 分離は源インピーダンスで大きく変わる**（対象に無い）: p22「Channel Separation vs Frequency」TONE=OFF（BW 10–80 kHz、A 重みなし）は Rg=0 で約 −112 dB、**Rg=620 Ω で 1 kHz 約 −100 dB・10 kHz 約 −80 dB・20 kHz 約 −75 dB**、Rg=5.1 kΩ で 1 kHz 約 −90 dB〔目読み〕。表の −120 dB は Rg=0・A 重みの値。箱では源の出力インピーダンスがそのまま Rg になる（入力の結合 C の先に何も無い）〔推論〕。PT2314E には Rg 依存のグラフが無く、同じ比べ方はできない（確かめられず）
- 出力の負荷: p24「Output Voltage vs Load Resistance」（Vin 4.2 Vrms）で 約 400 Ω〜20 kΩ まで約 4.1 Vrms で平ら〔目読み〕→ `TONE` バスの負荷で振幅は落ちない〔推論〕
- 頁の小さな食い違い: 最大出力 vs 周波数のグラフは **p19**（対象は p20。p20 は vs 温度と周波数特性）

### M3. 振幅（2.3 Vrms の要件）

- NJW1194（±7 V）: 入力の絶対最大 VIM＝V+/V−〔p3〕→ 2.3 Vrms（3.25 Vpk）は内側、4 Vrms（5.66 Vpk）でも内側〔計算〕。VOM min 3.6 Vrms。**PT2314E の入力の絶対最大（3.24〜3.55 Vrms、[DBR] #6）の問題はこの石では消える**
- **箱全体の天井はチップでは決まらなくなる**（修正）: チップの余裕 +3.9 dB は石単体の話。次に頭を打つのは ADC（入力換算 2.73 Vrms、[DBR] #9）、推定 min の低い石の出力振幅（約 2.8 Vrms）、出力側 TMUX の膝（2.9〜3.5 Vrms〔仮定〕）で〔[DBR] §0.2-5〕、**聴く経路の天井は 2.3 → 約 2.8〜2.9 Vrms（+1.7〜+2 dB）までしか上がらない**〔計算〕。対象 §3 の表の最後の行はこれを書いているが、冒頭の表と §4 の「+3.9 dB」は箱の余裕のように読める
- V21-継-08（ADC 前段の 6.19 k は PT2314E の VOMAX typ 2.6 Vrms で決めた）は前提が変わる。ADC は「本線を汚さないことが優先・絶対の品質は求めない」（[DEC] §4-2）ので、2.73 Vrms を越える源で ADC だけが頭を打つのは受けられる向き〔推論〕。定数を直すかはユーザー
- トーンを上げたとき（見落とし）: 2.3 Vrms の入力で Bass +10 dB なら出力は約 7.3 Vrms で VOM を越える〔計算〕。NJW1194 は**音量がトーンの前**にある〔p1・p8〕ので、ファームで「音量 ＝ −(最大の持ち上げ量)」にすれば頭を打たない〔推論〕。NJW1119A は前に絞る素子が無く、+12 dB で 2.3 Vrms は約 9.2 Vrms になる〔計算〕。PT2314E も音量がトーンの前だが、今は 0 dB 固定（V21-継-05）

### M4. 電源と制御

- 電源: ±4.5〜±7.5 V、絶対最大 ±8 V〔NJW1194 p3〕。±15 V から正負の 3 端子で ±7 V を作る形〔推論〕。部品（78L07／79L07 級、LM317／337 など）の DS はリポジトリに無い — **確かめられず**。±5 % の 7 V なら 7.35 V で ±7.5 V の内〔計算〕。V+ と V− の立ち上がりの順の規定は DS に無い（確かめられず）
- 負荷: NJW1194 は 12 typ / 17 max mA を**各レール**〔p3〕。今の PT2314E は +15 V だけに 35〜48 mA（[DEC] §3-4）。替えると +15 V は約 20〜30 mA 軽くなり、−15 V は 12〜17 mA（＋レギュレータの自己消費）重くなる〔計算〕。**−15 V が軽すぎて RS6 のクロスレギュレーションの 25 % を割りうる件（[DEC] §3-10、プリロードの足場）には良い向き**〔推論〕。対象はこれを「−15 V 側にも負荷が増える」と費用側だけに書いている（補足）
- グランドの木: ±15 V から LDO で作るので、[DEC] §3-4 の理由（PT2314E を PD 側へ移すと帰りが唯一の橋を通る）とは衝突しない〔推論〕
- 内部のロジックは **V− を基準**に動く: VDDOUT ＝ V−(sub)+5 V〔p6〕、応用回路で 10 µF を VDDOUT–V− 間〔p8〕。ロジックのしきい値は GND 基準（VIH 2.5〜V+、VIL 0〜1.5 V〔p5〕）。**3 線の書き込みの電流は −7 V のレールに戻る**〔推論〕→ −7 V のレギュレータはチップの近く
- ロジック入力の等価回路〔p7 画像〕: ピン → 4 kΩ → PMOS のゲート、ピンに V−(sub) へのダイオードとトランジスタ＋8 kΩ（GND へ）。**V+ へのダイオードは描かれていない**。入力電流（IIH）の規定は無い — 確かめられず。チップに電源が無い間に High を掛けたときどこへ流れるかも DS からは決まらない
- 3.3 V で駆動できるか: VIH min 2.5 V。MCP23017 の VOH は VDD−0.7 V（IOH −3 mA @4.5 V、−400 µA @1.8 V）で、3.3 V の条件の値は無い（[sw] §4）。3.3 V・軽負荷なら 2.6 V を下回らない読み〔推論〕。余裕は 0.1 V〜（負荷しだい）。対象の「そのままつなげる」は支持、余裕は薄いと補う
- **制御は書くだけ**（見落とし）: 3 線（DATA/CLOCK/LATCH）には ACK も読み出しも無い〔p11〕。[DEC] §2-16 の「書いたら読み返す」を**このチップには使えない**。書き損じ・電源の無い間の書き込みは黙って失われる〔推論〕→ ファームは状態を持ち、切替の手順の最後・BASS/TREBLE の変更のたびに 5 語（NJW1194）を全部書き直すのが筋〔推論〕。電源投入から書き込みを受け付けるまでの時間は DS に無い（PT2314E の 50 ms に当たるもの。確かめられず）
- タイミング: クロック幅 min 4 µs、High/Low min 2 µs、LATCH の High min 1.6 µs〔p11〕→ 最速でも 1 語 約 70 µs〔計算〕
- **3 本の出どころ**（[DEC] §2-16: Pico の空き 1 本、制御 MCP は M 案で 15/16）:
  - **UI の MCP23017（0x22）に空きが 5 本ある**〔SF pin U1610: GPB3〜GPB7（4〜8 番）がどのネットにも載っていない。GPB0＝`ENC3_SW`、GPB1/2＝`LED_DEST2/1`〕（v2 から写した図のまま）。対象は「数は図から数えていない」とした — **ここで数えた: 5 本**。Pico のピンも制御 MCP も使わずに 3 本が出る
  - UI の MCP で打つ場合の速さ〔計算〕: 1 エッジ ＝ 1 回の書き込みだと 1 語で約 50 回。100 kbit/s で 1 回 約 0.29 ms（[DBR] §5.4）→ 1 語 約 15 ms、0.5 dB で 0 → −40 dB の 80 語は約 1.2 s。**MCP の Byte mode（IOCON.SEQOP）なら 1 回の転送で OLAT を続けて書ける**（"useful for … continually writing to the output latches"、ただし BANK=0 では A/B が交互になる〔Microchip_MCP23017 p12 §3.2.1〕）→ 1 語 約 50 バイトで、400 kbit/s なら約 1 ms〔計算〕。400 kbit/s は、今 100 kbit/s に縛っている PT2314E（[DEC] §6-2）が居なくなれば選べる〔推論〕
  - **UI の MCP のバスに PT2314E が居なくなる効き**〔推論〕: BSS138 ×2 と 9 V 側のプルアップ（V21-継-05）が不要になり、「±15 V が無い間は UI の MCP が読めない」（[DEC] §2-16 の前提の箇条、[評] §1.10）の原因が消える。さらに、今は UI の MCP を読むたびに SCL/SDA のエッジが PT2314E の足に来るが、3 線にすれば**音声チップの足に来るのは書き込みのときだけ**になる（[DEC] §2-12 と同じ考え）
  - 制御 MCP の 3 本（DIRECT のリレーが無くなれば 13/16 で余り 3）: 数は合うが勧めない。制御 MCP は専用バス・「UI の誤った書き込みで制御 MCP を動かしうる経路を遠ざける」ためのもの（[DEC] §2-16）で、トーンの書き込みは UI 発。しかも 13 本の制御線と同じポートのレジスタ（OLATA/B）を毎エッジ書き直すことになる〔推論〕
  - Pico の SPI（LCD）と DATA/CLOCK を共用し LATCH だけ Pico の空き 1 本: 本数は入るが、LCD の転送のたびにクロックが音声チップへ来る（[DEC] §2-12 の形）。DS の "Set CLOCK in High … during a standby period"〔p11〕も SPI の待機レベルしだい。勧めない〔推論〕
  - → **A1 の決定（[DEC] §2-16）は動かさずに済む**〔推論。UI の MCP の空きを使う前提〕。対象の「外れる条件」の 3 行目は、UI の MCP を第一候補として書き直すべき（修正）

### M5. DIRECT への効き（[DBR] §5・§7.2 と照らす）

- **形 1・形 2 のリレーが要らなくなる** — 条件つき支持。条件は「DIRECT ＝ トーンを通さない」で、「チップと電気的に無縁」ではないこと（対象のとおり）。もう一つ、**V21-未決-14 の方針（ユーザー 2026-09-25）は「PT2314E を迂回する経路と、その切替を足す」**で、チップを替えて迂回を無くす形はこの方針の前提を動かす。ユーザーの判断が要る（対象は §5 の外れる条件の 1 行目でだけ触れている）
- **DIRECT で聴いたままの ch 替えの硬い端 2（[DEC] §2-10・[DBR] §5.3）は NJW1194 なら消える** — 支持。TSW＝0 でも音量のラダーがワイパの前にあり〔p1・p8〕、切替の手順の S1/S11（音量を段階で絞る／戻す）がそのまま DIRECT にも効く〔推論〕。0.5 dB 刻み〔p12〜p16〕は PT2314E の 1.25 dB より細かい
- **DIRECT の切替そのもの（TSW の書き換え）は「音量で絞れば静か」とは言えない**（修正）:
  - TSW のスイッチは**音量のラダーの後ろ、出力アンプの＋入力の直前**にある〔p1・p8 画像〕。音量を MUTE まで絞っても、TSW の切り替わりで出る段（ワイパの節と TONE の戻りの節の DC の差、スイッチの電荷）はラダーで減らない〔推論〕
  - 注 "When switching TSW(Tone Control By-pass Switch), use MUTE **on the set**."〔p8〕の "on the set" は「セット（機器）の側で」と読める。ROHM の同じ形の注 "please apply mute **on the side of a set** when changes these setting"（Advanced switch の効かない機能について）〔BD37033FV-M p11、BD37512FS p12〕と同じ言い回し〔推論〕。**チップ自身の MUTE で足りるとは DS は言っていない**。対象 §3 の「DS の注にしたがって、MUTE（音量を段階で絞る）→ TSW → 戻す」はこの読みを飛ばしている
  - 箱の「セット側のミュート」に当たるのは、**全娘の音声リレーが開いている窓**（全リセットの中、[DEC] §6-2）。TSW をこの窓の中で書き、音声 SET の後に音量を段階で戻せば、出口に出る硬い端は **0**〔推論〕。代わりに石の電源が 1 回落ちる（熱の整定のやり直し、[DBR] §5.5 の (5) の比較と同じ代償）
  - 窓を使わず「音量を絞る → TSW → 戻す」で済むか（端 0 か、小さな段が残るか）は**要実測**。済むなら [DBR] §5.5 (5) と同じく全リセットを回さずに切り替えられ、リレー版の「端 1（本質）」より良い
  - ゼロクロス検出は特長とブロック図にあるだけで、有効にするビットも、何の切替に効くかも、待ちの上限も書かれていない〔p1・p8・p11〕— 対象の「確かめられず」を支持
- 数の比較〔推論〕:

| 操作 | PT2314E＋DIRECT のリレー（[DBR] §5.5） | NJW1194（TSW） |
|---|---:|---:|
| PT/トーン経由で ch 替え | 0 | 0 |
| DIRECT で ch 替え | **2（本質）** | 0（音量で絞れる） |
| DIRECT の切替 | 1（本質） | 窓の中なら 0（石の電源が落ちる）／窓の外は要実測 |

- **電源断の DIRECT の形（[DBR] §7.2、#24）は消える**〔推論〕: 源 → C_D → `TONE` と直につながる枝が無くなり、`TONE` の源はいつも電源の無いチップの出力になる。これは [DBR] §7.2 が「PT 経由で切ったときは起きない」とした形と同じ。電源の無いチップの入力から出力へどれだけ抜けるかは DS に無い（確かめられず）— 対象は「確かめられず（要実測）」で止めているが、**リレー版より悪くならない**ことまでは言える（補足）
- ただし入力側の電源断の扱いは変わらない: 入力ピンは V+ と V−(sub) へのダイオード〔NJW1194 p6 画像、NJW1119A p5〕で、電源の無いチップの入力は今の PT2314E と同じく源を受ける。PT2314E には Iin ±100 mA（ラッチアップ）の規定がある（[DBR] #7）が、**NJW の 2 品には電流の規定が無い**（確かめられず）。NJW1119A の注は "Any signal **must not** be inputted on the power 'off'"〔p3〕で、禁止の書き方（帰結として書いてあるのは DATA CONTROL の初期状態だけ）。箱は源を止められないので、**この注は形 1（入口でも切る）なしには守れない**〔推論〕— 対象は要実測に置いているが、NJW1119A については DS の使用条件に反する運用になると書くべき（修正）
- NJW1194 の注〔p11〕の手当て「電源を切る前に MUTE にする」は、箱では電源断を制御できない（対象のとおり）。ただし [DEC] §5-7 の `PD_12V_SW` の検知の立ち下がりで、Pico が生きている間に音量 2 語を MUTE に書く（Pico の GPIO なら約 0.15 ms、UI の MCP 経由なら 400 kbit/s の Byte mode で約 2 ms・100 kbit/s の 1 エッジ 1 回で約 30 ms〔計算〕）ことはできる〔推論〕。コイルのパルスではないので規則②（検知が無い間はパルスを出さない）の例外にもならない〔推論〕。ホールドアップの時間は要実測
- 並列の PT の入力の保護ダイオードが源の頭を丸める件（[DBR] #8・#13）は、並列の枝が無くなるので消える — 対象を支持
- DIRECT のリレーまわりの削れるもの（AZ850 1 個、制御線 2 本、親の TBD62083A 2 ch、AHCT 1 段、C_D・R_D・R_P、[DBR] §0.2-2 の足場）— 支持。制御 MCP は 13/16 に戻る

### M6. 見落とし・入手性

- **入手性の根拠**: 「Digi-Key 最小 2,000 個・12 週」「秋月に無い」は対象の書き手が 2026-09-26 に web で見たもので、**リポジトリに写しが無い — 確かめられず**。本査読の時点で Digi-Key は自動取得を拒否（403）、秋月は検索の URL が合わず判定できなかった。どちらも否定の証拠ではない
- **少量で正規に買えないなら**: 1 位・2 位とも崩れる（対象のとおり）。そのときの順位は 1. PT2314E＋DIRECT のリレー（今の査読どおり）、2. PT2033（振幅の余裕だけの改善、バイパス無し）。AliExpress 品を 1 位の前提にしない（偽物・再生品の見分けが DS ではつかない）〔推論〕
- 起動時の既定: NJW1194 は音量 MUTE・セレクタ MUTE・TSW OFF〔p11・p16・p17〕、NJW1119A は Mute ON・TSW OFF〔p9〕。**POR で黙る状態が DS で決まっている**のは PT2314E（POR 直後のレジスタ値が DS に無い、[DBR] §2）より良い（対象に無い利点）。ファームが止まって書かなければ無音
- UI の MCP で打つなら、MCP の POR は全ピン入力（Hi-Z）（[sw] §4）→ 3 本に外付けのプルダウン（または LATCH だけでも）を置き、チップに電源が無い間は Low に保つ〔推論〕。DS の「待機中は CLOCK を High に」〔p11〕と、電源の無い間の Low は、検知（[DEC] §5-7）の有無で使い分ける〔推論〕
- 音量 0 dB 固定（V21-継-05）で使うこと: EC はすべて VOL＝0 dB の条件〔p3〕なので、0 dB 固定の使い方はそのまま表の条件に当たる — 問題は見当たらない。V21-継-02 の「音量 IC を信号経路に入れない」は**手回しのポットの代わりに音量 IC を使わない**という決めで、PT2314E と同じく 0 dB 固定・切替の絞りだけに使うなら反しない〔推論〕。ただし NJW1194 の本職は電子ボリュームで、音量は抵抗ラダー＋出力アンプの利得の組で作っている〔p1・p8〕ので、0 dB でも**ラダーとアンプの帰還網は経路にいる**（`DCCAP` 100 µF も帰還の足〔p8〕）。「トーンだけ飛ぶ」の実体はこれ
- TSW は **L/R 共通の 1 ビット**〔p17〕（NJW1119A は ch ごと〔p9〕）。DIRECT はステレオで切るので困らない
- 使わない入力（In2〜4）の処理は DS に無い（応用回路は 4 本とも 10 µF で描いている〔p8〕）— 確かめられず
- パッケージ: SSOP32・0.65 mm〔p1〕。外形寸法（11 × 7.6 mm）は DS に無く、対象が別の資料から書いた（リポジトリに無い — 確かめられず）。娘に TSSOP の TMUX7612 がすでに載っているので、手付けの難しさとしては新しい種類ではない〔推論〕。ルートの SOIC-28W の場所を描き直す（対象のとおり）
- 入力の結合: 入力抵抗 min 15 kΩ〔p3〕と今の 2.2 µF で 4.8 Hz〔計算〕。I/O の DC は 0 V〔p6〕だが出力のオフセットの規定は無い → 出力の結合 C は残す〔推論〕
