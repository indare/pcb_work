## 0. 比べる前に: 目標 −106 dBc をどう使うか

### 0.1 この −106 は「差の再現性」であって「鎖の絶対歪み」ではない

- −106 dBc は、同じ石を抜き差ししたときの **H3 の複素差ベクトル**の 3σ 検出限界（`dbc = 20·log10(ah/a1)`）[TF:L208–213]。
  限界を決めたのはソケットの再現性で、測定雑音のみの 3σ は約 −111 dBc [TF:L199–204]
- **同じ v1 の系は、ベースライン H3 が −76 dBc（仮配線由来、DUT の歪みではない）のまま −106 の差を検出していた** [TF:L229–232、L247]
- **ADC 自身の歪みも −106 より大きい**: PCM1804 の THD+N は −0.5 dB 入力・fs 48 kHz で **−102 dB typ / −95 dB max** [DS TI_PCM1804.pdf p7]

→ だから判定の軸は 2 本に分ける:

| 軸 | 何を見るか | DS で答えられるか |
|---|---|---|
| **A（絶対）** | 結合部そのものの H2/H3 が −106 dBc より下か。下なら「鎖の歪みが ADC より目立たない」 | 答えられる（DS が個別高調波を出している部品だけ。THD / THD+N しか無い部品は上限としてだけ使える） |
| **B（差）** | 高調波ビンの雑音、鎖の歪みの**安定性**（温度・時間・振幅）、帯域内スパー、DUT にかける負荷の変化 | **安定性はどの DS にも無い**。雑音だけは計算できる |

〔推論〕実際に −106 を縛るのは B。A は「ADC（−102 dB typ の THD+N）より悪くしない」ための目安で、A を満たさなくても B が満たせる場合がある（v1 の −76 dBc ベースラインがその実例）。
ただし A を大きく外す部品（Q3 の −80〜−93 dB）は、ベースラインが鎖で決まり、その安定性が DS で分からないので、B の保証も付けられない。

### 0.2 v2.1 での信号レベル（[計算]）

- ADC フルスケールのバス換算 = **5.47 Vrms**（前段入力抵抗 6.19k、差動ゲイン 0.323）[DEC:424–426][TF:L70–71]
- −3.4 dBFS の基本波 = 5.47 × 10^(−3.4/20) = **3.70 Vrms（5.23 Vpk、+13.6 dBu）** がバスに乗る
- ⚠ v1 で −106 を出したときは前段ゲイン 0.606、バス 約 1.97 Vrms だった [TF:L211]。**同じ石・同じ −3.4 dBFS でも、v2.1 のバスは約 5.4 dB 大きい**（DEC:429 の「感度は 5.4 dB 落ちる」の裏返し）
- 結合部は最大でフルスケール 5.47 Vrms（7.7 Vpk）を歪まずに通す必要がある。バスに出る最大は PT2314E typ で 5.2 Vrms [DEC:411, 427]

### 0.3 高調波ビンの雑音の物差し（[計算]、付録 A）

解析は Hann 窓・n = 16384・fs = 48 kHz [`Audio/measurement_fw/capture_raw.py`:49、`analyze_thd.py`:127–141]。
白色雑音密度 e（バス換算 V/√Hz）が H3 の推定値に作る 1 キャプチャあたりの 1σ は **20·log10(2.965·e / 5.23 V) dBc**。

## 2. 方式ごとの詳細

### 2.1 Q1 現行（抵抗・バッファのシングルエンド）

**構成**（すべて [SF] 経由の [TF:L51–65]）: `U1611`（OPA1656）ユニティフォロワ、入力バイアス 100k → `A_GND`、出力抵抗なし →
`U1602` 反転（4.7k/4.7k 0.1 %、+IN = `A_GND`）→ 10 µF NP で AC 結合 → `U1608`/`U1601` の反転 LPF（6.19k / 1k ∥ 1.8 nF、+IN = `VCOML`/`VCOMR`）→ 47 Ω → `A1601`（PCM1804）。
VCOM は LPF ドライバの +IN と 100 nF（→ `ADC_GND`）にしか使っておらず、タップ側の基準（`U1602` +IN）は `A_GND`。v1 も同じ [TF:L78–83, L158–160]。

1. **歪み・雑音**
   - DS: OPA1656 の THD+N **−131 dB**（G = 1、RL = 2 kΩ、3.5 Vrms、1 kHz、80 kHz 帯域）[DS TI_OPA1656.pdf p6]。雑音 4.3 nV/√Hz @1 kHz [同 p6]
   - [計算] 前段全体の雑音はバス換算 30 nV/√Hz、H3 推定の 1σ は −155 dBc/キャプチャ（§0.3）
   - 実測: v1 は同じトポロジ（v1 は OPA1652＋47 Ω、入力抵抗 3.3k）で −106 dBc を出した [TF:L153–157, L180–206]。**ただし n = 1・仮配線・v1 の前段ゲイン** [TF:L220–221]
   - DS が低域を覆うか: OPA1656 は 1 kHz と 20 kHz の表値（20 kHz で −129 dB）[DS TI_OPA1656.pdf p6]。低域の規定は読んでいない
2. **負荷と本線への影響**
   - バス 40.7 kΩ（タップ無し）→ **28.9 kΩ** [TF:L133–136]。`C601` 2.2 µF との −3 dB は 2.5 Hz [TF:L145][計算]
   - [SIM] TMUX7612 の H3（出力 Vrms / 負荷）: 9.2 Vrms・30.4 kΩ で −115.5 dB（DEC:398 と一致）、**3.7 Vrms・30.4 kΩ で −170 dB、5.47 Vrms で −179 dB**。
     試験レベルでは負荷の影響は TMUX に関しては無視できる。9.2 Vrms は v2.1 のソケット ±12 V [NOW:L14] では出ない振幅〔推論〕
   - 残る影響は **DUT 自身が見る負荷**（全 DUT の動作点）[DEC:376–377]。どの DUT にも同じなので、比較器としては一定なら困らない〔推論〕
   - CMRR: Vg（`A_GND` 上の電位差）の除去は、両脚をバッファで揃えて **約 43 dB（20 Hz〜20 kHz、理想オペアンプ・集中定数、確度: 中）**[DEC:309–316, 370]。次の律速は抵抗公差で 54 dB の床 [DEC:321–322]
3. **グランド**: ガルバニック。`ADC_GND`–`A_GND` は `NT1601` 1 点 [TF:L80–81]、木は `ADC_GND─NT1601─A_GND─NT1603─D_GND─NT1602─PD_GND` [TF:L101–106]。
   タップの界面は `AUDIO_L_IN`/`AUDIO_R_IN`/`A_GND` の 3 本で、音声専用の帰り・センス線は無い [TF:L76–77]。ジャックの GND（`J_HP501.2` など）は 156 ピンの `A_GND` の一部 [TF:L79]
4. **ADC 電源への含意**: ADC の基準は `A_GND` に 1 点で結ぶ前提。
   PD 12 V から取ると ADC の直流 61〜87 mA が `NT1601`→`A_GND`→`NT1603` と音声グランドを流れる [RRR:L18]。いまの図の `+15V` → LT1763 なら ±15 V の COM へ戻る [TF:L116–117]。
   「PD から取る」は NOW で取り消し線になっている（見直し中）[NOW:L10]
5. **追加部品**: なし（`U1611`/`U1602`/`U1601`/`U1608` の OPA1656 ×4 は既存 [TF:L115]）
6. **未知と確かめ方**
   - Vg の帯域内成分（特に H2/H3 のビン）。43 dB の除去は計算で、Vg 自体を測った記録は無い
   - 〔推論〕一番安い方法: 試作（か v1）で **タップ入力を ① MeasureControl の `A_GND` で短絡、② 選択 ch の出力側グランド（`R603` の足、またはジャック `J_RAIL501.2`）で短絡** の 2 通りで無信号を撮り、H2/H3 ビンと 1205 Hz 系スパーの差を見る。差が床以下なら Vg は効いておらず、Q2 の出番は無い。部品は短絡線だけ

5. **追加部品・電源・リスク**: INA1650 は **dual・TSSOP-14（4.40 × 5.00 mm）** [DS TI_INA1650.pdf p1] で L/R が 1 個。静止電流 10.5 typ / 12 max mA [tap:L104]（±15 V。1 ch 通電の +15 V typ 91.1 / max 110.8 mA [RR:L141] に足される）。GND センス線 1 本（母板↔MC の界面にシートピン 1 本 → ルートのシートシンボルにも要る。CLAUDE.md の注意）。
   リスクは小さい〔推論〕: 増えるのは線形素子 1 段
6. **未知と確かめ方**: Q1 の ⑥ と同じ測定で決まる。**Vg が H2/H3 ビンで床以下なら、Q2 は効果の無い保険**。効いていれば、INA1650 をブレークアウトで v1 の AdcBuffer 位置に挟んで A-B-A

### 2.4 Q4 ADC を音声側に置き、デジタルを絶縁

**回路図の事実**（このセッションの [SF nets]）:

- `ADC_MCLK` は `A1601.7` / `R1604.2`（33 Ω）/ `TP1601.1` の **3 ピンだけ**。源は `Y1601`（**ASFL1-12.288MHZ**、電源 `+3V3_A`、GND `ADC_GND`）[SF pin Y1601]。**MCLK は Pico へ行っていない**
- Pico（`A1602`）へ渡るのは `ADC_DATA`（A1601.10→A1602.1）、`ADC_BCK`（.9→.2）、`ADC_LRCK`（.8→.4）の 3 本（ADC → Pico）と、`ADC_nMR`（A1602.20 → `U1605.7`、Pico → ADC 側の監視 IC）の 1 本。`ADC_nRST` は `U1605.5` と `R1611` で ADC 側に閉じている [SF nets ADC_nRST / ADC_nMR]
- PCM1804 はマスター動作（記録 [DEC:454]）。マスターでは BCK 周期が 1/(64 fS) に固定 [DS TI_PCM1804.pdf p23, Figure 37 注 (3)]。fS = 48 kHz（12.288 MHz = 256 fS、キャプチャのヘッダ `fs_nominal 48000`）で **BCK = 3.072 MHz、周期 325.5 ns** [計算]。
  （記録の食い違い: DEC:3375 は「BCK 6.144 MHz」、DEC:454 と DEC:1336 は 3.072 MHz。DS の 64 fS からは 3.072 MHz。6.144 MHz はシングルレートの変調器の周波数 128 fS [DS TI_PCM1804.pdf p19 Table 3 注 (2)] と同じ値）
- 24.576 MHz は fS = 48 kHz の 512 fS（または 96 kHz の 256 fS）の SCKI として DS の表にある値 [DS TI_PCM1804.pdf p19 Table 3]。今の `Y1601` は 12.288 MHz ＝ 256 fS

→ **依頼文の「24.576 MHz の MCLK を ISO7741（50 Mbps max）に通す」は、今の回路図では起きない。** 通すのは BCK 3.072 MHz（照合者の数え方で 6.144 Mbps [ver:L41]）以下の 3 本で、ISO7741 の表の 50 Mbps [tap:L464] に対して 12 %。
24.576 MHz の MCLK を渡すのは「Pico がクロック源になるスレーブ動作」か fS = 96 kHz に変えた場合で、そのとき 49.152 Mbps 対 50 Mbps で **余裕 2 % 弱** [ver:L41]、しかもアイソレータのジッタが**サンプリング・クロックに直接乗る**〔推論〕。
参考: tie 1.3 ns（ISO7741、100 Mbps PRBS）を仮に rms ジッタとみなすと −20·log10(2π·1320 Hz·1.3 ns) = **−99 dB**（基本波に対する全帯域の雑音）[計算]。PCM1804 の SNR 111 dB より悪い。tie は PRBS データの時間間隔誤差でクロックのジッタとは定義が違う [tap:L605] ので上限の目安にすぎない。**MCLK は ADC 側に置いたままにする**のが前提〔推論〕

1. **歪み・雑音**: アナログ経路は Q1（か Q2）のまま変わらない。**マスター動作・ローカル水晶のままなら、アイソレータの遅延・ジッタは Pico 側のデータ取り込みのタイミングを動かすだけで、変換には乗らない**〔推論、上の回路図の事実から〕。
   タイミング: ISO7741 の伝搬遅延 max 18.5 ns（3.3 V）、同方向チャネル間スキュー tsk(o) max 4.4 ns、PWD max 5.9 ns [tap:L465–468]。PCM1804 の BCK→DATA は −5〜15 ns [DS TI_PCM1804.pdf p23]。半周期 162.8 ns に対して十分〔計算・推論〕
2. **負荷**: Q1/Q2 と同じ
3. **グランド**: ISO7741 の障壁 ≅1 pF [tap:L469]。ただし **`NT1603`（`A_GND`–`D_GND`）が残る限りガルバニックには切れない** [RR:L61, L63–64]。
   〔推論〕切らなくても意味はある: 今は ADC の出力段が Pico の入力容量を直接駆動し、その帰り電流が `ADC_GND` を流れる（記録の「本命」の経路 [DEC:3375]）。アイソレータを挟むと、ADC 側は ADC→アイソレータ入力で閉じ、Pico 側はアイソレータ出力段（Pico の 3V3 から給電）で閉じる。
   本当に切る（(b-2)）なら、境界を渡る信号は I²S だけでなく PT2314E の I²C・娘 MCP の制御線もある [RR:L123]（ISO1540 1 MHz / ADuM1250 1000 kHz / Si860x 1.7 MHz [tap:L493, L504, L544]。I²C は Standard 100 kbit/s で足りる [RR:L129]）。それはタップの選択ではなく箱全体の (b-2) の決定
4. **ADC 電源への含意**: **ADC は音声側に固定**。
   - 今の図のまま（`+15V` → LT1763-3.3 / LT1763-5、GND `ADC_GND`）[TF:L116–117] で成り立つ。追加の DC-DC は要らない
   - 代償は ±15 V の余裕: ADC を +15 V に載せると、RS6-1215D で 1 ch・最悪の石で 98.9 %（定格の内側だが余裕が無い）、TMR 9-1223 なら 65.9 % [RR:L125, L156][RRR:L19]
   - ISOW7741 で ADC 側の電源を作る案: VISOOUT は 5 V 設定で 0〜110 mA のとき **4.5 V min**、0〜55 mA のとき 4.75 V min [tap:L580][ver:L522]。PCM1804 の VCC は **4.75 V min** [SC:L334]。**110 mA 行では VCC の下限を割り、55 mA 行でちょうど下限**。PCM1804 の ICC 35 / 45 mA [SC:L339] に発振器・監視 IC・モジュールの分が乗る（モジュールとしての電流は DS に無い [SC:L359]）。〔推論〕直接給電には使いにくい
   - ADuM5401 も VISO 4.7 V min（5 V 出力）[tap:L557] で同じく下限を割る
5. **追加部品・リスク**
   - **ISO7741 は 3 順 1 逆** [tap:L457] で、ADC→Pico 3 本＋Pico→ADC 1 本（`ADC_nMR`）にちょうど合う。電源電流は 10 Mbps で ICC1 3.5 / 5.2、ICC2 3.7 / 5.8 mA（3.3 V）[tap:L470]

## 付録 A. 計算の式

- **高調波推定値の雑音**: `analyze()` は Hann 窓 w（Σw = n/2、Σw² = 3n/8）の DTFT 振幅を 2|X|/Σw で正規化する [`analyze_thd.py`:127–141]。
  片側密度 e の白色雑音で E|X|² = (e²·fs/2)·Σw² なので、振幅の rms は e·√(3·fs/n)。fs = 48 kHz、n = 16384 で **2.965·e**。
  基本波振幅 A1 = √2 × 3.698 = 5.230 Vpk。dBc = 20·log10(2.965·e / 5.230)
- **8 回複素平均・3σ**: 1σ − 10·log10(8) + 20·log10(3) = 1σ + 0.51 dB（ランダム雑音だけのモデル。スパーは平均で下がらない [BU:190–193]）
- **PCM1804 の雑音密度**: 1.768 Vrms（差動 5 Vpp のフルスケール）× 10^(−111/20) ÷ √20 kHz = 35.2 nV/√Hz（ADC 入力）、÷ 0.323 = 109 nV/√Hz（バス）。A 特性の SNR を平坦とみなしたので、平坦な雑音ならこれより数 dB 大きい
- **現行前段の雑音**: 熱雑音 √(4kTR)（300 K）で 1k 4.07、4.7k 8.82、6.19k 10.13 nV/√Hz。
  LPF 1 段 = √((10.13·0.1616)² + 4.07² + (4.3·1.1616)²)、`U1602` = √((2·4.3)² + 2·8.82²) × 0.1616、`U1611` = 4.3 × 0.323。差動で二乗和 9.81 nV/√Hz → ÷ 0.323 = 30.4 nV/√Hz
- **絶縁アンプの減衰**: バスのフルスケール 5.47 Vrms = 7.74 Vpk を ±1 V（AMC3330）/ 2 V 幅（AMC1311）に入れるので 1/7.74。±250 mV で 1/31、±200 mV で 1/38.7
- **INA1650 の不整合 CMRR**: 本文の 92 dB → 83.7 dB（20 Ω、RCOM = 0）[tap:L99] を振幅で線形加算とみて 1/CMRR = 10^(−92/20) + ΔZ/R_eq、R_eq = 20 / (10^(−83.7/20) − 10^(−92/20)) = 497 kΩ。ΔZ に [DEC:309–313] の |Zs| を入れた
- **INA1620 の差動アンプ CMRR**: G = 1 で CMRR ≈ 2/δ（δ = 2 つの比の不整合）。対内 2 × 0.004 % → 88 dB、2 × 0.02 % → 74 dB、対の外 0.3 % → 56.5 dB
- **バス負荷**: 50k ∥ 220k ∥ Z。`C601` との −3 dB = 1/(2π·Z·2.2 µF)
- **ジッタの目安**: SNR ≈ −20·log10(2π·f·tj)
