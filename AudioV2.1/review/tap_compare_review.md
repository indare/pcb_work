## 0. 結論（先に）

1. **回路図の主張（MCLK・BCK・渡る線・ISO7741 の 3 順 1 逆）は全部合っている。** ただしマスター動作は回路図では確かめられない（モジュールのジャンパで決まる）。ファームとも合う
2. **比較文書の第 1 位の理由が、別の Vg を比べている。** 記録の「約 43 dB」は `A_GND`↔`ADC_GND`（`NT1601` の両側）の差の除去で、Q2 の GND センスが落とすのは **ch 側グランド↔MC 側 `A_GND`** の差。後者は Q1 では **0 dB**（信号と直列）。しかも 43 dB は 47 Ω 付きの構成の値らしく、今の図（47 Ω 無し）には当てはまらない
3. **0.1 節の「−106 は差の再現性」という枠組みは正しいが、比較文書自身がそれを順位に使っていない。** A 軸（絶対歪み）の余裕は Q2 の強みにも Q3 の欠点にもならない（v1 は −76 dBc の鎖のベースラインで −106 の差を出した）。順位は B 軸（雑音・安定性）・実績・費用で決めるべき
4. **試験レベル 3.70 Vrms（−3.4 dBFS）は仮定。** v1 と同じバス振幅（約 1.97 Vrms）で撮ると ADC は −8.8 dBFS になり、雑音だけの 3σ は v1 の −111 から **約 −105.5 dBc** に上がって目標を割る [計算]。ここはユーザーの決定
5. **JT-11P-1 の「1 kHz <0.001 %」は TYPICAL 列で、上限（保証）ではない。** 一方「+13.6 dBu の DS は無い」も誤りで、左の図に +14 dBu（と +20 dBu）の曲線があり、どちらも約 400〜600 Hz 以上で図の下端 0.001 % を下回る
6. **ISO224 の雑音は DS の中で 3 倍食い違う**（入力換算 3 µV/√Hz 対 出力 300 µVrms/10 kHz ÷ 利得 1/3 ＝ 入力換算 9 µV/√Hz）。後者なら雑音だけで −106 を割る。Q3 最下位の結論は変わらないが、理由が変わる
7. **Q4 の「本命」[DEC:3375] は ADC 自身の床の話で、音声出力への漏れの記録ではない。** Q4 を確かめる「リセット保持の A-B-A」は、保持が 1.37 s を超えると PCM1804 がパワーダウンに入り、アナログ電流も変わるので切り分けにならない
8. **修正後の順位: 1 Q1（現行）、2 Q2（INA1650、実験で Vg が出たときだけ）、別枠 Q4（−106 には効く根拠が無い）、3 Q5、4 Q3。**

## 2. 主な指摘（表の補足）

### 2.1 第 1 位の理由は二つの Vg を混ぜている（表 4-4）

比較文書の要約表（Q1 行 ②）と §4 の 1 位の理由は「グランド差の除去を**記録上の約 43 dB から DS の 85 dB min へ上げる**」。
しかし:

| Vg | Q1（今の図） | Q2（INA1650、REF を ADC 側） | 記録 |
|---|---|---|---|
| **ch 側グランド ↔ MC 側 `A_GND`**（`AMP_SEL` の基準と `U1602` +IN の差） | **0 dB**（信号と直列に乗る） | 85 dB min（DS、±18 V 条件） | 測った記録なし |
| **`A_GND` ↔ `ADC_GND`**（`NT1601` の両側） | 純コモンモード。部品公差と PCM1804 自身の同相除去（DS 規定なし）で決まる。0.1 % 抵抗だけなら約 60 dB〔推論・計算〕 | 同上（REF の置き方次第） | DEC の 43 dB は 47 Ω 付きの構成の値らしい（DEC:390）。確度: 中 |

Q2 の理屈上の得は、比較文書が書いたより**大きい**（0 → 85 dB）。だが**どちらの Vg も −106 に効いているという記録は無い**。
−106 を縛っているのはソケット（[BU:413]、[DEC:350]「同じソケットを使う限り改善しない」）。したがって 1 位にする根拠は「未測定の機構への保険」しか残らない。比較文書自身も §2.2 ⑥ で「Vg が効いていなければ Q2 は保険でしかない」と書いている。

### 2.2 0.1 節の枠組みと §4 の順位が噛み合っていない（表 2-3）

0.1 節は正しい: −106 は差ベクトルの検出限界で、v1 は −76 dBc のベースラインのまま −106 の差を出した。
この枠組みでは、結合部の**絶対**歪みは「安定なら差から消える」。効くのは:

- 高調波ビンの雑音（1 キャプチャの 1σ、平均で下がる）
- 鎖のベースラインの**揺らぎ**（ベースライン × 相対変動。v1 の 1σ 0.115 dB・0.63° を仮に当てはめると、−76 dBc のベースラインで約 −112 dBc、−84 dB で約 −120 dBc）〔計算・推論〕
- DUT にかかる負荷の変化（全 DUT 共通なら比較器として困らない、は比較文書のとおり）

**Q2 の「HD3 −142 で 27〜36 dB 余裕」も、Q3 の「−84 dB で 22 dB 外れ」も、この基準では決め手にならない。**
ADC 自身が THD+N −102 typ / −95 max で、どの案でも鎖の絶対歪みは ADC が支配する。

### 2.3 試験レベルはユーザーの決定（表 3-3）

比較文書の数値（高調波ビン 1σ の dBc、各部品の条件との比較）は全部「v2.1 でもバス 3.70 Vrms」を前提にしている。

- **3.70 Vrms で撮る場合**: dBFS が v1 と同じなので、v1 の dBc の床がそのまま使える。ただし DUT は v1 より 5.5 dB 大きい振幅で動く。PT2314E は 1.85 Vrms を出す必要がある（VOMAX min 2.3 Vrms @ VDD 9 V に対して 1.9 dB）[DEC:409]〔計算〕
- **v1 と同じ DUT 振幅（バス 1.97 Vrms）で撮る場合**: ADC は −8.9 dBFS、雑音だけの 3σ は約 −105.5 dBc（v1 の床が dBFS で同じと仮定）[計算]。**結合方式に関係なく目標を割る**ので、平均回数を増やす（8 → 約 30 回で 5.5 dB 戻る）か、v2.1 の床が v1 より下がることが要る

これは Q1〜Q5 のどれを選ぶかより先に効く。

### 2.4 JT-11P-1 の読み（表 3-5）

- 表の「1 kHz <0.001 %」は **TYPICAL 列**。比較文書の「上限だけ」「≤ −100 dB の上限」は、保証値のように読める書き方で不正確
- 左の図には +4 / +14 / +20 dBu の 3 本があり、図の下端 0.001 % に届くのは約 250 / 410 / 600 Hz（私の読み、±20 % 程度）。**1320 Hz・+14 dBu は「<0.001 %（図の下端止まり）」と DS から言える。** 「+13.6 dBu の DS は無い」は誤り。ただしそれ以上の分解能は図に無い

### 2.5 ISO224 の雑音の食い違い（表 6-2）

p7 の入力換算 3 µV/√Hz と、p8 の出力雑音 300 µVrms（10 kHz、利得 1/3）から出る入力換算 約 9 µV/√Hz が 3 倍違う。
後者なら 8 回平均の 3σ が約 −105 dBc で、**雑音だけで目標を割る**。Q3 最下位は変わらないが、「雑音だけなら −106 は割らない」という比較文書の一文は DS の片方しか見ていない。

### 2.6 Q4 について（表 1-7、5-4〜5-6、6-6）

- 回路図の主張（MCLK を渡さない、3 順 1 逆、BCK 3.072 MHz）は正しい
- ただし「記録の本命」は ADC 自身の床への経路で、音声への漏れではない。音声への漏れは誰も測っていない
- −106 との関係: I²S の活動で出るものは BCK/LRCK に同期した定常のスパー（v1 の fS/64 系列 [BU:176]）で、試験音 1320 Hz はそれを避けて選んである [BU:181–188]。定常なら差から消える。**Q4 が −106 に効くという筋は記録から立たない**〔推論〕
- ISO7741 自身も OOK の高周波搬送波を ADC の隣に置く（周波数は DS に無い）
- Q4 を選ぶと ADC の電源が ±15 V 側に決まる。ユーザーが後で決めると言っている議論を先取りする

### 2.7 二つの「一番安い確かめ方」の評価（表 6-5、6-6）

| 実験 | 何を決められるか | 決められないこと |
|---|---|---|
| ① 入力の短絡点を変えた 2 回の無信号キャプチャ | ch↔MC の Vg（信号と無相関な分）が v1 の床より上か。**負なら Q1 のままでよい、と強く言える** | v1 の仮配線は v2.1 の基板と違うので、正の結果は v2.1 で Q2 が要る根拠にならない。DUT を抜くので信号に相関した Vg は見えない |
| ② ADC リセット保持の A-B-A | この形では決められない（1.37 s でパワーダウン、BCK が止まるか不明、MCLK は走ったまま、VCOM の振る舞い不明） | — |
| ②' （代案〔推論〕）I²S 3 本を Pico 側で外す／直列抵抗を挟む A-B-A、LINE 出力を外部で撮る | Q4 が変える経路が音声出力に出ているか | −106 には関係しない |

## 3. 修正後の順位

判定の軸: **−106（差の検出）を悪くしないこと**（ビンの雑音・ベースラインの安定性）＞ 実績 ＞ 費用・リスク ＞ ADC 電源の自由度。絶対歪み（A 軸）は使わない。

| 順位 | 方式 | 理由 | 変わる条件 |
|---|---|---|---|
| **1** | **Q1 現行** | v1 の同じ形で −106 を出した唯一の方式（n = 1・仮配線・前段 3.3k）。部品が増えない。前段の雑音 −155 dBc/キャプチャは効かない [計算]。**2.3 の試験レベルの前提は Q1 にも Q2 にも同じく効く** | 実験①で ch↔MC の Vg が床より上に出たら 2 位と入れ替え |
| **2** | **Q2 INA1650（`U1611` の後ろ）** | 害は小さい（雑音 −152 dBc、歪みは定常）。得は「ch↔MC の Vg を 0 → 85 dB」で比較文書が書いたより大きいが、効いている記録が無い。GND センスを 8 ch のどこで取るか・切り替えるかの手間、ルートのシートピン追加が付く | 実験①が正なら 1 位 |
| 別枠 | **Q4 ISO7741**（Q1/Q2 と併用） | 回路図上は素直に入る。ただし −106 に効く筋が記録から立たず、ADC 電源を ±15 V 側に固定する。比較対象に直列抵抗（ほぼ無料）を入れるべき | 実験②' で音声出力への漏れが出て、かつユーザーが音声出力の純度を目標に加えたとき |
| **3** | **Q5 JT-11P-1（`U1611` の後ろ）** | 受動で電源・搬送波が無い。1320 Hz・+14 dBu は「<0.001 % typ（図の下端）」まで DS で言える。H3 単独と安定性は無い。購入して v1 に挟まないと分からない | 実機で H3 の揺らぎが v1 の床以下なら Q2 と並ぶ（ガルバニックに切る決定をするなら） |
| **4** | **Q3 ISO224B ほか** | 雑音が DS の中で 3 倍食い違い、悪い方なら雑音だけで目標を割る。1.3 kHz の規定・安定性が無い。ΔΣ・搬送波・DC-DC が ADC の隣 | EVM での実測以外に覆す材料が無い |

比較文書の順位からの変更は「1 位と 2 位の入れ替え」と「Q4 を順位の外へ」。3 位以下の並び（Q5 > Q3）は理由を差し替えて維持。
