# ZT-703S による 1175 Hz 残差ノイズ計測

最終更新: **2026-08-24**

機材: **ZOYI ZT-703S**（2ch・50 MHz）＋プローブ 2 本。  
対象: 初号 MeasurementADC の残差 **約 1175 Hz 倍音列**（L ≈ −84 dBFS / R ≈ −70 dBFS）。

スペアナ（Pico FFT）は感度が高い。オシロは **電源／VCOM／GND の形と相関**を取る道具。  
両方が同じ時間帯に見える状態で測る。

---

## J703 向けセットアップ（説明書準拠）

出典: ZOYI ZT-703S Owner's Manual（Channel Settings / Vertical / Horizontal / Trigger / Signal Generator）。  
**AUTO は使わない**（リプルが小さく、1 V/div などに飛ばされる）。

### 0. プローブ物理スイッチ

- 両プローブ側面の減衰スイッチを **X1**
- 説明書どおり、**本体側の減衰設定も X1 に合わせる**（不一致だと V/div 表示が嘘になる）
- ※ X1 だと帯域が狭くなるプローブもあるが、今回は ~1 kHz なので問題ない

### 1. オシロモードへ

1. `MODE` でオシロ画面にする（マルチメータ画面なら切替）
2. 画面下が `VOL/TIME` / `MOVE` / `TRIG` / `CURSOR` なら測定画面

### 2. 内蔵信号源（Output）

`MENU` 第6ページの **`F4`＝Output** が簡易信号設定。

**波形だけ選ばれていて FREQ / VPP / DUTY が全部 `--` は正常。**  
方形波（校正用）のときは周波数が **固定 1 kHz / 約 2.5 V** なので、パラメータ欄は出せない。壊れていない。  
この状態だと右側面の信号端子から 1 kHz 方形が出る（プローブ校正用）。測定画面にも □ と 1.000 kHz が出る。

オフにしたいとき（説明書の本線）:

1. 同じ第6ページで **`F1`＝拡張アプリ** → **信号出力** を選んで `MENU`
2. 画面右上の **ON/OFF** が OFF になるまで `MENU` でトグル
3. `MODE` でオシロへ戻る

ファームによっては、オシロに戻るとまた方形波 `--` に戻る。その場合は無理に消さなくてよい。  
**J703 測定では、プローブを右側面の信号端子に繋がない／USB カバーを閉めておけば、CH1/CH2 には乗らない。**  
sine / pulse / 鋸歯にすると時間軸が 100 µs/div 上限になるので、測るときは方形波 `--` のままが安全。

`F4` の設定窓はもう一度 `F4` で抜けて、`VOL/TIME` の測定画面へ戻る。

### 3. CH1 / CH2 を AC・X1・両方 ON

説明書: `MENU` → **第1ページ＝Channel Settings**。

1. `MENU` → 第1ページ
2. **CH1:** `F1` で CH1（メニュー色が黄）→ `F2` で表示 ON → `F3` で **AC** → `F4` で **X1**
3. **CH2:** `F1` で CH2（青）→ 同様に ON / **AC** / **X1**
4. `MENU` で閉じて測定画面へ  
   右側の ch 表示が **AC** かつ感度が mV 台であること

### 4. 垂直・時間軸（VOL/TIME）

説明書: 測定画面で `F1`＝VOL/TIME。↑↓＝V/div、←→＝時間軸。

1. `F1` で **VOL/TIME**（ハイライト）
2. `F1` で CH1（黄）→ **↑↓** で **20〜50 mV/div**（最初は 40 mV でも可）
3. `F1` で CH2（青）→ 同じく **20〜50 mV/div**
4. **←→** で時間軸を **200 µs/div〜1 ms/div**  
   - 右＝時間軸を細かく（速い）、左＝粗く（遅い）  
   - **50 ms/div は遅すぎ**（1175 Hz が潰れる）  
   - **200 ms/div 以上は Scroll Mode** に入るので使わない

### 5. 波形の位置（MOVE）

1. `F2`＝MOVE
2. `F1` で ch を選び、↑↓ で黄を上半分・青を下半分あたりへ（重ならないように）

### 6. トリガ（第2ページ＋TRIG）

説明書: `MENU` → 第2ページ＝Trigger。測定画面 `F3`＝TRIG でレベル調整。

1. `MENU` → **第2ページ**
2. `F1` トリガモード → まず **Auto**（波形が出てから Normal でも可）
3. `F2` エッジ → Rising
4. `F3` ソース → **CH1**
5. `F4` でトリガ位置 50%（あれば押す）
6. 測定画面に戻り `F3`＝TRIG → ↑↓ でトリガ線を **黄色い帯の真ん中**へ  
   （前回の −210 mV / −5.3 V のように画面外だとロックしない）

### 7. 数値表示（任意）

説明書: 第6ページ → 数値測定。

1. `MENU` → 第6ページ → `F3` で測定項目
2. CH1/CH2 それぞれ **Peak-Peak** と **Frequency**（または Period）をオン
3. `F4` で確定

### 8. 配線（ここが本体設定と同じくらい重要）

| 線 | 行き先 |
|---|---|
| CH1 先端 | J703 **3番** AMP_V+（西・遠い側） |
| CH2 先端 | J703 **1番** AMP_V−（東・近い側） |
| 両 GND | J703 **2番** に **直接・最短** |

- 説明書: **両 ch の GND は内部で共通**。別電位の GND に落とさない
- USB 充電ケーブルは外す（GND が PC 経由でループしやすい）
- 電源は通電したまま（±15 が出ている状態）

### 9. 保存

- `HOLD/SAVE` **長押し約2秒** → Save 表示で波形画像保存
- PC へ出すとき: 第3メニュー `F3` データ保存モード → USB → `pic` フォルダ

### この設定で見えるはずのもの

- 成功: mV 台の細い〜やや太いトレース。周期が取れれば ~0.85 ms（≈1175 Hz）か、スイッチングの速いリプル
- 失敗パターン: また 1 V/div・数 Vpp・きっちり 1.000 kHz → 信号源オフと短 GND を再確認

| 優先 | 仮説 | 期待するオシロ所見 |
|---|---|---|
| 1 | **J703 経由の MCW03 ±15V リプル**が FE／VCOM に乗る | ±15 に共通の ~1.17 kHz（鋸歯寄り）。R 側が J703 寄りで大きい |
| 2 | **GND 星点ずれ**（初号は NT701 が U702/U703 付近で GND⇄ADC_GND） | アナログ FE 近傍と A701 近傍の GND 間に同周期の電位差 |

## オシロ基本設定（毎回これ）

| 項目 | 設定 |
|---|---|
| モード | オシロ（Normal。1 kHz 帯なので High-Speed 不要） |
| カップリング | **AC**（リプル専用）。DC は平均電圧確認のときだけ |
| プローブ減衰 | リプル狙いなら **×1**（ZT-703S 最小 20 mV/div）。×10 は 200 mV/div 相当になり 1 kHz 残差には粗い |
| 垂直 | まず 20–50 mV/div。見えたら拡大 |
| 時間軸 | **200 µs/div〜1 ms/div**（1175 Hz 周期 ≈ 851 µs） |
| トリガ | CH1、Auto → 波形が安定したら Normal。Edge・立ち上がり。**トリガレベルは波形の中央付近**（画面外だとロックしない） |
| プローブ GND | **短いスプリング／短いクリップ**。長いワニ口は 50/60 Hz とスイッチングを拾う |
| 共通 GND | 両プローブの GND を **同じ基準点（J703 の 2番）**に落とす |
| AUTO | **押さない。** リプルが数十 mV なのに 1 V/div へ飛ばされる |
| 画面右の 1.000 kHz □ | **内蔵信号源の状態表示**であり、レールの測定値ではない。校正出力は本体右側面。**オフにする** |

- 周波数（Hz）
- Vpp / Vrms（あれば）
- 時間軸・垂直・カップリング・プローブ減衰
- 測定点ラベル（下表の ID）

## 基準 GND（迷子防止）

北を上にしたときの **J703**: 西→東で **3=AMP_V+ / 2=GND / 1=AMP_V−**。

| 記号 | どこ | いつ使う |
|---|---|---|
| **G0** | J703 の 2 番（MCW03 二次 0V） | ±15 リプル（A1） |
| **G1** | C719 北パッド近傍（VCOMR 側・ADC_GND） | VCOM／アナログ FE |
| **G2** | C720 南パッド近傍（VCOML 側・ADC_GND） | L 側対称測定 |
| **G3** | A701（ADC モジュール）近傍の ADC_GND | 星点／GND 電位差 |

ADC モジュールヘッダ（測りやすい）:

| コネクタ | 北 | 中央 | 南 |
|---|---|---|---|
| CN2F（北・R） | VINR− | **VCOMR** | VINR+ |
| CN1F（南・L） | VINL− | **VCOML** | VINL+ |

入力開放のまま（Amp 切り離しでも可）。スペアナは起動したまま、ピークが ~1175 Hz 付近にあることを先に確認。

## 計測メニュー（2 プローブ）

### A1 — ±15V 入口リプル（最優先）

| CH | 先端 | GND |
|---|---|---|
| CH1 | J703 **3**（AMP_V+） | **G0** |
| CH2 | J703 **1**（AMP_V−） | **G0** |

見るもの:

- 両ch に **同じ周波数**があるか（~1.17 kHz？ MCW のスイッチング数十 kHz？ 両方？）
- 形（鋸歯／三角／正弦）
- Vpp。±で位相が同相か逆相か

判定メモ:

- ± に共通の ~1.17 kHz → **仮説1 有力**。次は A2
- スイッチングだけ大きく 1.17 kHz が無い → 1.17 kHz は負荷応答／別経路。A3・A4 へ
- ほぼ平坦（ノイズ床のみ）→ J703 入口は無罪寄り。星点／デジ側へ

### A2 — VCOM L/R 同時

| CH | 先端 | GND |
|---|---|---|
| CH1 | CN2F 中央 **VCOMR** | **G1** |
| CH2 | CN1F 中央 **VCOML** | **G1**（または G2。基準は1点に統一） |

見るもの:

- 周波数がスペアナの 1175 Hz と一致するか
- **R が L より大きいか**（FFT の 14 dB 差と整合するか）
- A1 の ±15 と **同期・同形**か（2 回に分けて撮ってもよい。できれば A1 の CH1 を残し CH2 を VCOMR に付け替え＝A3）

### A3 — 電源と VCOM の相関（R 側）

| CH | 先端 | GND |
|---|---|---|
| CH1 | J703 **3**（AMP_V+）または U703 電源ピン近く | **G0** |
| CH2 | **VCOMR** | **G1** ※GND を G0 と G1 で分けるとループが増える。まずは **両方 G1** でも可 |

見るもの: 位相同期・周期一致。一致すれば電源→VCOM 経路。

### A4 — GND 電位差（星点仮説）

プローブは電圧計なので「GNDどうし」も測れる。

| CH | 先端 | GND クリップ |
|---|---|---|
| CH1 | **G1**（FE 近傍 ADC_GND） | **G0**（J703 GND） |
| CH2 | **G3**（A701 近傍 ADC_GND） | **G0** |

見るもの:

- G1−G0 と G3−G0 に ~1.17 kHz があるか
- FE 側（G1）の方が大きい → 初号の NT701 位置（U702/U703 付近）と整合

注意: クリップと先端で大きなループを作らない。できるだけ近いパッド同士。

### A5 —（任意）デジタル 3.3/5 と比較

| CH | 先端 | GND |
|---|---|---|
| CH1 | `+3V3_A` または LT1763 出力 | ADC_GND |
| CH2 | VCOMR | G1 |

1.17 kHz がデジレールに無くアナログにだけある → デジ由来ではない。

## 実測ログ

### A1 1回目（2026-08-24）— 時間軸が遅い

- 接続: CH1=J703-3（+）、CH2=J703-1（−）、GND=J703-2 の想定
- 表示: **50 ms/div**、両ch **40 mV/div**、トリガ −210 mV（波形から大きく外れている）
- 波形: 黄・青とも約 1 目盛の太い帯 → 包絡 **約 40 mVpp**。周期は分解できていない
- 画面右 **1.000 kHz □** は内蔵信号源。測定周波数ではない
- 読み: ±15 入口に数十 mV 級の変動はあるが、**1175 Hz かどうかは未確定**。次は時間軸を速くする

### A1 2回目（同日）— GND の取り方を変更

- 表示: **5.0 ms/div**、両ch **1.0 V/div**、トリガ −5.3 V
- 波形: 黄・青ともノイズ付き鋸歯／三角、**ほぼ同位相**、約 2〜3 目盛 → **2〜3 Vpp**、見かけ ~1 kHz
- 読み: **これは ±15 のリプルではない。** MCW03 二次のリプルは mV 台が普通で、数 V は電源が壊れている水準。両ch が同じ形・同位相なのは **GND ループ／長いクリップが拾ったコモンモード**（内蔵 1 kHz 校正出力の可能性が高い）
- 1 回目の 40 mV 帯のほうが実レールに近い

**A1 やり直し（これで撮る）:**

1. 第 6 メニューの信号出力を **オフ**（右の 1.000 kHz □ を消す）
2. AUTO は使わない
3. 両 GND クリップを **J703 の 2番ピンの金属に直接・最短**（長いリードで離れた GND に落とさない）
4. AC、×1、**20–50 mV/div**、**200 µs/div〜1 ms/div**
5. トリガレベルを黄色い帯の真ん中へ

## 安全・取り扱い

- ±15V は ×1 のまま触ってよい電圧だが、**誤って高圧ノードや一次側に当てない**
- USB で Pico を見ながらオシロ GND を落とすと、PC アース経由でループが増えることがある。怪しい 50/60 Hz が出たらノート PC を電池駆動にして比較
- GP9→CN3F-1 は **駆動禁止**（センス専用）。オシロを SCKI に当てるのは本キャンペーンの主目的ではない
