# ZT-703S による 1175 Hz 残差ノイズ計測

最終更新: **2026-08-24**

機材: **ZOYI ZT-703S**（2ch・50 MHz）＋プローブ 2 本。  
対象: 初号 MeasurementADC の残差 **約 1175 Hz 倍音列**（L ≈ −84 dBFS / R ≈ −70 dBFS）。

スペアナ（Pico FFT）は感度が高い。オシロは **電源／VCOM／GND の形と相関**を取る道具。  
両方が同じ時間帯に見える状態で測る。

---

## J703 向けセットアップ（説明書準拠）

出典: ZOYI ZT-703S Owner's Manual（Channel Settings / Vertical / Horizontal / Trigger / Signal Generator）。  
**AUTO は使わない**（リプルが小さく、1 V/div などに飛ばされる）。

### 0. プローブ物理スイッチ

- 両プローブ側面の減衰スイッチを **X1**
- 説明書どおり、**本体側の減衰設定も X1 に合わせる**（不一致だと V/div 表示が嘘になる）
- ※ X1 だと帯域が狭くなるプローブもあるが、今回は ~1 kHz なので問題ない

### 1. オシロモードへ

1. `MODE` でオシロ画面にする（マルチメータ画面なら切替）
2. 画面下が `VOL/TIME` / `MOVE` / `TRIG` / `CURSOR` なら測定画面

### 2. 内蔵信号源（Output）

`MENU` 第6ページの **`F4`＝Output** が簡易信号設定。

**波形だけ選ばれていて FREQ / VPP / DUTY が全部 `--` は正常。**  
方形波（校正用）のときは周波数が **固定 1 kHz / 約 2.5 V** なので、パラメータ欄は出せない。壊れていない。  
この状態だと右側面の信号端子から 1 kHz 方形が出る（プローブ校正用）。測定画面にも □ と 1.000 kHz が出る。

オフにしたいとき（説明書の本線）:

1. 同じ第6ページで **`F1`＝拡張アプリ** → **信号出力** を選んで `MENU`
2. 画面右上の **ON/OFF** が OFF になるまで `MENU` でトグル
3. `MODE` でオシロへ戻る

ファームによっては、オシロに戻るとまた方形波 `--` に戻る。その場合は無理に消さなくてよい。  
**J703 測定では、プローブを右側面の信号端子に繋がない／USB カバーを閉めておけば、CH1/CH2 には乗らない。**  
sine / pulse / 鋸歯にすると時間軸が 100 µs/div 上限になるので、測るときは方形波 `--` のままが安全。

`F4` の設定窓はもう一度 `F4` で抜けて、`VOL/TIME` の測定画面へ戻る。

### 3. CH1 / CH2 を AC・X1・両方 ON

説明書: `MENU` → **第1ページ＝Channel Settings**。

1. `MENU` → 第1ページ
2. **CH1:** `F1` で CH1（メニュー色が黄）→ `F2` で表示 ON → `F3` で **AC** → `F4` で **X1**
3. **CH2:** `F1` で CH2（青）→ 同様に ON / **AC** / **X1**
4. `MENU` で閉じて測定画面へ  
   右側の ch 表示が **AC** かつ感度が mV 台であること

### 4. 垂直・時間軸（VOL/TIME）

説明書: 測定画面で `F1`＝VOL/TIME。↑↓＝V/div、←→＝時間軸。

1. `F1` で **VOL/TIME**（ハイライト）
2. `F1` で CH1（黄）→ **↑↓** で **20〜50 mV/div**（最初は 40 mV でも可）
3. `F1` で CH2（青）→ 同じく **20〜50 mV/div**
4. **←→** で時間軸を **200 µs/div〜1 ms/div**  
   - 右＝時間軸を細かく（速い）、左＝粗く（遅い）  
   - **50 ms/div は遅すぎ**（1175 Hz が潰れる）  
   - **200 ms/div 以上は Scroll Mode** に入るので使わない

### 5. 波形の位置（MOVE）

1. `F2`＝MOVE
2. `F1` で ch を選び、↑↓ で黄を上半分・青を下半分あたりへ（重ならないように）

### 6. トリガ（第2ページ＋TRIG）

説明書: `MENU` → 第2ページ＝Trigger。測定画面 `F3`＝TRIG でレベル調整。

1. `MENU` → **第2ページ**
2. `F1` トリガモード → まず **Auto**（波形が出てから Normal でも可）
3. `F2` エッジ → Rising
4. `F3` ソース → **CH1**
5. `F4` でトリガ位置 50%（あれば押す）
6. 測定画面に戻り `F3`＝TRIG → ↑↓ でトリガ線を **黄色い帯の真ん中**へ  
   （前回の −210 mV / −5.3 V のように画面外だとロックしない）

### 7. 数値表示（任意）

説明書: 第6ページ → 数値測定。

1. `MENU` → 第6ページ → `F3` で測定項目
2. CH1/CH2 それぞれ **Peak-Peak** と **Frequency**（または Period）をオン
3. `F4` で確定

### 8. 配線（ここが本体設定と同じくらい重要）

| 線 | 行き先 |
|---|---|
| CH1 先端 | J703 **3番** AMP_V+（西・遠い側） |
| CH2 先端 | J703 **1番** AMP_V−（東・近い側） |
| 両 GND | J703 **2番** に **直接・最短** |

- 説明書: **両 ch の GND は内部で共通**。別電位の GND に落とさない
- USB 充電ケーブルは外す（GND が PC 経由でループしやすい）
- 電源は通電したまま（±15 が出ている状態）

### 9. 保存

- `HOLD/SAVE` **長押し約2秒** → Save 表示で波形画像保存
- PC へ出すとき: 第3メニュー `F3` データ保存モード → USB → `pic` フォルダ

### この設定で見えるはずのもの

- 成功: mV 台の細い〜やや太いトレース。周期が取れれば ~0.85 ms（≈1175 Hz）か、スイッチングの速いリプル
- 失敗パターン: また 1 V/div・数 Vpp・きっちり 1.000 kHz → 信号源オフと短 GND を再確認

| モード | オシロ（Normal。1 kHz 帯なので High-Speed 不要） |
| カップリング | **AC**（リプル専用）。DC は平均電圧確認のときだけ |
| プローブ減衰 | リプル狙いなら **×1**（ZT-703S 最小 20 mV/div）。×10 は 200 mV/div 相当になり 1 kHz 残差には粗い |

| トリガ | CH1、Auto → 波形が安定したら Normal。Edge・立ち上がり。**トリガレベルは波形の中央付近**（画面外だとロックしない） |

## 基準 GND（迷子防止）

北を上にしたときの **J703**: 西→東で **3=AMP_V+ / 2=GND / 1=AMP_V−**。

| 記号 | どこ | いつ使う |
|---|---|---|
| **G0** | J703 の 2 番（MCW03 二次 0V） | ±15 リプル（A1） |
| **G1** | C719 北パッド近傍（VCOMR 側・ADC_GND） | VCOM／アナログ FE |
| **G2** | C720 南パッド近傍（VCOML 側・ADC_GND） | L 側対称測定 |
| **G3** | A701（ADC モジュール）近傍の ADC_GND | 星点／GND 電位差 |

ADC モジュールヘッダ（測りやすい）:

| コネクタ | 北 | 中央 | 南 |
|---|---|---|---|
| CN2F（北・R） | VINR− | **VCOMR** | VINR+ |
| CN1F（南・L） | VINL− | **VCOML** | VINL+ |

入力開放のまま（Amp 切り離しでも可）。スペアナは起動したまま、ピークが ~1175 Hz 付近にあることを先に確認。

## 計測メニュー（2 プローブ）

### A1 — ±15V 入口リプル（最優先）

| CH | 先端 | GND |
|---|---|---|
| CH1 | J703 **3**（AMP_V+） | **G0** |
| CH2 | J703 **1**（AMP_V−） | **G0** |

見るもの:

- 両ch に **同じ周波数**があるか（~1.17 kHz？ MCW のスイッチング数十 kHz？ 両方？）
- 形（鋸歯／三角／正弦）
- Vpp。±で位相が同相か逆相か

判定メモ:

- ± に共通の ~1.17 kHz → **仮説1 有力**。次は A2
- スイッチングだけ大きく 1.17 kHz が無い → 1.17 kHz は負荷応答／別経路。A3・A4 へ
- ほぼ平坦（ノイズ床のみ）→ J703 入口は無罪寄り。星点／デジ側へ

### A2 — VCOM L/R 同時

| CH | 先端 | GND |
|---|---|---|
| CH1 | CN2F 中央 **VCOMR** | **G1** |
| CH2 | CN1F 中央 **VCOML** | **G1**（または G2。基準は1点に統一） |

見るもの:

- 周波数がスペアナの 1175 Hz と一致するか
- **R が L より大きいか**（FFT の 14 dB 差と整合するか）
- A1 の ±15 と **同期・同形**か（2 回に分けて撮ってもよい。できれば A1 の CH1 を残し CH2 を VCOMR に付け替え＝A3）

### A3 — 電源と VCOM の相関（R 側）

| CH | 先端 | GND |
|---|---|---|
| CH1 | J703 **3**（AMP_V+）または U703 電源ピン近く | **G0** |
| CH2 | **VCOMR** | **G1** ※GND を G0 と G1 で分けるとループが増える。まずは **両方 G1** でも可 |

見るもの: 位相同期・周期一致。一致すれば電源→VCOM 経路。

### A4 — GND 電位差（星点仮説）

プローブは電圧計なので「GNDどうし」も測れる。

| CH | 先端 | GND クリップ |
|---|---|---|
| CH1 | **G1**（FE 近傍 ADC_GND） | **G0**（J703 GND） |
| CH2 | **G3**（A701 近傍 ADC_GND） | **G0** |

見るもの:

- G1−G0 と G3−G0 に ~1.17 kHz があるか
- FE 側（G1）の方が大きい → 初号の NT701 位置（U702/U703 付近）と整合

注意: クリップと先端で大きなループを作らない。できるだけ近いパッド同士。

### A5 —（任意）デジタル 3.3/5 と比較

| CH | 先端 | GND |
|---|---|---|
| CH1 | `+3V3_A` または LT1763 出力 | ADC_GND |
| CH2 | VCOMR | G1 |

1.17 kHz がデジレールに無くアナログにだけある → デジ由来ではない。

## 実測ログ

### A1 1回目（2026-08-24）— 時間軸が遅い

- 接続: CH1=J703-3（+）、CH2=J703-1（−）、GND=J703-2 の想定
- 表示: **50 ms/div**、両ch **40 mV/div**、トリガ −210 mV（波形から大きく外れている）
- 波形: 黄・青とも約 1 目盛の太い帯 → 包絡 **約 40 mVpp**。周期は分解できていない
- 画面右 **1.000 kHz □** は内蔵信号源。測定周波数ではない
- 読み: ±15 入口に数十 mV 級の変動はあるが、**1175 Hz かどうかは未確定**。次は時間軸を速くする

### A1 2回目（同日）— GND の取り方を変更

- 表示: **5.0 ms/div**、両ch **1.0 V/div**、トリガ −5.3 V
- 波形: 黄・青ともノイズ付き鋸歯／三角、**ほぼ同位相**、約 2〜3 目盛 → **2〜3 Vpp**、見かけ ~1 kHz
- 読み: **これは ±15 のリプルではない。** MCW03 二次のリプルは mV 台が普通で、数 V は電源が壊れている水準。両ch が同じ形・同位相なのは **GND ループ／長いクリップが拾ったコモンモード**（内蔵 1 kHz 校正出力の可能性が高い）
- 1 回目の 40 mV 帯のほうが実レールに近い

### A1 3回目（同日）— 時間軸は良いが垂直が粗い

- 表示: **1.0 ms/div**（1175 Hz 向きで適切）、両ch **5.0 V/div**、Freq `--.--`、トリガ −1.3 V
- 波形: 黄・青とも水平線のみ（このスケールではリプルは見えない）
- 画面: 右下に 1.000 kHz □ 残存、充電中（USB 接続）
- 読み: 時間軸は OK。**5 V/div では 40 mV 級は約 0.01 目盛で消える。** 次は垂直だけ下げる

### A1 4回目（同日）— 20 mV / 200 µs で帯が画面を埋める

- 表示: **200 µs/div**、両ch **20 mV/div AC**、トリガ CH1・−78 mV
- 1枚目（RUN）: 黄が画面の大半を塗り潰す。Freq **5.63 kHz**（青は `--.--`）
- 2枚目（HOLD）: 黄・青とも同じ太い帯。Freq 両方 `--.--`
- 読み:
  - 設定は初めて実用レンジ。**塗り潰しは 1175 Hz ではなく、もっと速いスイッチングリプル**が 200 µs では分解できない見え方
  - 画面いっぱい ≈ **100 mVpp 超**。Freq 5.63 kHz は塗り潰しへのカウンタなので信用しない
  - 1175 Hz（周期 ≈ 0.85 ms）は、この帯の**ゆっくりした上下**として探す

**次の 2 枚（配線はそのまま、AUTO 禁止）:**

1. **スイッチングを分解:** 時間軸 **5〜20 µs/div**（VOL/TIME でさらに右）。垂直は 50 mV/div でも可。ギザギザの周期が数えられたらその Hz を記録
2. **1175 Hz の包絡:** 時間軸 **1.0 ms/div**、垂直 **50〜100 mV/div**（帯が画面に収まること）。帯全体が約 0.85 ms 周期で上下するかを見る

### A1 5回目（同日）— 10 ns/div は行き過ぎ

- 表示: **10 ns/div**、両ch **40 mV/div AC**、HOLD、トリガ −40 mV
- 1枚目: Freq 黄 **20.00 MHz** / 青 **20.83 MHz**（正弦っぽい）
- 2枚目: Freq 黄 **14.37 MHz** / 青 **15.72 MHz**（振幅およそ 60 mVpp）
- 読み:
  - 依頼は **5〜20 µs/div**。**10 ns はその 500〜2000 倍速い**（ZT-703S の帯域上限付近）
  - 2枚で周波数がバラつき、±で一致しない → **安定した電源リプルではない**。プローブが拾ったデジクロック／EMI、または補間ノイズ
  - 板上には Y701 **SCKI 12.288 MHz** がある。10 ns ではこれをアンテナとして拾いやすい
  - MCW03 のスイッチングは普通 **数十〜数百 kHz**。見る時間軸は **µs**

### A1 6回目（同日）— 10 µs と 1 ms が揃った

| 枚 | 時間軸 | 垂直 | カーソル | 見え方 |
|---|---|---|---|---|
| 1 | **10 µs/div** | 40 mV AC | Δ 200 mV / 40 µs | 黄 約 200–240 mVpp、青 約 120–160 mVpp の帯。Freq `--` |
| 2 | **25 µs/div** | 40 mV | Δ 200 mV / 100 µs | 同様の塗り潰し。周期は数えられない |
| 3 | **1.0 ms/div** | 40 mV | Δ 200 mV / 4.0 ms | 帯の厚みはほぼ一定。0.85 ms の上下は見えない |
| 4 | **1.0 ms/div** | 100 mV | Δ 500 mV / 4.0 ms | 帯 50–100 mVpp 程度。包絡なし |
| 5 | **1.0 ms/div** | 50 mV | Δ 250 mV / 4.0 ms | 黄の厚み ≈ 250 mVpp（カーソル一致）。包絡なし |

**A1 の結論:**

- J703 の ±15 には **100〜250 mVpp の高周波ハッシュ**がある。**+ のほうが − より大きい**（R が J703 寄りで悪いことと方向は合う）
- 10 µs でも周期が取れない → スイッチングは **おおよそ 100 kHz 以上**（または広帯域）。**1175 Hz そのものではない**
- 1 ms/div で帯が一定厚 → **1.17 kHz の大きな包絡は J703 入口には見えない**（数 mV なら 200 mV の HF に埋もれる）
- 仮説1「MCW03 が 1.17 kHz の鋸歯を ±15 に出している」は **このオシロでは支持されない**。HF リプルはある。1.17 kHz は VCOM／GND 側の可能性が残る

カーソル Time 4.0 ms は画面幅（4 div×1 ms）であって周期測定ではない。Freq `--` は正常。

**次は A2（VCOM）。** スペアナの残差はここが出やすい。

### A2 — VCOM L/R

設定は A1 の 1 ms を流用: AC、×1、**20–50 mV/div**、**1.0 ms/div**。AUTO 禁止。GND は **短いクリップで C719 北パッド近傍（G1）に両方**。

| CH | 先端 |
|---|---|
| CH1（黄） | CN2F 中央 **VCOMR**（北側ヘッダ） |
| CH2（青） | CN1F 中央 **VCOML**（南側ヘッダ） |

見るもの: 約 0.85 ms 周期があるか、R が L より大きいか。HF 帯だけならその Vpp も。

（任意）MENU 第5ページあたりの **FFT を ON** にできるなら、1 kHz 付近に棒があるか。無くても A2 の時間波形を優先。

### A2 1回目（同日）— 写真 688=VCOMR、689=VCOML（ファイル名。**どちらも CH1 のみ**）

1.0 ms/div、50 mV/div AC。画面の **青い平坦線は未接続の CH2** であり、VCOML ではない。

- **688 CH1 → VCOMR:** 厚い HF 帯、Δ ≈ 260 mV → **約 250 mVpp**
- **689 CH1 → VCOML:** 同様の厚い HF 帯、Δ ≈ 250 mV → **約 250 mVpp**
- **GND クリップは J703 の 0V（2番 = G0）。** A2 手順の C719（ADC_GND）ではない

**読み（再訂正）:** 測っているのは `VCOM − J703_0V` = `(VCOM − ADC_GND) + (ADC_GND − J703_0V)`。L/R とも約 250 mVpp なのは、**星点間（ADC_GND と MCW03 0V）の HF が共通で乗っている**可能性が高い。VCOM 自体の差ではない。

追加 1 枚（500 µs/div、50 mV、GND=J703 0V）: 黄は厚い帯（約 100–125 mVpp＋位置は MOVE）、青は細い。青が何に付いているかは未記。

**次: GND だけ移す（A2-local / 仮説2）。** 先端は VCOMR のまま。

1. 黄先端 → VCOMR（そのまま）
2. **GND クリップだけ** J703-2 から **C719** へ（**南パッド＝ADC_GND。北は VCOM なので GND にしない**）
3. 同じ 1 ms または 500 µs、50 mV、CH2 は MENU 第1ページ `F2` で OFF

判定:

- 帯が **大きく細くなる** → 今まで見ていたのは GND 間電位。仮説2（星点）が本命
- 帯が **250 mV のまま** → VCOM 対 ADC_GND の汚染

### A2-local 1回目 — CH2 GND だけ C719

- 500 µs/div、両ch 50 mV AC、Δ 250 mV / Time 1.0 ms
- 黄（CH1、GND は J703 0V のまま想定）: 帯 **約 200–250 mVpp**
- 青（CH2、GND を **C719** へ）: 帯 **約 100 mVpp**（約半分）

**注意（説明書）: 2ch の GND は内部で共通。** CH1 クリップが J703-2 に残っていると、**J703 0V と ADC_GND がプローブ GND で短絡**する。青が細いのは「局所 GND」と「ループが短い」が混ざっている。

2. 黄先端は VCOMR

4. 同じ 500 µs / 50 mV

これで残る厚みが、VCOM 対 ADC_GND の本体。

### A2-local 2回目 — 黄が細く、青が太い（おやおや）

1 ms および 500 µs、50 mV。Δ 表示 250 mV は **黄と青の画面上の上下位置（MOVE）をカーソルが跨いだ値**で、新しい直流 250 mV ではない（5 目盛 × 50 mV）。VCOM の 2.5 V は 50 mV/div では画面に載らない。

- **黄（CH1）: 細い／ほぼ平坦** → 先端が VCOMR で、基準が C719（ADC_GND）なら、**VCOM 対局所 GND はきれい**。以前の 250 mVpp は J703 0V 基準のループ／星点間
- **青（CH2）: 太い帯（枚によって 25 mV〜200 mVpp）** → こちらがノイズ源を見ている。先端がまだ J703 0V なら **ADC_GND−J703_0V そのもの（A4）**。先端が ±15 なら電源対 ADC_GND。先端が浮いていればアンテナ

仮説2は強まる。1175 Hz はまだ未分解（HF の下）。

青の先端は **どこにも付いていなかった**（CH2 OFF のつもりでも波形表示が残っていた）。太い青は **浮いたプローブのアンテナ拾い**であり、星点間の測定ではない。無視する。

**次: CH1 だけでもう一度。**

1. MENU 第1ページ → CH2 を `F2` で **OFF**（青が消えること）
2. 可能なら CH2 プローブを本体 BNC から抜く
3. GND クリップは **C719 のみ**（J703 には付けない）
4. 黄先端 → **VCOMR**
5. 500 µs / 50 mV AC、必要なら 1.0 ms も 1 枚

この黄の厚みが VCOM 対 ADC_GND。細ければ仮説2。太いままなら VCOM 汚染。

### A2-local 3（CH1 のみ）— まだ 150–250 mVpp

- 500 µs / 50 mV: 帯 約 3 目盛 → **約 150 mVpp**
- 1.0 ms / 50 mV: 帯 約 5 目盛、カーソル V **250 mV**
- CH2 なし。GND=C719、先端=VCOMR

**読み:** 局所 GND にしても HF は消えない。さっき黄が細かったのは浮いた CH2 との取り違え。  
VCOM 対 ADC_GND に **百 mV 級 HF がある**か、**CN2F〜C719 のループ拾い**かのどちらか。  
※ C719 は **北パッドが VCOM、南が ADC_GND**（北を GND にすると VCOM 同士）。

**次: ループ最短。** CH1 のみ、500 µs / 50 mV。

- 黄先端 → C719 の **北**（VCOM）
- GND → C719 の **南**（ADC_GND）  
  同じ部品の両端。クリップは最短。

細ければ今までは配線ループ。太いままならデカップをすり抜ける VCOM HF。

### A2-cap（C719 両端）— まだ 100–150 mVpp

- 200 µs / 50 mV: 帯 約 3 目盛 → **約 150 mVpp**
- 500 µs / 50 mV: 同様 **約 100–150 mVpp**
- 1.0 ms / 50 mV: 同様。1.17 kHz 包絡は見えない
- 画面右の 1.000 kHz □ は内蔵信号源のまま

**読み:** CN2F までの配線ループだけでは説明できない。候補は (a) C719 をすり抜ける VCOM の HF、(b) **プローブ GND リードのループが EMI を拾っている**（×1・長いクリップでよくある）。上端のバッファ縮小表示が三角っぽいのは 1 kHz 帯の包絡の手がかりかもだが、主画面では未確認。

### プローブ短絡テスト — **合格（帯が消えた）**

- 500 µs / 50 mV、先端と GND 同点短絡 → **黄は中央の細い水平線**
- スコープ／CH1 の床は静か。以前の 100–250 mVpp は **浮遊アンテナでも本体ノイズでもない**
- 画面右 1.000 kHz □ と上端プレビューの正弦は、短絡時でも出る内蔵源／バッファ表示。主トレースとは別

**結論ここまで:**

| 項目 | 結果 |
|---|---|
| J703 ±15 | 100–250 mVpp の HF。1.17 kHz 包絡なし |
| VCOM×J703 0V | 約 250 mVpp（星点間＋本体が足算） |

| 1175 Hz | オシロの主画面では未分解（HF に埋もれている） |

**VCOM には C719 をすり抜ける HF がある**（またはパッド間の極短ループでも乗るスイッチング）。次号は VCOM デカップ強化／±15 の HF 低減が候補。スペアナの 14 dB 差（R）は別経路の可能性が残る。

## 安全・取り扱い

- ±15V は ×1 のまま触ってよい電圧だが、**誤って高圧ノードや一次側に当てない**
- USB で Pico を見ながらオシロ GND を落とすと、PC アース経由でループが増えることがある。怪しい 50/60 Hz が出たらノート PC を電池駆動にして比較
