## 2. 信号・電源トポロジ（破らない）

```text
PD(+15/PD_GND) ──直──► Power / Controll×2 / 計測デジ入口のみ

Power MCW03 二次
  ├─ A_GND ──分配器並列──► Amp×10 / 計測 A_GND / 端子台 0V

              ├─ スペアナ（ハイZ）
              └─ HP バッファ（ハイZ・将来）
```

## 3. 機械・フロア方針（固定）

1. **全面一面並べはしない**（幅が現実的でない）
2. **1F**: Controll（親・子）＋ MeasurementADC  
3. **2F**: Amp×10（広さ次第で平面。足りなければ **Amp スタック**）
4. Controll 親↔子カスケードは **ピン直結ではなくケーブル**（J17: `GND / 3V3 / SCL / SDA`）
5. **Pico2 配線はフタをヒンジ**で当面メンテする前提
6. **LCD 開口は必須**（MeasurementADC / WAVESHARE-29318）
7. 取付は **既存 MountingHole（M3 / drill 3.2mm）を優先**。新規穴を基板に増やす案は最終手段

既存メモのスペーサ目安: Controll 2 段＋Amp 10（2 段×5）で **約 5cm 樹脂スペーサ** も候補。

## 4. ケーブリング制約

| 制約 | 内容 |
| --- | --- |
| Controll 親↔子 | ピンヘッダスタック禁止。I2C 4 線ケーブル |
| Amp 電源 | 常時全通電しない。Controll リレー出力のみ |
| A_GND | 分配器でスター／バス。ループを作らない |
| 線径 | アナログ信号 30AWG 可。±15 / PD 系は 26AWG 推奨 |
| 分配 | 2×6 分配器を使う前提で束ね方を設計 |
| サービス | ヒンジ蓋から Pico2 / 計測側配線に手が届くこと |
| 長さ | 過剰に長い線はノイズ源。フロア間は最短寄り |

Controll I2C は 400kHz 前提（OLED 転送）。ケーブル延長時は引き回しを短く・寄り添わせる。

## 7. デザイン成果物に求めるもの

各案は次を含める:

1. フロア平面図（1F/2F、テキスト or mermaid）

3. 既存 M3 穴をどうシャーシ／スタッドに落とすか
4. ケーブル表（From→To、用途、AWG、概算長）
5. 前面／側面のパネル穴リスト
6. リスク（干渉、線長、放熱、サービス性）と棄却理由があれば明記
