## AudioV2 ±12 V 電源での可否（DKMW20F-12）

前提: 推奨動作範囲に **±12 V が入るか**（絶対最大だけの「壊れない」判定ではない）。  
ヘッドルームは ±15 V 時より狭い（Amp 最大出力 ≈±10 V 級 → DECISIONS §9 どおり約 2〜3 dB 低下）が、**電源定格としては全石 OK**。

| 石 | 推奨／動作 Vs（目安） | ±12 V | 備考 |
|---|---|---|---|
| OPA828（×2 DIP 化） | ±4〜±18 | **OK** | |
| NJM5532DD | ±3〜±22 級（5532 系） | **OK** | Amp 標準相当 |
| NJM4580DD | ±2〜±18 級 | **OK** | |
| OPA2134PA | ±2.5〜±18 | **OK** | |
| OPA1656ID | ±2.25〜±18 | **OK** | 計測 SOP。Amp DIP 直挿しは別問題 |
| OPA2604AQ | ±4.5〜±24 級 | **OK** | |
| LME49860NA | ±2.5〜±22 級 | **OK** | |
| OPA1652 DIP 化 | ±2.25〜±18 | **OK** | |
| OPA627AU DIP 化 | ±4.5〜±18 | **OK** | |
| MUSES02D | ±3.5〜±16 | **OK** | 上限 ±16。±15 より ±12 の方が余裕 |
| OPA1612 DIP 化 | ±2.25〜±18 | **OK** | |
| LT1364CN8 | ±2.5〜±18 級（特性は ±15 表記多い） | **OK** | |
| OPA2140 AIDR DIP | ±2.25〜±18 | **OK** | |
| MUSE01（2→1 DIP） | **±9〜±16**（MUSES01 DS） | **OK** | 下限 ±9。±12 は範囲内 |

**結論:** 手持ちリストは **すべて ±12 V で電源的に足りる**。落ちる石は無し。

電源以外で効く制約（差し替え時）:

- 高速（OPA828 / 1656 / 1612 / LME49860 / LT1364）→ Amp 現行 47k 帰還では安定性注意
- OPA1612 / LME49860 → この抵抗網ではノイズ不利になりやすい
- OPA1656ID → パッケージが SOIC（変換なしでは Amp ソケット不可）

| 場所 | 標準石 |
|---|---|
| AmpModule `AMP401` | NE5532（ソケット） |
| AdcBuffer `AMP801` | OPA1652AID-DIP（原則固定） |
| HeadphoneBuffer `AMP901` | NJM4556A（**差し替え不可**・電流不足リスク） |

## 差し替え時の注意（要約）

- Amp は帰還 47k/10k 級 → **高速石はピーキング注意**（並列 pF or 抵抗下げ）。詳細は [AmpModule_OPAMP_REFINE.md](AmpModule_OPAMP_REFINE.md)
- **バイポーラ超低ノイズ**（OPA1612 / LME49860 等）はこの回路では電流ノイズで不利になりやすい
- HP バッファに電圧アンプ系（MUSES / OPA 汎用）を入れない
- SOIC 単体（OPA1656ID）は Amp DIP ソケットにそのまま挿せない
