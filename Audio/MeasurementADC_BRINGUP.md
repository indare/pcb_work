## 現在の結論（2026-08-14）

**`ADC_nRST` 張り付きは解消した。いま止まっているのは PCM1804 が BCK/LRCK を出さないこと。**

1. 犯人は当初の U709（CT）ではなく、最終的に **U710 の RESET 出力が L 固定**だった
2. U710 の 1番を浮かせ、U709 は CT–VDD に 100kΩ を付けて 1番を戻すと `ADC_nRST` ≈ 3.25V
3. Y701（新品・空中配線）は発振している（OUT のテスター読みが極性非対称／SCKI ≈ 1.4–1.5V）
4. ジャンパはマスタ・256fs・I²S どおり。モジュール上 CN3F の 2/3 は ≈ 0V のまま
5. Pico（GP0/1/2）でも DATA/BCK/LRCK はすべて 0Hz

VCOM 側や OPA 電源の未供給は、BCK/LRCK には無関係。

### 次にやること

1. **予備の ADC1804_F に載せ替え**して CN3F の 2/3 を見る（いちばん早い生死判定）
2. だめならオシロで SCKI 振幅（0⇔約 3V）を確認
3. それでもだめなら次板へ（下記「次改版」）

## 2026-08-14 で分かったこと

### `ADC_nRST` 切り分け（確定）

| 手順 | 結果 |
|---|---|
| U709 CT–VDD に 100kΩ | CT ≈ 2.96V（解除側）。それでも R719 東 ≈ 0.01V |
| U710 SENSE/VDD/CT | 5.14V / 5.14V / 2.9V（解除側なのにネットは L） |
| 電源 OFF の `ADC_nRST`–GND | 19kΩ から徐々に低下＝コンデンサ残留。硬短絡ではない |
| U709 1番を完全に浮かせる | ネットは **0V のまま** → U709 ではない |
| 続けて U710 1番を浮かせる | **R719 東 ≈ 3.26V** → **U710 の RESET 出力不良** |
| U709 1番を戻す | 3.25V 維持 → U709 は正常 |

以前 U710 を換装しても変わらなかったのは、当時まだ U709 側も L だったため。

### Y701 / ASFL（初号基板）

初号の split パッド番号は **右回り**（データシートの部品ピンはマークから **左回り**）。

| 位置 | 基板 pad | 銅箔 | 部品ピン（マーク右上で直付け） |
|---|---|---|---|
| 右上 | 1 | +3.3V | 1 OE → OK |
| 右下 | 2 | GND | 4 VDD → **NG（逆）** |
| 左下 | 3 | OUT | 3 OUT → OK |
| 左上 | 4 | +3.3V | 2 GND → **NG（逆）** |

正しい飛ばし方: 部品 2→右下（GND）、部品 4→左上（+3.3V）。1 と 3 はそのまま。  
FP の GND/VDD 入れ替え修正はリポジトリ上 `ef9d6d4` 済みだが、**実基板は修正前の Gerber**。

GND 足が 0.39V など浮いていると OUT が ≈1.4V に張り付く。0V になってから発振を確認。

### I2S / モジュール

| 項目 | 実測 |
|---|---|
| R719 東（モジュール装着） | ≈ 3.01V（内蔵プルダウンでやや低下） |
| モジュール +3.3V / +5V | あり |
| JP1F | BYPAS 開放 / OSR2 開放 / OSR1・OSR0 ショート / S/_M 開放 / FMT1 開放 / FMT0 ショート |
| CN3F 1 SCKI | ≈ 1.48V（発振している気配） |
| CN3F 2 LRCK / 3 BCK（**モジュール上**） | ≈ 0–0.1V |
| Pico GP0/1/2 | レベル 0、周波数 0Hz |
| CN6F を一瞬短絡（RST パルス） | その後も 2/3 は 0V |

CN3F の 2/3 は PCM1804 の 17/16 番から直接出る（マスタ時は出力）。モジュール上で 0V なら IC が出していない。

### Pico から見える範囲

| 見える | 見えない |
|---|---|
| GP0 DATA / GP1 BCK / GP2 LRCK | SCKI、`ADC_nRST`、±アナログ電源、VCOM |

### Y701 短絡と ADC

- OUT↔GND/3.3V → 主に「クロック来ない」。SCKI 入力破壊は起きにくい
- VDD↔GND 逆接 → `+3V3_A` 全体が危険。ADC も同一電源なら巻き添えしうる
- 現状レールが 3.3V/5V 出ているなら、焼損より未起動の切り分けが先

## 基板上の U709 / U710

`Package_TO_SOT_SMD:SOT-23-6` を **rot=180** で配置しているため、一般的な SOT-23-6 の図とは向きが異なる。

| 位置 | ピン | U709 の接続 | U710 の接続 |
|---|---|---|---|
| 南東 | 1 RESET | `ADC_nRST` | `ADC_nRST`（現在リフト） |
| 東・中央 | 2 GND | `ADC_GND` | `ADC_GND` |
| 北東 | 3 MR | `+3V3_A` | **未接続** |
| 北西 | 4 CT | 100kΩ→VDD | 100kΩ→VDD |
| 西・中央 | 5 SENSE | `+3V3_A` | `+5V_A` |
| 南西 | 6 VDD | `+3V3_A` | `+5V_A` |

- 座標: U709 = (144.490, 52.213)、U710 = (144.430, 56.663)。**U709 が北**
- 見分け方: **3番ピン（北東）に配線があるのが U709**

### `ADC_nRST` ネット

接続: U709 pin1 / U710 pin1（リフト中）/ R719（10kΩ → +3V3_A）/ A701。

**Pico からは制御されていない。**

## 切り分けで潰した仮説

| 仮説 | 判定 | 根拠 |
|---|---|---|
| ADC モジュール側が RST を引いている | ✗ | CN6F を外しても L のまま（初期） |
| 電源電圧不足で監視 IC がアサート | ✗ | SENSE はしきい値以上 |
| `ADC_nRST` が GND に短絡 | ✗ | 電源 OFF で十数 kΩ |
| U709 が最終犯人 | ✗ | 1番リフト後も L、U710 リフトで H |
| U710 RESET 出力 L 固定 | **確定** | 1番リフトで 3.26V |
| スレーブ設定で BCK/LRCK が出ない | ✗ | S/_M 開放を再確認 |
| OSR/FMT ジャンパ違い | ✗ | 設計どおりを再確認 |
| VCOM/OPA 未電源で I2S が出ない | ✗ | デジタル起動には不要 |
| PCM1804 が BCK/LRCK を出していない | **残** | モジュール上 CN3F 2/3 = 0V |

## TPS3808 / PCM1804 メモ

- CT オープンは 220nA 充電。リークに弱い → **100kΩ で VDD へ**が実機でも有効
- CT 電圧: ほぼ 0V = アサート中 / 2–3V = 解除済み
- PCM1804: SCKI の High は 2V 以上。テスター平均 1.4V は振幅保証にならない
- 起動は SCKI が先に来てから RST を離す必要あり（電源投入順に注意）

## 次改版への反映事項

- ASFL FP は `ef9d6d4` の修正版を使う（初号実基板は旧 FP）
- **監視 IC は大きいフットプリント**を検討（SOT-23-6 のリワークが切り分けを阻害）
- U709/U710 の CT を最初から 100kΩ で VDD へ
- SENSE に 1–10nF
- **`ADC_nRST` を Pico からオープンドレインでワイヤAND**（監視 IC は残す。置換は非推奨）
- Y701 の銅箔配線を正す／MCLK テストポイント
- U710 相当の部品は初号で出力不良があったので、実装・調達に注意
