# MeasurementADC 初号機 ブリングアップ記録

最終更新: **2026-08-13**

初号 PCB の立ち上げ作業ログ。現在 `ADC_nRST` が L に張り付いており、ADC が動作せず I2S クロックが出ない状態で止まっている。

---

## 現在の結論

**U709（+3V3_A 監視 / TPS3808G33）がリセットをアサートし続けている。**

`ADC_nRST` を引いているのは U709 で、U710 ではない。SENSE / VDD / MR はすべて解除条件を満たしているため、残る原因は CT ピンが充電できていないか、U709 自体の不良のいずれか。

### 次にやること

1. **U709 の 4番（CT・北西）と 6番（VDD・南西）の間に 100kΩ を渡す**
   - データシート規定の 300ms 遅延モードになる。CT が低インピーダンスで吊られるので、リークがあっても無効化できる
   - これで `ADC_nRST` が 3.3V になれば解決。抵抗はそのまま恒久対策として残せる
2. 変わらなければ U709 の不良。予備の TPS3808G33DBVR（マーキング **AVO**）に換装
   - U710 が 4.45mm しか離れていないのでカプトンテープで養生すること
3. 解決したら A701 と CN6F を戻し、Pico から BCK / LRCK を測定してブリングアップ再開

### 応急処置（監視機能を捨てて先に進む場合）

U709 の **1番ピン（南東）をリフト**すると、R719 の 10kΩ で `ADC_nRST` が 3.29V に上がる。

ただし `ADC_nRST` は **Pico から制御されていない**（後述）ため、監視 IC を切り離すと ADC がパワーオンリセットを受け取れなくなる。`ADC_nRST`–GND 間に 10µF を追加して R719 との RC（時定数 100ms）でリセットパルスを作るか、電源投入後に手で一瞬 GND に落とす。

## 基板上の U709 / U710

`Package_TO_SOT_SMD:SOT-23-6` を **rot=180** で配置しているため、一般的な SOT-23-6 の図とは向きが異なる。

| 位置 | ピン | U709 の接続 | U710 の接続 |
|---|---|---|---|
| 南東 | 1 RESET | `ADC_nRST` | `ADC_nRST` |
| 東・中央 | 2 GND | `ADC_GND` | `ADC_GND` |
| 北東 | 3 MR | `+3V3_A` | **未接続** |
| 北西 | 4 CT | 未接続 | 未接続 |
| 西・中央 | 5 SENSE | `+3V3_A` | `+5V_A` |
| 南西 | 6 VDD | `+3V3_A` | `+5V_A` |

- **東側の列が南から 1・2・3、西側の列が南から 6・5・4**
- 座標: U709 = (144.490, 52.213)、U710 = (144.430, 56.663)。**U709 が北、U710 がその 4.45mm 南**
- 両方とも `ADC_GND` ベタの中にあり、パッドと GND 銅箔のクリアランスは 0.5mm
- 見分け方: **3番ピン（北東）に配線があるのが U709、未接続なのが U710**

### `ADC_nRST` ネット

接続されているのは **U709 pin1 / U710 pin1 / R719（10kΩ → +3V3_A）/ A701** の 4 つだけ。

**Pico からは一切制御されていない。** ソフトリセットは不可で、リセット解除は監視 IC 任せ。

### 手を入れた箇所

- **U710 を新品の TPS3808G50DBVR（AVN）に換装済み** — 結果的に不要な作業だった
- **U710 の CT（4番）–VDD（6番）間に 100kΩ を追加** — 残置してよい
- R719 に並列で 1kΩ を足す実験を行ったが、データシート違反のため撤去済み

### テスターについて

オーム電機 **TST-DTM86**。入力抵抗は公表されていないが、CT が 2.86V を示した事実から **10MΩ 級**と判断できる（1MΩ なら 220nA × 1MΩ = 0.22V までしか振れない）。

## TPS3808 データシートの要点

デバッグ中に効いた仕様。

- **CT は 220nA の定電流で 1.23V まで充電され、到達して初めて RESET が解除される。** オープンで 20ms 遅延
  - 1.23V ÷ 220nA = **5.6MΩ**。CT–GND 間にこれ以下のリークがあると永久にアサートされる
  - 微小電流のため、**テスターを当てるだけでも解除を妨げうる**（10MΩ で 123nA を奪う）
- **アサート中は内部で CT を放電する。** したがって **CT 電圧はそのチップのリセット状態をそのまま示す**
  - 2〜3V = 解除済み / ほぼ 0V = アサート中。犯人特定に使える
- CT を VDD に吊る場合は **40k–200k の抵抗が必須**。直結は放電 FET 経由で VDD–GND を短絡するため厳禁
- RESET ピン電流の推奨上限は **5mA**、プルアップは **10kΩ 以上**（R719 の 10kΩ は下限ちょうど）
- しきい値: G33 = 3.07V / G50 = 4.65V。ヒステリシス VHYS = 1.5–3%
- MR は内部 90kΩ で VDD にプルアップ。VIH = 0.7 × VDD
- マーキング: **TPS3808G33DBVR = AVO** / **TPS3808G50DBVR = AVN**
- SENSE には 1–10nF のバイパスコンデンサが推奨（現状未実装）

## 次改版への反映事項

- **U709 / U710 の CT を 100kΩ で VDD に吊る（300ms モード）。** CT オープン運用は 220nA という微小電流ゆえに汚れや寄生容量に弱すぎる
- **SENSE に 1–10nF のバイパスコンデンサを追加**（データシート推奨、トランジェント耐性）
- **`ADC_nRST` を Pico の GPIO からも制御できるようにする。** 現状ソフトリセット手段がなく、今回のような切り分けで手も足も出ない
- Y701 の銅箔配線を引き直す（現基板は空中配線で回避済み）
