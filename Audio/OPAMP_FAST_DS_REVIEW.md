# 高速寄りオペアンプ — DS 精査（対象・根拠・対応策）

**更新:** 2026-09-24  
**対象回路:** AudioV2 `AmpChannel`（非反転・ゲイン 2・出力アイソレーション抵抗・入出力フィルム結合）。**定数は回路図 `AudioV2/AmpChannel.kicad_sch` が正**。以下「20 k 網」は現行の帰還網、「2 k 網」は高速娘案の帰還網を指す名前  
**在庫の正:** [OPAMP_INVENTORY.md](OPAMP_INVENTORY.md)  
**旧メモ（v1 Amp・47 k/10 k 前提）:** [AmpModule_OPAMP_REFINE.md](AmpModule_OPAMP_REFINE.md) — 数値はこのファイルより古い前提を含む  

回路図から機械的に導出できる部品値・ネットはここに書かない。ここに書くのは **DS の読み**と **差し替え運用の判断**。

---

## 1. 結論（先に）

1. 在庫の「高速枠」に **ユニティゲイン非安定でゲイン 2 禁止の石はいない**。  
2. 以前の粗い分類（「高速＝危ない」「AD797 はゲイン 10 必須」）は **DS と食い違う**。軸を分ける。  
3. AudioV2 の **出力 47 Ω は DS の容量負荷隔離（RISO）推奨と整合**しており、高速娘でも下げない。  
4. 高速娘 1 枚の案は **ゲイン 2 据え置き・Rf/Rg を 2.00 k に下げる**（＋電源デカップ強化）。ただし 2 k 網でも雑音は網の熱雑音が支配し（§3.7）、デカップ追加と Cf は **AmpChannel に足場が無い**（§5）。**高速娘の網・バイアス・足場は未決（2026-09-25 議論中）**

---

## 2. 分類のやり直し（GBW 一塊をやめる）

| 区分 | 石 | 何が本題か |
|---|---|---|
| **A. レイアウト敏感（本当に高速）** | **LT1364** ≫ OPA828 / OPA1656 / LME49860 | ソケット寄生・デカップ・CL ピーキング。最低ゲイン不足ではない |
| **B. 低 Z 網向き（バイポーラ超低ノイズ）** | OPA1612 / LME49860 / **AD797** | ゲイン 2 でも動くが、**20 k 網では `in×R` で en の強みが死ぬ** |
| **C. JFET 高速（網そのままでもノイズ有利）** | OPA828 / OPA1656 | 20 k のままでもノイズは負けにくい。気にするのは CL／RISO／デカップ |
| **D. 中速・通常娘向け** | NJM5532 / 4580 / OPA2134 / OPA1652 / OPA2140 / OPA2604 / OPA627 / MUSES01/02/03 | この精査の主対象外（現行 20 k・ゲイン 2 で素直） |

OPA1656 は計測 SOP が標準。Amp DIP へは変換基板が要る（在庫メモどおり）。

## 3. 石ごと — 対象・DS 根拠・AmpChannel への読み

数値はローカル PDF（[`datasheets/opamps/`](datasheets/opamps/README.md)）および AD797 は Analog Devices Rev.K 本文から。typ @ ±15 V 付近。

### 3.1 LT1364（`AD_LT1364.pdf`）

| | |
|---|---|
| **対象** | 区分 A の筆頭。DIP-8 デュアルそのまま |
| **根拠** | Features: **Unity-Gain Stable**、**70 MHz GBW**、**1000 V/µs**、**C-Load — stable with any capacitive load**（ピーキングは増えうる）。特性図の網は **Rf = Rg = 1 k**（ただし条件は **AV = −1**＝反転。AV = 2 は差動利得・位相（RL = 150 Ω）と歪みの図に出るが、抵抗値の記載は無い）。en ≈ 9 nV/√Hz、in ≈ 1 pA/√Hz |
| **現行 20 k / 47 Ω** | 動きうるが、GBW が電源 100 nF の自己共振帯を超えるので **デカップ不足が本丸**。ソケット＋バス容量でピーキングしやすい |
| **対応策** | 高速娘: Rf/Rg **2.00 k**（DS の特性図が取られている 1 k 級の網に近づける）。電源 **100 nF ＋ 1〜10 nF ピン直近**（足場なし・§5）。出力 **47 Ω 維持**。入出力フィルム変更なし |

### 3.2 OPA828（`TI_OPA828.pdf`）

| | |
|---|---|
| **対象** | 区分 A＋C。手元は Dual DIP 化モジュール |
| **根拠** | GBW **45 MHz**、SR **150 V/µs**。G=1・CL=30 pF で **phase margin ≈ 57°**（UGS）。§ Capacitive Load: 重い CL は出力隔離、**RISO 例 25 / 50 Ω**。en ≈ 4 nV/√Hz、JFET（in 極小） |
| **現行 20 k / 47 Ω** | **47 Ω は RISO 推奨帯に入る**。ノイズも 20 k で負けにくい |
| **対応策** | 通常娘でも試せる。高速娘に載せるなら Rf/Rg 2 k は余裕増。デカップ強化は LT1364 ほど必須ではないが有益 |

### 3.3 OPA1656（`TI_OPA1656.pdf`）

| | |
|---|---|
| **対象** | 区分 A＋C。Amp は SOIC → DIP 変換時のみ |
| **根拠** | GBP **53 MHz**、Unity-gain bandwidth **20 MHz**（G=1）、SR **24 V/µs**。CL drive **100 pF**。Overshoot vs CL に **RISO = 0 / 25 / 50 Ω**。en ≈ 2.9 nV/√Hz、in ≈ 6 fA/√Hz |
| **現行 20 k / 47 Ω** | 電気的には OPA828 と同型の読み。**パッケージ制約が先** |
| **対応策** | 変換モジュールがあるときだけ。網は 828 に準ずる |

### 3.4 LME49860（`TI_LME49860.pdf`）

| | |
|---|---|
| **対象** | 区分 A＋B。DIP-8 |
| **根拠** | **Unity-gain stable**、GBWP **55 MHz**、SR **±20 V/µs**。**CL ≤ 100 pF** はそのまま、**超えたら出力隔離**。en ≈ 2.7 nV/√Hz、**in ≈ 1.6 pA/√Hz** |
| **現行 20 k / 47 Ω** | バス OFF 容量（旧見積 ~265 pF）に対し **47 Ω 隔離は DS どおりの方向**。一方 **20 k では電流ノイズが支配**しやすい |
| **対応策** | 高速娘: Rf/Rg **2.00 k** が本命（安定＋ノイズ）。47 Ω・フィルム維持 |

### 3.5 OPA1612（`TI_OPA1612.pdf`）

| | |
|---|---|
| **対象** | 区分 B（中高速）。DIP 化モジュール |
| **根拠** | **Unity Gain Stable**、GBW **40 MHz**（G=1）、SR **27 V/µs**。低ゲイン＋大 CL はピーキング → **直列 RS**。en ≈ **1.1 nV/√Hz**、**in ≈ 1.7 pA/√Hz**。DS もソース抵抗が低い用途を推奨 |
| **現行 20 k / 47 Ω** | 発振より **ノイズ負けが先**。47 Ω は CL 対策として妥当 |
| **対応策** | 2 k 網で JFET 勢よりわずかに良くなる程度（§3.7。1 kHz で 4.6 vs 5.0〜5.7 nV/√Hz）。en 1.1 nV を生かすには 300 Ω 級の網が要る。ゲインを上げる必要は無い |

### 3.6 AD797（手持ちあり・シングル×2）

| | |
|---|---|
| **対象** | 区分 B。**1 回路なので L/R で 2 個**（Dual 化変換基板想定） |
| **根拠** | en ≈ **0.9 nV/√Hz**、in ≈ **2.0 pA/√Hz**。フォロワは直結帰還だと不安定になりやすく、DS は **100 Ω ダンピング**を要求。一方 **Table 6（Follower with Gain）にゲイン 2 が明示**（例: R1=R2=1 kΩ、CL≈20 pF／300 Ω 級＋CL≈10 pF）。Pin8 の C1/C2 は主に **高ゲインでの歪みキャンセル／デコンプ**であり、「ゲイン 10 未満禁止」ではない。**同じ節に「ソース抵抗は揃える前提。不平衡のソース抵抗 > 200 kΩ/G では使うな」**（G = 2 で 100 kΩ）。入力バイアス電流 0.25 µA typ / 1.5 µA max |
| **現行 20 k / ゲイン 2** | v1 でゲイン 2 改造して発振しない例と矛盾しない（ゲイン 2 自体は正規）。ただし **20 k 網では電流ノイズ最悪級**になりやすい。**＋入力の DC 経路は現行のバイアス抵抗（100 k）で、− 入力側（網の並列）との不平衡が DS の上限（100 kΩ）の際**。＋入力に Ib × 100 k ≈ 25 mV typ / 150 mV max の DC |
| **対応策** | 高速娘既定（2 k）でも可。DS 最適に寄せるなら Rf/Rg **~1 k**＋**Rf 並列 CL ≈ 10〜20 pF**（Table 6: 1 k/1 k で ≈ 20 pF、300 Ω/300 Ω で ≈ 10 pF）。バイアス抵抗を下げるかは未決（下げると入力結合の低域が上がる）。ゲイン 10 専用網は必須ではない（やるなら別袋・別ラベル） |
| **ローカル PDF** | 未保管。メーカー: `https://www.analog.com/media/en/technical-documentation/data-sheets/ad797.pdf`（Rev.K）。2026-09-25 の照合は RS 配布の Rev.J（`https://docs.rs-online.com/b77f/0900766b814b7923.pdf`）で行った。取得したら `datasheets/opamps/` に置く |

### 3.7 雑音の見積もり（1 kHz・入力換算）

en・in（DS typ）と、網の並列 Req = Rf‖Rg の熱雑音の二乗和。＋入力側は低インピーダンスの信号源とみなす。単位 nV/√Hz。

| 石 | 20 k 網（Req 10 k） | 2 k 網（Req 1 k） | 1 k 網（Req 500 Ω） |
|---|---|---|---|
| NE5532（通常娘の基準） | 15.5 | 6.5 | 5.8 |
| LT1364 | 18.6 | 9.9 | 9.5 |
| OPA828 | 13.5 | 5.7 | 4.9 |
| OPA1656 | 13.2 | 5.0 | 4.1 |
| LME49860 | 20.7 | 5.1 | 4.0 |
| OPA1612 | 21.4 | 4.6 | 3.2 |
| AD797 | 23.8 | 4.6 | 3.2 |
| 網の熱雑音だけ | 12.9 | 4.1 | 2.9 |

- 20 k 網では網の熱雑音と in × Req が支配し、JFET（B と C の分け方）が有利 — §2 の分類どおり
- 2 k 網でも網の熱雑音 4.1 nV が支配。バイポーラ超低ノイズ勢は JFET 勢より 1 nV 程度良いだけ
- **低域は別**: ＋入力は入力フィルムとバイアス抵抗で決まり、20 Hz では |Z| ≈ 7 kΩ。in × |Z| は AD797 で ≈ 15 nV、OPA1612 で ≈ 12 nV と網の変更では下がらない（100 Hz で ≈ 3 nV、1 kHz で無視できる） |

## 4. 訂正した誤認

| 旧い言い方 | DS 精査後 |
|---|---|
| AD797 はゲイン 10 以上必須 | **誤り寄り**。G=2 は Table 6。G≥10 は Pin8 技法の文脈と混線していた |
| 高速石はゲインを上げると良い | **必須ではない**（みな UGS または G=2 可）。上げると THD・ヘッドルームは不利 |
| 出力 47 Ω を下げたい | **DS 的には残す**（828/1656 の RISO、LME の CL>100 pF 隔離） |
| 「高速」＝一塊で危険 | **A（レイアウト）／B（網の Z）／C（JFET）に分ける** |

旧 [AmpModule_OPAMP_REFINE.md](AmpModule_OPAMP_REFINE.md) §4.2 の「AD797 はこのゲインでは使わない」は **v1 図面値 47 k/10 k（実装は 10 k/10 k）前提の一次スクリーニング**。AudioV2 と AD797 Table 6 を踏まえた判断は **本ファイルを正**とする。

## 5. 対応策 — 通常娘と高速娘

PCB は共通。**娘 1 枚まるごと実装違い**（ch 混在はしない）。4 ch の Rf/Rg は揃える。

**⚠ 2026-09-25 時点で AmpChannel に「追加デカップ」と「Rf 並列 Cf」のフットプリントは無い**（電源デカップは各レール 100 nF が 1 個ずつ）。PCB 共通のまま下表の高速娘を組むには、未実装（DNP）の足場を回路図・生成スクリプト・PCB に入れる必要がある。入れるかどうかは**未決（議論中）**。

| 項目 | 通常娘 | 高速娘（推奨既定） |
|---|---|---|
| 想定石 | 5532 / MUSES / 中速 JFET など | LT1364 / 828 / 1656 / LME / 1612 / AD797 |
| ゲイン | 2（20 k 網） | **2 のまま**（Rf/Rg = **2.00 k 0.1%**） |
| 出力アイソレーション | 現行 | **現行維持** |
| 入出力フィルム | 現行 | **変更なし**（低域の雑音は §3.7） |
| バイアス / 出力 PD | 現行 | **未決**（AD797 は DS の不平衡条件の際。§3.6） |
| 電源デカップ | 現行（各レール 100 nF） | **＋ 1〜10 nF ピン直近**（LT1364 向け必須級）— **足場なし・未決** |
| Rf 並列 Cf | 無し | **AD797 は ~10–20 pF**（他石はリンギング時のみ）— **足場なし・未決** |
| ラベル | `G2 20k` | `FAST G2 2k` |

### オプション（既定にしない）

| 案 | 網 | いつ |
|---|---|---|
| AD797 DS 最適 | Rf/Rg ≈ 1 k ＋ CL 10–20 pF | AD797 セッションだけ差し替え |
| ゲイン 5 | 例: 10 k / 2.5 k | 交差をさらに下げたいとき（レベル +≈8 dB。通常娘と別セッション） |
| ゲイン 10 | 例: 9.09 k / 1 k | 必要性が薄い。Pin8 技法を試すとき程度 |

聴き比べは **娘ごと差し替え**。ゲイン 2 同士ならレベルは揃えやすい。

## 6. 現行 AmpChannel（20 k）でのざっくり優先度

| 優先 | 石 | 20 k のまま |
|---|---|---|
| そのまま試しやすい | OPA828（変換済み Dual）、OPA1652/2140 等 | 安定・ノイズとも比較的素直 |
| 動くが損する | OPA1612 / LME49860 / AD797 | 発振よりノイズ |
| 回路側を整えてから | LT1364 | デカップ＋できれば 2 k 網 |
| パッケージ先 | OPA1656 | DIP 変換が無いと Amp ソケット不可 |
