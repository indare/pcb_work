## 装置（忘れないこと）

オペアンプ10個を電子的に切り替えて音の差を楽しむ箱。**計測器ではない。**
切替素子の優劣は耳で決める。

## UI（表示）

- **操作は従来どおり**（ENC×3 / DEST SW / ポット）。AmpBankSwitch・AmpBankRelay 共通の FrontPanel
- **状態表示（CH / DEST / Bass / Treble）は Waveshare LCD に寄せる**
- **2.42″ OLED（`J_OLED`）は回路図・PCB から削除**（I²C は MCP / PT / 娘向けのまま）
- **ファーム置き場:** [`firmware/`](firmware/)（骨格。Switch/Relay 共通 API）
  - Switch SEL の外付けプルは無し。起動時は娘 MCP をすぐ出力＋既知値（[`firmware/amp_select.py`](firmware/amp_select.py)）

## AmpBank 番地（ジャンパ 6 段）

- **旧 D21（スロット側 ADDR）はやめ、娘基板の A0/A1/A2 ジャンパで番地を決める**（縦積み B 向け）
- 両版とも娘に MCP23017。スイッチ版 SEL も娘 MCP（親 `U_IO101` 廃止）
- UI MCP は **0x22** のまま。娘は **0x20 / 0x21 / 0x23 / 0x24 / 0x25 / 0x26**
- コネクタ pin 11..16（旧 ADDR/SEL）は母板・娘とも N.C.

## 部品調達（[issue #38](https://github.com/indare/pcb_work/issues/38)）

- **PRECISION / MATCH / SPEC** の正は [PARTS.md §0c](PARTS.md)
- AmpChannel `Rf`/`Rg` は **0.1%**（図上 `20k 0.1%`）。`D-i` 閉じた
- 1 µF / 2.2 µF film は **PET・B32529・P5 のまま**＋LCR 選別（MATCH）。FP 変更なし
- ADC 1.8 nF C0G・HP 470 µF NP・ADC 経路 10 µF NP も MATCH（選別条件は PARTS）

## 電源（ゲート1）

- **`REC20K-2415DZ` に確定**（2026-09-07）。±15 V / ±667 mA / Cout ±3000 µF。回路図・
  フットプリント・シンボルとも差し替え済み。理由3つは
  [DECISIONS.md](DECISIONS.md)「`REC20K-2415DZ` へ差し替え」
- **要求は「合計 mA」ではなく「ソケット1個あたり何 mA」で持つ。** 10 個が常時通電する箱なので。
  いま **42.8 mA/socket**（計測系を `+15V` へ寄せた場合の保守値）。在庫の `MUSES03` は 20 mA
- フットプリントは `Library:REC20K-Z_1in_THT`（穴 Ø1.4）。**Ø1.4 なら `REC10K` も挿さる**ので
  1 個で両方いける。⚠ 旧 `REC10K-AW_1in_THT` は `drill 1.0` で、`REC20K` のピンは入らない
- ⚠ **`F201`（入口 F2A 速断）**。入手性で T1.6A スロー→**F2A 速断**（2026-09-09）。想定 0.75〜1.00 A では余裕。`REC20K` 全能力 1.89 A では定格付近。例: 秋月 `MF51NR 250V2A` / Littelfuse `0217.002` 系
- **`U1604`（MBC2596 非絶縁バック）を削除**（2026-09-07）。ADC の LDO は `+15V` 直結。
  ⚠ **削除の理由は「グランド」であって「スパー」ではない。** 軽負荷スキップ説は同日に
  実測で否定されている（[DECISIONS.md](DECISIONS.md)「`U1604` の軽負荷スキップは否定」）。
  **1.2 kHz スパーの発生源は未特定のまま**で、削除で消えた保証は無い。
  残る理由は、**データシートが無く「非絶縁」が型番からの推定だった**部品が
  `ADC_GND` と `PD_GND` を橋渡ししていたこと ＝ 未確定を確定にした
- **`NT1603`（`A_GND`↔`D_GND`）を新設。** `U1604` を消すとグランドが2島に割れるため。
  結合点の数は1のまま（U1604 の内部 → 置き場所を選べる NetTie）。
  **⚠ PCB では `NT1601` の隣に置く** — I²S の帰りが2ホップになるので、離れるとループ面積になる
- ADC 枝の PPTC（旧 `F1603`）は**戻さない**（2026-09-07 確定）。`LT1763` の電流制限＋サーマルが保護そのもの。枝ごと PPTC の流儀の唯一の例外で、理由は [DECISIONS.md](DECISIONS.md)「ADC 枝の PPTC は戻さない」
- 絶縁容量の不利はスイッチング帯の話。1.2 kHz スパーでは判定しない
- ⚠ **`REC20K` の Ciso 2000 pF は同クラスの最悪端**（低 Ciso 品は 1.5〜20 pF あるが **6 W が上限**で、
  この電力帯に代替が無い）。ただし障壁は `NT1602`→`NT1603` で既にバイパスされていて、
  効くのはスイッチング帯以上（[DECISIONS.md](DECISIONS.md)「絶縁 DC-DC の絶縁容量」）
- **`BP5293` FP の穴は DS 推奨どおり Ø0.9**（ランド Ø2.0）。査読の「DS 1.2」は外形注記
  `A=1.2mmMAX`（基板見え）の誤読。ピッチは等間隔 2.54 mm（Description を訂正済み）

## トーン（PT2314E）

- **`PT2314E` に確定**（2026-09-07）。無印 PT2314 は DigiKey に無く、LCSC / JLCPCB に
  あるのは E のみ。ピン28本は無印と同一、I²C の 26/27 が DATA/CLK → SDA/SCL
- フットプリントは `SOIC-28W_7.5x17.9mm_P1.27mm`。LCSC の
  `SOP-28_L17.9-W7.5-P1.27-LS10.3` と外形・ピッチが一致する（パッドの伸ばし方だけ
  違うがリードスパン 10.3 をどちらも覆う）
- 外付け網は DS どおりに組み直した（`BOUT`/`BIN` を 100n で1点に集め 5.6k で GND）
- トーンを回すのは **`ENC_BASS` / `ENC_TREBLE`**（`ENC1602` が `ENC_VOL` になっていたのを
  2026-09-07 に直した。音量は手回しポット、ボリューム段はインサートで飛ばしている）
- UI の MCP23017 は `INTA`/`INTB` を Pico へ引いた。**I²C は PT2314E 由来で 100 kbit/s 止まり**
  なので、エンコーダをポーリングで読むと I²C バスを塞ぐ。**INT は外付け 10k→`3V3`**
  （2026-09-09。OD なので内部プルだけに頼らない）
- **`DGND`(25) はチップの足元で `A_GND` へ ＋ I²C 境界にレベルシフタ（2026-09-08 実装）。** PT 側は
  `I2C_SDA_9V`/`I2C_SCL_9V`、10k → `VCC_TONE`（9 V）。**⚠ 素子は記録の「P82B96 級」ではなく `BSS138` ×2** —
  `P82B96` の Sx 側 VOL 0.8–1.0 V が PT2314E の VIL 1.0 V / RP2350 の 0.8 V を食い切るため
  （[DECISIONS.md](DECISIONS.md)「DGND はチップの足元で A_GND へ」の実装節）。**2026-09-08 に `BSS138` で確定**（3者合意。
  ツェナーの保険は入れない。故障電圧を嫌うなら次は「5 V × 専用 IC」）

## 箱の I/O（2026-09-07 に入力側が埋まった）

- 入力 `J_IN401`・出力 `J_HP501` / `J_LINE501`。**3つとも L / `A_GND` / R の 3P**（出力側は 2026-09-08 に 2P→3P）。
  入力は Phoenix MKDS-1,5。**HP／LINE は JST XH 3P**（2026-09-15、パネルジャックへケーブル）
- **HP は `U501` バッファ越し**（2026-09-08 に v1 から 5xx で移設。DIP-8 ソケット・標準実装 `OPA1652`・
  10 Ω＋470 µF NP）。`C501`/`C502` の FP は **Ø16 / P7.5**（2026-09-10、Muse ES `UES1E471MHM` が入る）。LINE はバッファ無しで `RV502` 直出し
- **フットプリント未設定は 0**
-   ⚠ **パネル操作は FrontPanel 子基板に集約**（垂直実装→物理パネルへネジ止め）。
  ENC／RV／DEST・PWR SW／DEST LED／LCD／`U1609`／`J_PNL*`（メイトは母板上）。OLED は廃止。
  **DEST は DPDT ON–ON 1本（`SW501`）で PHONE↔LINE。** MUTE 位置は捨てた（電源断は PWR SW）。
  位置センスラダーは廃止（`DEST_ADC` は MC 側で `D_GND` へプル、ファームは無視でよい）。
  **パネル部品 FP（2026-09-15）:** DEST=`Cosland 2MD1`（秋月 104028）／PWR=`Cosland 2MS1`（秋月 100300、片側 NC で ON–OFF）／
  ENC=EC11E 垂直押し・**軸 L=25**・**パネルナット無し**（基板当接 ≈4.5 mm vs トグル≈9 mm を軸長で吸収）。
  FP は `Library:SW_Toggle_Cosland_2MD*`／既存 EC11 H20mm パッド流用。
  **RV501/502（2026-09-15 確定）:** FrontPanel PCB は **`JST XH 6P`（`B6B-XH-A`）**。
  ポット本体は**ユニバーサル基板**→XH ケーブルで接続。垂直 2連 A50k 直付けは捨てた。
  **母板上:** Pico（`A1602`）と計測島は `MeasureControl`。パネル界面コネクタはルート
