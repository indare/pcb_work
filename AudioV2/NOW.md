## 電源（ゲート1）

- **`REC20K-2415DZ` に確定**（2026-09-07）。±15 V / ±667 mA / Cout ±3000 µF。回路図・
  フットプリント・シンボルとも差し替え済み。理由3つは
  [DECISIONS.md](DECISIONS.md)「`REC20K-2415DZ` へ差し替え」
- **要求は「合計 mA」ではなく「ソケット1個あたり何 mA」で持つ。** 10 個が常時通電する箱なので。
  いま **42.8 mA/socket**（計測系を `+15V` へ寄せた場合の保守値）。在庫の `MUSES03` は 20 mA
- フットプリントは `Library:REC20K-Z_1in_THT`（穴 Ø1.4）。**Ø1.4 なら `REC10K` も挿さる**ので
  1 個で両方いける。⚠ 旧 `REC10K-AW_1in_THT` は `drill 1.0` で、`REC20K` のピンは入らない
- ⚠ **`F201`（入口 T1.6A）は据え置き。** `REC20K` を使い切ると入力 1.89 A で切れる（118 %）。
  いまの想定 0.75 A・計測系を寄せても 1.00 A なので足りているが、**全能力を使う判断はまだ無い**
- **`U1604`（MBC2596 非絶縁バック）を削除**（2026-09-07）。ADC の LDO は `+15V` 直結。
  ⚠ **削除の理由は「グランド」であって「スパー」ではない。** 軽負荷スキップ説は同日に
  実測で否定されている（[DECISIONS.md](DECISIONS.md)「`U1604` の軽負荷スキップは否定」）。
  **1.2 kHz スパーの発生源は未特定のまま**で、削除で消えた保証は無い。
  残る理由は、**データシートが無く「非絶縁」が型番からの推定だった**部品が
  `ADC_GND` と `PD_GND` を橋渡ししていたこと ＝ 未確定を確定にした
- **`NT1603`（`A_GND`↔`D_GND`）を新設。** `U1604` を消すとグランドが2島に割れるため。
  結合点の数は1のまま（U1604 の内部 → 置き場所を選べる NetTie）。
  **⚠ PCB では `NT1601` の隣に置く** — I²S の帰りが2ホップになるので、離れるとループ面積になる
- ADC 枝の PPTC（旧 `F1603`）は**戻さない**（2026-09-07 確定）。`LT1763` の電流制限＋サーマルが保護そのもの。枝ごと PPTC の流儀の唯一の例外で、理由は [DECISIONS.md](DECISIONS.md)「ADC 枝の PPTC は戻さない」
- 絶縁容量の不利はスイッチング帯の話。1.2 kHz スパーでは判定しない
- ⚠ **`REC20K` の Ciso 2000 pF は同クラスの最悪端**（低 Ciso 品は 1.5〜20 pF あるが **6 W が上限**で、
  この電力帯に代替が無い）。ただし障壁は `NT1602`→`NT1603` で既にバイパスされていて、
  効くのはスイッチング帯以上（[DECISIONS.md](DECISIONS.md)「絶縁 DC-DC の絶縁容量」）

## トーン（PT2314E）

- **`PT2314E` に確定**（2026-09-07）。無印 PT2314 は DigiKey に無く、LCSC / JLCPCB に
  あるのは E のみ。ピン28本は無印と同一、I²C の 26/27 が DATA/CLK → SDA/SCL
- フットプリントは `SOIC-28W_7.5x17.9mm_P1.27mm`。LCSC の
  `SOP-28_L17.9-W7.5-P1.27-LS10.3` と外形・ピッチが一致する（パッドの伸ばし方だけ
  違うがリードスパン 10.3 をどちらも覆う）
- 外付け網は DS どおりに組み直した（`BOUT`/`BIN` を 100n で1点に集め 5.6k で GND）
- トーンを回すのは **`ENC_BASS` / `ENC_TREBLE`**（`ENC1602` が `ENC_VOL` になっていたのを
  2026-09-07 に直した。音量は手回しポット、ボリューム段はインサートで飛ばしている）
- UI の MCP23017 は `INTA`/`INTB` を Pico へ引いた。**I²C は PT2314E 由来で 100 kbit/s 止まり**
  なので、エンコーダをポーリングで読むと OLED と同居できない
- **未実装の確定事項:** `DGND`(25) をチップの足元で `A_GND` へ、I²C の境界にバッファ＋
  9V プルアップ（[DECISIONS.md](DECISIONS.md)「DGND はチップの足元で A_GND へ」）。
  回路図はまだ `DGND → D_GND` のまま。**B5 でバッファの置き場を決めるときに一緒に入れる**

## 箱の I/O（2026-09-07 に入力側が埋まった）

- 入力 `J_IN401`（L / A_GND / R）・出力 `J_HP501` / `J_LINE501`。全部 Phoenix MKDS-1,5
- **フットプリント未設定は 0**
- ⚠ **パネル部品は2種類ある。** ヘッダ（現物は箱配線・基板の位置は自由）= `RV501/502`・
  `SW402`・`SW501/502`・`SW1601`。**基板実装（本体が基板に載る）= `ENC1601-1603`
  （EC11 垂直・軸20mm）・`D1610/D1611/D403`（5mm LED）・`A1602`（Pico の USB）**。
  後者があるので **`MeasureControl` はフロントパネルの直後に固定される** — 基板の
  置き場を動かす検討をするときは、まずここを見ること
- 親シートの6ラベルは箱外スタブ。ERC に `label_dangling` として出るが**仕様**
