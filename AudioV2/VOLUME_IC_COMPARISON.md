# AudioV2 音量 IC 比較 — B（MCP45HV51 ×4）vs C（PGA231x ×2）

[DECISIONS.md](DECISIONS.md) §3 の「digipot は B か C」を決めるための調べ物。一次ソースは各社データシート（本文中にリンク）。

---

## 0. 先に結論

**確定: C 系 — [PGA2310PA](https://www.ti.com/lit/ds/symlink/pga2310.pdf) ×2（DIP-16）。** B（MCP45HV51 ×4）は見送り。

**電源: アナログ ±12 V**（例: DKMW20F-12）。PD 給電モジュールは差し替え可（2026-08 確定）。

判断を動かした事実は 2 つある。どちらも今の DECISIONS.md の記述と食い違う。

| # | 見つかったこと | 影響 |
|---|---|---|
| 1 | **PGA2311 のアナログ電源は ±5 V**。入出力は ±3.75 V（2.65 Vrms）まで | DECISIONS.md §3 の「耐圧 ±15 V 系で実績」は **PGA2311 では成り立たない**。Amp 後・LINE 無パッドの前提と直接ぶつかる。±15 V の兄弟品は **PGA2310 / PGA2320** |
| 2 | **MCP45HV51 の I²C アドレスは `0111 1 A1 A0` = 0x3C–0x3F の 4 個だけ** | 4 個使うと **アドレスを使い切る**。制御 OLED（SSD1306）は 0x3C / 0x3D しか選べないので **必ず衝突する**。B は「I²C 一本に集約できる」という当初の最大の利点を自分で潰す |

つまり **B の売りだった「バスを増やさない」が成立しない**。B も C も、操作 Pico に 2 本目のバス（B なら I²C1、C なら SPI0）が要る。ピン数の差は 1 本しかない。そこが分かると、あとは音質・実装のしやすさで素直に C 系が勝つ。

---

## 1. まず C の品種を確定させる（PGA2311 → PGA2310）

PGA2311 / 2310 / 2320 は**ピン互換・ソフト互換**（さらに Cirrus CS3310 とも互換）。違うのは電源電圧・パッケージ・値段だけ。

| | **PGA2311PA** | **PGA2310PA（推奨）** | PGA2320IDW |
|---|---|---|---|
| アナログ電源 | ±5 V（±4.75〜±5.25） | **±4.5〜±15.5 V** | ±4.5〜±15.5 V |
| 入出力レンジ | レールから 1.25 V 内側 → **±3.75 V / 2.65 Vrms** | レールから 1.5 V 内側 → **±13.5 V / 9.5 Vrms** | レールから 0.86 V 内側 |
| THD+N @1 kHz | 0.0004 %（U）/ 0.0002 %（A） | **0.0004 %**（VIN = 10 Vpp） | 0.0003 % |
| 出力ノイズ | — | **9.5 µVrms**（typ、0 dB） | 10.5 µVrms |
| パッケージ | PDIP-16 / SOIC-16 | **PDIP-16** / SOIC-16 | **SOIC-16 のみ** |
| 単価（1 個、2026-08 時点） | 数 US$ | **US$15〜22** | US$18〜27（TI 直販は在庫切れ） |

Amp（NE5532 ×10・±15 V）の出力は最大 ≈ ±13 V = **9.19 Vrms**。

- **PGA2310**: 入出力レンジ ±13.5 V。**Amp のクリップ点とほぼ一致する** → 音量 IC が先に飽和しない。パッド不要。
- **PGA2311**: 2.65 Vrms 止まり。LINE 無パッドでは **−11 dB 以上の固定パッドを前段に足さないと成立しない**（9.19 → 2.65 Vrms が −10.8 dB）。HP 側もパッドが digipot の**後ろ**にある現行案のままだと同じく足りない。
- **PGA2320**: 電気的には最良だが SOIC のみ・高い・在庫が薄い。DIP ソケット主体のこのプロジェクトでは選ぶ理由がない。

以降 **「C」= PGA2310PA ×2**（HP 用 1 + LINE 用 1）として比較する。原案の PGA2311 のままなら、下表の「回路設計」で **パッド 4 本（2 抵抗 × 2 系統 × L/R）が追加**になる点だけ読み替える。

## 2. 信号レベルの実際（判断の土台）

```text
[Amp NE5532 ×10 / ±15V]  最大 ±13V = 9.19 Vrms
        ├─ 測定タップ（音量非連動）
        ├─ HP  : 音量IC ──(-20dB pad 8.2k/910)── HeadphoneBuffer → PHONE
        └─ LINE: 音量IC ─────────────────────► LINE OUT
```

- 固定パッド 8.2 kΩ 直列 + 910 Ω 並列 = **−20.0 dB**、出力インピーダンス 819 Ω（`Audio/README.md` の実績値）
- HP で必要な減衰幅: 9.19 Vrms → 1 Vrms（32 Ω で 31 mW＝十分うるさい）が **−19 dB**、→ 5 mVrms（かなり静か）が **−65 dB**。**約 46 dB のレンジ**
- LINE で必要な減衰幅: 9.19 Vrms → 1〜2 Vrms が **−13〜−19 dB**、上下 ±10 dB 見て **−3〜−29 dB**

### MCP45HV51 のリニア 256 タップを dB に直すと

分圧接続（A = 信号、B = `A_GND`、W = 出力）で減衰量 = `20·log10(n/255)`。

| コード n | 減衰 | 1 タップあたりの刻み |
|---|---|---|
| 255 | 0.00 dB | 0.03 dB |
| 128 | −5.99 dB | 0.07 dB |
| 64 | −12.01 dB | 0.14 dB |
| 32 | −18.03 dB | 0.28 dB |
| **18** | **−23.03 dB** | **0.50 dB** |
| 8 | −30.07 dB | 1.16 dB |
| 4 | −36.09 dB | 2.50 dB |
| 2 | −42.11 dB | 6.02 dB |
| 1 | −48.13 dB | （下は 0 = ミュートへ落ちる） |

読み方:

- **0 〜 −23 dB は 0.5 dB 以下**。ここは PGA2310 と同等かむしろ細かい
- **−30 dB より下で 1 dB を超え、−42 dB で 6 dB 刻み**になる
- **−48 dB が床**。その次はコード 0（ミュート）で崖

HP は −20 dB パッドがあるので、digipot 側 0〜−25 dB（＝トータル −20〜−45 dB）が常用域になる。**そこは 0.6 dB 以下で足りている。** 粗くなるのは digipot −30 dB より下、つまり深夜の小音量域。「使えない」ではなく「静かにするほど刻みが荒れる」。

PGA2310 は **0 〜 −95.5 dB の全域が 0.5 dB 均一**、コード 0 でミュート。

## 3. 比較表

5 点満点。B = MCP45HV51 ×4、C = PGA2310PA ×2。

|---|---|---|---|

| **配線** | **3 / 5**<br>**アドレスが 0x3C–0x3F の 4 個で打ち止め**。4 個使うと OLED（0x3C/0x3D）が入らないので、**digipot 専用に I²C1 を立てる（GP2 本）**のが実質唯一の素直な解。IC は TSSOP-14 ×4 = 56 パッド、しかも ±15 V アナログ基板の上。加えて **LINE を駆動する出力バッファ（デュアル OPA ×2）が要る**（ワイパー出力インピーダンスが 10 k 品で最大 2.5 kΩ）。結局 IC は 6 個 | **4 / 5**<br>SPI 3 本（SCLK / SDI / CS）＋ MUTE 1 本。**2 個は SDO→SDI でデイジーチェーン**（CS は共有・32 clk）なので、**IC が増えてもピンは増えない**。DIP-16 ソケット ×2 で手はんだ・差し替え可。出力バッファ不要（LINE を直結できる）。ZCEN は VD+ 固定で GPIO を食わない | **C** |
| **ノイズ** | **3 / 5**<br>抵抗ノイズは 10 k 品の中点で 0.91 µVrms（20 kHz 帯域）＝無視できる。だが**必須の出力バッファが定常ノイズを足し戻す**ので実効は引き分け。**ジッパーノイズが構造的に残る**のが実害。I²C は OLED の 1 KB フレーム転送（400 kHz で ≈25 ms 連続）を抱えるので、**アナログの近くで動くデジタル活動は B の方が多い** | **4 / 5**<br>出力ノイズ 9.5 µVrms（typ）。9.19 Vrms 出力時 SNR ≈ 120 dB。減衰を深くしても出力バッファのノイズは残る＝深い減衰では受動分圧より不利、という理屈上の弱点はあるが、B もバッファを足すので差は消える。**ゼロクロスでジッパーノイズが原理的に出ない**。SPI はバースト動作で**普段は静止している**（§5） | **C**（僅差） |
| **回路設計** | **2 / 5**<br>digipot ×4 + バッファ ×2 + 第 2 I²C バス + （ジッパー対策するなら）ゼロクロス比較器。DGND / VL / V+ / V− の関係（`VL ≥ V− + 2.7 V`、DGND は V− と V+ の間）を 4 個ぶん確認する。**ファームでリニア→対数カーブを自前で書く**。**Rev. ## 4. Pico 2 ピンバジェット（実数）

`Audio/Controll.kicad_sch` では GPIO0–19 がリレーコイルで埋まっていたが、**AudioV2 は基板 B 分割 + B2-exp（MCP23017）確定**なので、コイル線は操作 Pico から消えている。つまり **ピンはむしろ余っている**。

Pico 2（RP2350A）で外に出ている GPIO は **GP0–GP22 と GP26–GP28 の 26 本**（GP23 = SMPS、GP24 = VBUS sense、GP25 = LED は使えない）。

| 用途 | B | C |
|---|---|---|
| I²C0（OLED制御 / MCP23017 / PT2314） | GP20 SDA, GP21 SCL … **2** | GP20 SDA, GP21 SCL … **2** |
| 音量 IC | **I²C1 が必須**（0x3C 衝突）GP18/GP19 … **2** | SPI0: GP18 SCLK, GP19 SDI, GP17 CS … **3** |
| MUTE | −（SHDN を使うなら +1〜4） | GP16（2 個共通・負論理）… **1** |
| ENC ×6（A/B/SW 直結） | 18 | 18 |
| **合計** | **22 / 26** | **24 / 26** |
| 残り | 4 | **2** |

**差は 1 ピン。** 「I²C ならピンが浮く」は、アドレス衝突で 2 本目のバスが要る以上ほぼ成り立たない。

### C を選んだ場合の推奨割り当て

| GPIO | 用途 | 備考 |
|---|---|---|
| GP0–GP11 | ENC ×6 の A / B | **直結必須**。GPIO 拡張越しだと取りこぼす |
| GP12–GP15, GP26, GP27 | ENC ×6 の SW | 押しボタンは遅いので、逼迫したら MCP23017 + INT に逃がせる（6 本浮く） |
| GP16 | `PGA_MUTE`（両 IC の pin 8 に共通、負論理） | 10 kΩ プルダウンを付けると**電源投入直後から強制ミュート** |
| GP17 | `PGA_CS`（両 IC の pin 2 に共通） | ハード CSn でなく通常 GPIO でよい（MicroPython は CS を自動駆動しない） |
| GP18 | `PGA_SCLK`（SPI0 SCK、両 IC の pin 6） | |
| GP19 | `PGA_SDI`（SPI0 TX、**1 個目の** pin 3） | 1 個目の SDO(pin 7) → 2 個目の SDI(pin 3) |
| GP20 / GP21 | I²C0 SDA / SCL | `Control/protocol.py` のまま変えない |
| GP22, GP28 | 予備 | PWR 検出 / 12 V LED 系など |

MISO（SDO の戻り）は **Pico に繋がない**。書き込み専用で足りるうえ、SDO は VD+ = 5 V 出力なので 3.3 V の Pico に直結してはいけない。読み戻しが欲しくなったら分圧かレベルシフタを挟む。

ENC ×6 のポーリングが重いなら、RP2350 の **PIO でクアドラチャデコーダ**を回すのが素直（PIO ブロック 3 × SM 4 = 12 個、6 本ぶんは余裕）。SPI0 は PIO と競合しない。

## 5. SPI をアナログ音声と同じ基板に載せてよいか → **よい。この設計では I²C より静か**

理由は「SPI がバースト動作だから」に尽きる。

| | この設計での実際の動作 |
|---|---|
| **PGA2310 の SPI** | エンコーダーが 1 ステップ動いたときだけ **32 clk**（2 個デイジーチェーン = 16 bit × 2）。1 MHz なら **32 µs**。**音楽を聴いている間、SCLK は静止している** |
| **I²C（どちらの案でも動く）** | 制御 OLED の SSD1306 が **1 KB フレーム**を 400 kHz で吐く。1 回の描画で **≈25 ms 連続スイッチング**（`Control/README.md` に「100 kHz に落とすとタイムアウトする」と実測が残っている） |

**digipot を I²C にしても、その隣で OLED が 25 ms 叩き続けている**。つまり「デジタルをアナログから遠ざけたい」という動機で B を選ぶのは筋が通らない。むしろ C の方が音量 IC の足元は静か。

そのうえで、載せるときの条件:

- SCLK / SDI / CS を `VINL`(16) `VINR`(9) `VOUTL`(14) `VOUTR`(11) と**長く平行に走らせない**。交差は直交で
- SPI クロックは **1 MHz 程度**にする（上限 6.25 MHz だが速くする理由がない）。エッジを鈍らせたければ Pico 側に直列 100 Ω
- **DGND(5) は `D_GND` 島、AGNDL(15) / AGNDR(10) は `A_GND` 島**に落とす。結合は `MeasurementADC` と同じ **NetTie 一点**（DECISIONS.md §7 の G2 がそのまま使える）
- VD+(4) は 0.1 µF + 10 µF、VA+(12) / VA−(13) は 0.1 µF + 10 µF を**ピン直近**に
- ZCEN(1) は VD+ に固定（ゼロクロス常時 ON）。ゼロクロス 2 回か **16 ms タイムアウト**でラッチされる仕様なので、無信号時に速くノブを回すと最大 16 ms 遅れるが、**最後に書いた値が勝つ**ので実害はない

## 6. 決定木

### 「音質を最優先。Amp 差し替え比較の測定に、音量段の素性の分からない歪みを混ぜたくない」 → **C（PGA2310PA）**

AudioV2 の目的は `AMP401` ソケットで**アンプを差し替えて聴き比べ・測り比べ**すること（`Audio/README.md`）。音量段は「測っても出てこない」ものであるべき。MCP45HV51 は **THD がデータシートに無い**＝比較実験に未知の変数を 1 つ足すことになる。

### 「部品代が最優先。音量は聴ければいい。US$30 の差は大きい」 → **B**

ただし見積もりは正直に。**digipot ×4（US$5〜12）だけでは終わらない**。第 2 I²C バス、TSSOP-14 ×4 の実装、LINE 用出力バッファ（デュアル OPA ×2 + ソケット）、ジッパー対策するならゼロクロス比較器まで含めて比べること。差は US$20〜30 に縮む。

### 「I²C 一本に集約したい。SPI を増やしたくない」 → **その願いは B では叶わない**

MCP45HV51 は 0x3C–0x3F の 4 アドレスしか無く、4 個で使い切る。制御 OLED（0x3C / 0x3D）が必ず衝突するので、**B でもバスは 2 本になる**。本当に叶えたいなら **音量を Amp 前（小信号）に移す**という別の判断が要る（→ §7-3）。

### 「はんだ付けは DIP だけにしたい。後で差し替えて聴き比べたい」 → **C（PGA2310PA）**

PGA2310PA は **PDIP-16**。このプロジェクトは `AMP401` / `AMP801` / `AMP901` を全部 DIP ソケットにしている作り方なので、そこに素直に乗る。MCP45HV51 は **TSSOP-14 と QFN しか無く、DIP が存在しない**。0.65 mm ピッチ ×4 を ±15 V アナログ基板に直付けすることになり、**ソケット化＝差し替え・リワークができない**。

### 補足: 「LINE しか使わない。HP は要らない」 → **B でも十分**

LINE の常用域（−3〜−29 dB）は MCP45HV51 のタップで **0.05〜0.9 dB 刻み**に収まる。B の解像度の弱点（−30 dB 以下）に当たらない。ただし出力バッファは要る。

## 7. 推奨と、変わる条件

### 推奨（デフォルト）

**C 系: PGA2310PA ×2**（HP 用 1 + LINE 用 1）、SPI0 デイジーチェーン、DIP-16 ソケット実装。

- HP: `Amp出力 → PGA2310(HP) → −20 dB パッド → HeadphoneBuffer → PHONE`
  - パッドは**残す**。理由が変わる: 元々は「機械式ポットが回転下端でしか使えない」対策（`Audio/README.md`）だったが、デジタル音量ではその問題は消える。**残す理由はノイズ**で、PGA2310 の出力ノイズ 9.5 µVrms を −20 dB してヘッドホンに渡せる（0.95 µVrms）。感度の高いイヤホンでのヒスに効く
- LINE: `Amp出力 → PGA2310(LINE) → LINE OUT`
  - **バッファ不要**（600 Ω 直接駆動可）。パッドも不要（±13.5 V レンジが Amp のクリップ点とほぼ一致）
- ファーム: `N = 192 + round(dB × 2)` を **N ≤ 192** に制限すれば純減衰器（N=192 が 0 dB、N=1 が −95.5 dB、N=0 がミュート）。HP と LINE で 2 個ぶん = **32 bit を 1 トランザクションで書く**

### 次点（正直に）

**B: MCP45HV51 ×4。**「US$30 の差額が判断を決めるほど効く」場合のみ。その場合は 10 kΩ 品（`MCP45HV51-103E/ST`、帯域 240 kHz）を選び、分圧接続で使い、**LINE / HP とも出力にユニティゲインバッファを入れる**。第 2 I²C バスは digipot 専用にする（エラッタの「専用バスに置け」に半分だけ従える）。

### 推奨が変わる条件

| 条件 | 何が起きるか | どうするか |
|---|---|---|
| **±12 V レールに変更** | PGA2310 に余裕。Amp 最大出力は ≈6〜7 Vrms（−2〜3 dB）。HP パッド見直し | **AudioV2 確定**。±15 V へ戻すなら PGA2310 上限問題が再発 |
| **PGA2310PA の入手が切れた / 価格が倍になった** | C 系が成立しない | ピン互換の **PGA2311PA + 前段 −14 dB パッド**（LINE / HP 両方に 2 抵抗ずつ）に落とす。または CS3310（DIP-16、±5 V、同じくパッド前提） |
| **音量を Amp 前（小信号）に移す判断に変える** | **HV 要件が丸ごと消える**。この比較の前提が全部崩れる | 小信号なら **PGA2311PA が最有力**（安い・DIP・±5 V で足りる）。B 側も MCP4251 級の普通の digipot でよくなり、価格差もほぼ消える。**これが一番大きいレバー**。DECISIONS.md §2 で B（Amp 後）を確定済みなので、覆すなら §2 から |
| **音量チャンネルを増やしたくなった**（バランス、CH 個別トリム、サブアウト） | B は **4 アドレスで打ち止め**。5 個目は I²C マルチプレクサ（PCA9548A）が要る | C は **SDO→SDI でデイジーチェーンするだけ、GPIO 追加ゼロ**。拡張予定があるなら C 一択 |
| **ENC ×6 を GPIO 拡張に逃がすことにした** | ピン圧は下がる | **判断は動かない**。B と C のピン差は元々 1 本 |
| **手元の MCP45HV51 が Rev. A2 以降だと確認できた** | B の I²C エラッタ（Rev. A1 の General Call 問題）リスクが消える | B の「回路設計」が 2 → 3 点相当に上がるが、THD 無記載・TSSOP のみ・出力バッファ必須は変わらないので結論は同じ |
