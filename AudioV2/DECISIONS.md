# AudioV2 判断メモ

前提（合意寄り）:

- スペアナ用 Pico 2 は独立（負荷・ノイズ・GND 島が違う）
- ラッチングリレーで多系統 Amp のうち **1 系統だけ有効**は残す
- **操作側 Pico は 1 台**（リレー用の子 Pico は置かない）
- 音量はエンコーダー化を検討（機械式デュアルポット置き換え）
- `Audio/` は参考のまま残し、ここは新規プロジェクト

### 決定ログ

| 項目 | 状態 | 内容 |
|---|---|---|
| 基板の切り方 | **確定** | **B**: リレー＋端子台盤。操作 Pico / ENC / OLED / digipot は別 |
| 切替信号の渡し方 | **確定** | Pico 1 台 + **I²C GPIO 拡張（B2-exp）** + ULN |
| CH / 電源 / 音声切替 | **確定** | ラッチングリレー（1 系統のみ有効） |
| CH 操作 | **確定** | **ENC_CH**（現行どおり）。**回して候補変更、押して確定**（確定で音声＋電源リレー適用） |
| 音量 | **確定** | Amp 後。**ENC_HP / ENC_LINE は独立**（別 digipot） |
| 出力先 | **確定** | **ENC_DEST**: 回して候補、押して確定。**LINE → PHONE → MUTE** ループ。**起動時 LINE**。切替は **出力段のラッチングリレー**（CH と同系）。`A_GND` は共有のまま音声出口だけ切替 |
| トーン | **確定** | **ENC_BASS / ENC_TREBLE** の 2 個（独立）。制御 OLED にも表示。バクサンドール系の回路方式は後続 |
| OLED | **確定** | **2 枚**。計測＝スペアナ用／操作＝制御用 |
| 電源 UI | **確定** | **パワースイッチ＋12V LED**（電源投入の視認用） |
| ULN2803 | 役割固定 | コイル電流増幅のみ |
| トーン | **確定** | **T1: PT2314 系**（Princeton / TDA7313 互換）。**Amp 前**（小信号）。ENC_BASS / ENC_TREBLE → I²C |
| 音量 digipot | **B か C で最終決定** | 下記 §3。DS1882 案は見送り |

## 0. 操作系統まとめ（いまここを先に固める）

### アクチュエータ（何が動くか）

| 対象 | 仕組み |
|---|---|
| CH 選択（どの Amp を活かすか） | ラッチングリレー（音声） |
| その系統の電源 | ラッチングリレー（電源） |
| 出力先 PHONE / LINE / MUTE | **出力段**のラッチングリレー（CH と同系）。`A_GND` 共有のまま音声出口を切替 |
| HP 音量 | digipot（Amp 後 → パッド → HeadphoneBuffer 前） |
| LINE 音量 | digipot（Amp 後 → LINE） |
| バクサンドール（Bass/Treble 等） | デジタル制御（後続で方式決定）。**制御 OLED に状態表示** |
| スペアナ表示 | 計測 Pico 側（独立） |

### 操作子・表示（人が触るもの）

| 部品 | 役割 |
|---|---|
| **ENC_CH** | CH 選択。**回す＝候補、押す＝確定**（確定時に音声＋電源ラッチング適用）。現行 Controll と同じ |
| **ENC_HP** | HP 音量専用 |
| **ENC_LINE** | LINE 音量専用 |
| **ENC_DEST** | 出力先。**回す＝候補、押す＝確定**。並び **LINE → PHONE → MUTE**（ループ）。**起動時 LINE** |
| **ENC_BASS** | トーン Bass 専用。制御 OLED に表示 |
| **ENC_TREBLE** | トーン Treble 専用。制御 OLED に表示 |
| **OLED 制御用** | CH・音量・出力先・Bass/Treble。操作 Pico 配下 |
| **OLED スペアナ用** | 計測専用。計測 Pico 配下 |
| **PWR SW + 12V LED** | 本体電源スイッチ。12V LED で ON 視認 |

```text
[操作パネル]
  ENC_CH  ENC_HP  ENC_LINE  ENC_DEST  ENC_BASS  ENC_TREBLE   OLED_制御   PWR+12V LED
      \      \       |        /         /          /             |            |
       \      \      |       /         /          /              |            |
        ======== Pico 操作 1台 ========（表示・制御）============     （電源系）
                       | I2C
       +--------+------+------+----------+-----------+
       |        |      |      |          |           |
  digipot_HP  digipot_LINE  トーン系   GPIO拡張    OLED
                                      |
                                    ULN→ラッチング
```

エンコーダーは **6 個**（各 A/B/SW → 直結なら 18 本）。実装時は **I²C 集約／GPIO 拡張**を検討（リレー用拡張とバス共有可）。

### DEST 確定ルール（確定）

| 項目 | 内容 |
|---|---|
| 操作 | 回して候補、押して確定（CH と同型） |
| 並び | **LINE → PHONE → MUTE**（表示・候補とも **ループ**） |
| 起動 | **LINE**（押さなくても起動処理で LINE を適用） |
| その他表示 | CH / 音量 / Bass / Treble の表示もループでよい（本節で「全て表示はループ」） |

### 出力先にリレーは必要か → **必要。出力段にラッチング（確定）**

| 項目 | 内容 |
|---|---|
| 素子 | CH と同じ **ラッチングリレー** |
| 置き場所 | **出力段**（CH 選択のリレー盤ではない） |
| 役割 | `A_GND` は共有のまま、**音声の出口**（LINE / PHONE / MUTE）だけ切替 |
| MUTE | 両経路オフ |
| 駆動 | 操作 Pico →（I²C・GPIO 拡張可）→ ULN → コイル |

旧 SW101（手回し DP3T）は ENC_DEST + このラッチングに置き換え。

### 操作系統の残り穴

1. digipot / トーン回路の品種
2. 12V LED の取り出し元
3. ENC×6 の配線（GPIO 直結 / I²C 集約）
4. 出力段ラッチングのコイル電源と、GPIO 拡張を操作側バスへどう乗せるか

## 1. 基板の切り方（いちばん大きい判断）

### A. Controll 型一体（Pico + リレー + 端子台 + UI ヘッダ）

いまの `Controll.kicad_sch` に近い。digipot も同じシート／基板に足す。

| メリット | デメリット |
|---|---|
| 配線・コネクタが最少 | 1 枚が混在信号になりやすい（`CTRL_GND` と `A_GND`） |
| 既存回路・ファームをほぼ流用 | 改版のたびにリレー基板も触る |
| I²C digipot なら GPIO 不足にならない（バス相乗り） | アナログ音量が乗るとレイアウトが窮屈 |

### B. リレー＋端子台だけの基板 ／ Pico・ENC・OLED・digipot は別基板（有力）

リレー盤は「コイル駆動 + 接点の端子台」に徹する。知能は操作基板へ。

| メリット | デメリット |
|---|---|
| リレー盤が単純・改版しやすい（接点配線の箱物向き） | 基板間ケーブルが増える（コイル用 GPIO 束、またはバス化が必要） |
| デジタル電流とラッチング・サージをアナログ音量から遠ざけやすい | 「誰がコイルを叩くか」を決める必要がある（下記 1-付記） |
| リレーだけ先に起こして箱配線を進められる | コネクタピンアサインの設計コスト |

**1-付記: 切替信号を外から渡すときの受け側（いまここ）**

ケーブルを細くするには、リレー盤上で「コマンド → 各コイルの短パルス」に展開する必要がある。ULN の手前に置くのは次のどちらか。

| 副案 | 内容 | メリット | デメリット |
|---|---|---|---|
| **B2-exp**（I²C GPIO 拡張） | MCP23017 等 + ULN。マスターがビットを書いてパルス相当を出す | ファームがマスター側に集約。部品が安い。ブートローダ不要 | パルス幅・排他（他 CH を落とす順）をマスターが面倒を見る。I²C トラブル時のフェイルセーフを決めにくい |
| **B2-mcu**（子 MCU） | 盤上の安い MCU（Pico 小／既存子 Pico 発想）+ ULN。マスターは「CH n」等を I²C で投げる | パルス・排他・起動時デフォルトを盤側で完結。現行 `Control/slave.py` の延長 | ファームが 2 つ。電源・リセット・アドレス管理が増える |
| ~~B1~~ | GPIO 20 本直結 | — | 束が太いので見送り寄り |
| ~~デコーダ IC のみ~~ | 74HC138 等で番地デコード | 線は減る | ラッチングのワンショット／誤パルス対策が基板論理になり、拡張より得しにくい |

### C. 3 枚構成（リレー盤 / 操作+Pico / 音量 digipot）

| メリット | デメリット |
|---|---|
| `A_GND` 境界を基板単位で切りやすい | コネクタと筐体設計が重い |
| 音量段だけ後から差し替え可能 | 過剰分割になりやすい（この規模だと B で足りることが多い） |

**確定:** 基板は **B**。受け側は **B2-exp（I²C GPIO 拡張）**。  
理由: ラッチング 20 台級も親 Pico 1 台 + 拡張 IC で足りる。盤側に子 MCU を置く必然がない。パルス幅・排他・起動時 Reset は親ファームの規約にする。

## 2. 音量（digipot）をどこに置くか

Amp は ×10・±15 V 系。digipot の耐圧と配置はセットで決める。

### A. Amp **前**（入力減衰）

| メリット | デメリット |
|---|---|
| 普通の digipot（±5 V 級）で足りやすい | 全系統の Amp 入力前なので、リレー切替の **前か後か**で意味が変わる |
| 部品が安く入手しやすい | 測定タップ（Amp 後）のレベルは音量と連動しない／するを要設計 |
| クリッピング耐性が高い側に振れる | 「聴感音量」と「Amp 出力フルスケール」がずれる |

※ リレーで Amp を選ぶ構成なら、digipot はだいたい **選択後の共通バス上（選ばれた Amp の入力側 or 出力側）** になる。入力側共通バスに置くなら「選ばれた系統の入力レベル」を一括で絞る形。

### B. Amp **後**・現行 `RV101`/`RV102` 位置（出力減衰）

| メリット | デメリット |
|---|---|
| いまの聴感・パッド・HP バッファの関係をほぼ維持 | 信号振幅が大きく、**耐圧の高い digipot**か、固定パッド必須 |
| PHONE / LINE の意味が現行どおり | HV 品は高い・単チャネルが多く L/R で 2 個、など |

### C. PHONE と LINE で別減衰

| メリット | デメリット |
|---|---|
| 用途ごとに最適レベル | I²C アドレス・部品・UI が倍 |
| 現行デュアル 2 個の役割分担を維持 | エンコーダー操作が複雑 |

**確定寄り:** **B + C**（Amp 後で、LINE と HP は別減衰・別エンコーダー）。  
ヘッドホンの思想は現行どおり **「HeadphoneBuffer に入れる量を絞る」**（バッファ後にポットを置かない）。LINE も Amp 出力バス上で別 digipot。  
固定 −20 dB パッドは HP 側に残す前提（耐圧・常用域のため）。品種は次項。

信号のイメージ:

```text
[選ばれた Amp 出力]
        ├─（測定タップ：音量非連動のまま可）
        ├─ HP用 digipot ← ENC_HP  ─(-20dB pad)─► HeadphoneBuffer → PHONE
        └─ LINE用 digipot ← ENC_LINE ───────────► LINE OUT

同じ Pico がさらに:
  ・出力先（PHONE / LINE / MUTE … 現行 SW101 相当）
  ・CH 選択 + その系統の電源リレー（GPIO拡張経由）
```

## 3. 音量 digipot 品種

**絞り込み:** **B（MCP45HV51）** か **C（PGA2311 系）**。DS1882 等の ±7 V 級は LINE 無パッドと相性が悪く見送り。

### B. MCP45HV51（HV 単ch・I²C）

| | |
|---|---|
| 構成 | HP L/R + LINE L/R = **4 個**（単ch） |
| 耐圧 | ±15 V 級で Amp 後にそのまま |
| 段 | 256、**リニア** → ファームで dB カーブ |
| バス | **I²C**（GPIO 拡張・OLED と同系統） |
| 向く | I²C 一本・部品入手・設計の素直さ |

### C. PGA2311 / LM1972（ステレオ音量 IC）

| | |
|---|---|
| 構成 | HP 用 1 + LINE 用 1 = **2 個**（ステレオ） |
| 耐圧 | ±15 V 系で実績 |
| 段 | **0.5 dB**（PGA2311）。RV に近い聴感 |
| バス | **SPI**（CS 2 本 + MOSI/MISO/SCK） |
| 向く | 音量の音質・段数・L/R 連動 |

### B vs C（決めどころ）

| | **B MCP45HV51** | **C PGA2311** |
|---|---|---|
| インタフェース | I²C のまま | SPI が増える |
| 部品数 | 4 | 2 |
| 音（音量） | リニア＋ソフト補正 | オーディオ向けが強い |
| ファーム | 4 アドレス管理 + カーブ | SPI ドライバ + 0.5 dB |
| 方針との一致 | **I²C 集約**と一致 | 音質優先ならこちら |

**トーン（確定）: T1 PT2314 系**

| | |
|---|---|
| 配置 | **CH 選択後・Amp 前**（小信号） |
| 操作 | ENC_BASS / ENC_TREBLE → I²C。制御 OLED に dB |
| レンジ | おおよそ ±14 dB、2 dB 段 |
| 注意 | TDA7313 系の **1 バイトコマンド** I²C。音量機能は 0 dB 固定で Bass/Treble のみ使う |

```text
CH 選択 ──► [PT2314 Bass/Treble] ──► Amp ──► digipot(HP/LINE) ──► 出力段
                 ▲ ENC_BASS / ENC_TREBLE
```

## 4. 操作 Pico の置き場と役割分担

| 案 | 操作 Pico が持つもの | リレー盤 |
|---|---|---|
| **P1** | ENC / OLED / digipot /（必要なら）リレー GPIO | 端子台＋ULN＋リレーのみ |
| **P2** | ENC / OLED / digipot / I²C マスター | 子 MCU or GPIO 拡張でラッチング駆動 |
| **P3** | 現行どおりリレー盤上の Pico（UI ヘッダだけ外出し） | 一体 |

計測 Pico 2 はどれでも触らない。

**GPIO メモ（現行 Controll）:** リレーコイルで GPIO0–19 を使用済み。I²C（OLED）と ENC で残りほぼ埋まり、**空きは GPIO28 程度**。だから digipot は **I²C 相乗りが前提**で、SPI digipot を足すなら基板分割か子 MCU 化が先。

## 5. エンコーダー操作の意味

| 案 | 内容 | メリデメ |
|---|---|---|
| **E1** | 1 つの ENC をモード切替で使い回す | ハード最少。誤操作しやすい |
| **E2** | **ENC_HP / ENC_LINE は音量専用**。CH・出力先・電源は別 UI（ENC 追加 / SW / OLED+SW） | 誤操作が減る。今回の「LINE と HP の ENC」に一致 |
| **E3** | ENC=CH、音量はポットのまま | 今回の動機から外れる |

**確定:** **ENC×6**（CH / HP / LINE / DEST / BASS / TREBLE）。CH は回して変更・押して確定。Bass/Treble は独立 ENC＋制御 OLED。パワースイッチに **12V LED**。

## 6. 新ディレクトリに何をコピーして起こすか

| 案 | 範囲 | メリデメ |
|---|---|---|
| **D1** | 操作系だけ（リレー盤 ± 操作/音量） | 早い。Amp/電源は `Audio/` 参照のまま箱で繋ぐ |
| **D2** | D1 + Amp/HP/電源もコピーして親シートまで | 単体でネットリストが閉じる。メンテ二重化 |
| **D3** | 空のプロジェクト枠 + シンボルだけ先 | 最速だが判断が終わるまで中身が空 |

いまは **D3 → 判断後に D1** が無難（このリポジトリは `Audio/` が生きている）。

## 7. GND

計測側の型を踏襲する前提で、操作系だけ決める。

| 案 | 内容 |
|---|---|
| **G1** | リレー盤 = 接点側は各 Amp の `A_GND` 世界、コイル/ULN = `D_GND`（または `CTRL_GND`）。結合は NetTie 一点 |
| **G2** | digipot アナログ端子 = `A_GND`、ロジック = 操作 Pico の `D_GND`。同様に一点 |

基板を B 分割するほど G1/G2 を基板境界に寄せやすい。
