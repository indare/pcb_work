## `ampbank_switch_pop.cir` — 出力カップリングの置き場所

`AmpBank` でアンプ出力をバスへ繋ぐとき、カップリングコンデンサをアナログスイッチの
**前**に置くか**後**に置くか。後に置けば全 ch 共通の1組で済むが、前に置くと ch 毎に要る。

オペアンプの DC オフセット（NE5532 代表 ±3 mV）を持つ 2 台の間で切り替え、
バスに出る段差を測る。信号を載せると段差が振幅に埋もれるので DC のみで観測する。

| | バスに出る段差 |
|---|---|
| 案A: カップリングが SW の前 | **≈ 0 V**（4e-18） |
| 案B: カップリングが SW の後（共通1組） | **−6.0 mV**、150 ms かけて減衰 |

6 mV は信号 7 V に対し −61 dB でアンプの雑音フロアの約3000倍。低周波過渡なので
「ボツッ」と聴こえる。**案A（ch 毎に前置き）を採用。**

> **⚠ このデッキの限界（2026-09-02 追記）:** 案A側の `a1s`（`Ca1` とスイッチの間）には
> 漏れ電流源を入れていない。そのため「前置きにすると今度はカップリング C の右極板が
> 非選択中に浮く」という論点をこのデッキは検証していない。実際その節点は
> `ampbank_input_pulldown.cir` が扱ったのと同じ構造で、**出力側にも 220 kΩ の
> プルダウンが要る**（2026-09-02 に追加）。2.2 µF に 0.15 nA で 68 µV/s、
> 非選択 1 分で 4 mV。ここで案B を却下した根拠の −6 mV を数分で超える。
出力カップリングを 470 µF → 2.2 µF に小さくしたことで、ch 毎に持っても
面積が 3.6 cm² に収まる（470 µF なら 24.5 cm² で不可能だった）。

## `ampbank_input_pulldown.cir` — 入力 220 kΩ プルダウンの置き場所

現行 AmpModule の入力プルダウン（`R701`/`R706` = 220 kΩ）を、スイッチの
**前**（音源側）と**後**（結合コンデンサの左極板側）のどちらに置くか。

スイッチのオフ漏れ電流（TMUX7612 の max 0.15 nA）を注入し、非選択を 5 秒続けた
あとに再接続する。

| | 非選択中の結合C左極板 | 再接続時の段差 |
|---|---|---|
| 案P: 220 kΩ が SW の**後** | **0.000033 V** | なし |
| 案Q: 220 kΩ が SW の**前** | **150 V**（浮いて漏れ電流で充電） | **−149 V** |

案Q の 150 V は理想モデルゆえの誇張（実機では ESD ダイオードや基板漏れでクランプ
される）だが、「浮いた節点が漏れ電流で充電され再接続時に放電する」機序は実在し、
数百 mV〜数 V の段差になる。**案P（SW の後ろへ移す）を採用。**

これにより 220 kΩ の役割は「ケーブル未接続時に入力を浮かせない」から
**「非選択中に結合コンデンサの左極板を 0 V に保つ」**へ変わる。10 ch すべてに必要。

## `switch_thd.py` — アナログスイッチが足す THD（2026-09-02）

「TMUX7612 は高いので DG412 で足りないか」という検討のために作った。
**`ΔRon / R_load` は THD ではない**（あれは非線形分圧の大きさの目安で、
実際の THD は `Ron(V)` 曲線の形で決まる。TI SCDA058 も同じ説明）ので、
データシートのグラフを **PDF のベクタパスから数値として抽出**し、
時系列を解いて FFT した。目視の読み取りではない。

    data/dg412_ron_curve.json     Vishay 61564 の ±15V カーブ（68点）
    data/tmux7612_ron_curve.json  TI Figure 5-4 の ±15V カーブ（151点）

### 分かったこと1: TMUX7612 の平坦領域は ±11V で終わる

| 信号範囲 | TMUX7612 | DG412 |
|---|---:|---:|
| ±6.5 V（入力側） | 0.001 Ω※ | 1.59 Ω |
| ±13 V（出力側） | **0.313 Ω** | 5.70 Ω |
| ±15 V | 6.309 Ω | 5.70 Ω |

※ グラフの分解能限界。仕様表は 0.0003 Ω。**グラフから mΩ 精度を主張しないこと。**

TI が DS 本文で「best linear performance には上下レールから 5V の headroom」と
書いているのが数値で裏付けられた（±15V 電源なら ±10V まで）。

### 分かったこと2: 出力振幅に膝がある

通し（入力SW → OpAmp×2 → 出力SW → 50kΩ）の THD、Rbias 47k:

| 出力 | TMUX7612 | DG412 |
|---|---:|---:|
| 7.07 Vrms（±10V） | **−162.8 dB** | −90.9 dB |
| 9.2 Vrms（±13V、現仕様） | −115.2 dB | −90.0 dB |
| 10.0 Vrms（±14.1V） | −88.3 dB | −91.2 dB |

**現仕様の 9.2 Vrms は TMUX7612 の性能を 47 dB 捨てている。** ±14V では DG412 に逆転される。

### 分かったこと3: DG412 は出力側で律速される

DG412 は Rbias をいくら上げても通しで −90 dB 止まり（出力側スイッチが −93 dB で律速、
しかも振幅を下げても改善しない）。**出力を理想スイッチ（機械リレー）にすると**
入力側の真の限界が見え、Rbias 220k で −113 dB、1M で −126 dB まで伸びる。

### 手法の妥当性

- **linear と PCHIP の差は 0.1 dB 以内。** cubic spline は点間でオーバーシュートして
  偽の曲率＝偽の THD を作るので使わない
- `ΔRon/R_load` の目安は実際の THD より 11〜14 dB 悲観的だった

## `switch_offiso.py` — OFF の9chから何が漏れるか（2026-09-02）

ON のスイッチの THD だけ見ていては足りない。10ch セレクタでは**非選択9chの OFF 経路**が
別の律速になりうる。`CS(off)` の比では判断できない（あれはソース対グランド容量）。
**ソース→ドレインの貫通は OISO 規格が捉えている**ので、そこから実効直列容量を逆算する。

| | OISO @100kHz (RL=50Ω) | 逆算 C_off |
|---|---:|---:|
| TMUX7612 | −105 dB | **0.18 pF** |
| TMUX4821 | −50 dB | **100.6 pF**（562倍） |

10ch を節点方程式で解いた結果（Rbias 47k / 負荷 50k / 1 ON・9 OFF）:

| 周波数 | TMUX7612 BUS漏れ | TMUX4821 BUS漏れ | TMUX4821 の特性誤差 |
|---:|---:|---:|---:|
| 1 kHz | −126 dB | −71 dB | 0.0024 dB |
| 20 kHz | −100 dB | **−46.8 dB** | **0.040 dB** |

**漏れは信号の同相コピーなので THD にはならない**（周波数特性の誤差になる）。
非選択アンプ自身の歪みが漏れてくる分は −145 dB で無視できる。
つまり OISO の差は TMUX4821 を失格にしない。

ただし **20kHz では非選択アンプの入力に −5.9 dB も漏れる**（TMUX7612 は −59.5 dB）。
高域では10台全部が信号を増幅している。害はないが「非選択chは休んでいる」は成り立たない。

## `adg1407_ron_curve.json` — ADG1407 の実測（2026-09-02）

「入力を10 DUTへ常時ブロードキャストし、出力だけ切替える」構成の検討で、ADG1407（ADI、
dual 8:1 差動マルチプレクサ、EN付き）が2 IC で10ch分の出力選択を賄える候補として浮上した。
データシート（`AudioV2/datasheets/ADI_ADG1406_1407.pdf`）の **Figure 10**（VDD=+15V/VSS=−15V
固定、TA=−40/+25/+85/+125℃の4本）をベクタパスから数値抽出した（TMUX7612/DG412と同じ手法。
目視ではない）。

**⚠ 電気的特性表の「1.6 Ω typ」はこのボードの±15V電源の値ではない。** 表の条件は
`VDD=+13.5V, VSS=−13.5V, VS=±10V`（TMUX7612で踏んだのと同じ「表の電源電圧を読み違える」罠）。
Figure 10（実電源±15V固定）から読むと:

| 温度 | Ron@VS≈0 | flatness(\|VS\|≤10V) | Ron@\|VS\|≈13V |
|---|---:|---:|---:|
| −40°C | 6.32 Ω | 0.874 Ω | 8.88 Ω |
| **+25°C(typ)** | **7.79 Ω** | **1.063 Ω** | **10.55 Ω** |
| +85°C | 9.74 Ω | 1.251 Ω | 13.08 Ω |
| +125°C | 10.70 Ω | 1.477 Ω | 14.46 Ω |

+25°C カーブを `data/adg1407_ron_curve.json` として保存し、`switch_thd.py` で通しの THD を実測
（9.2Vrms、curve-based）:

| 部品 | 入力段のみ(Rbias47k) | 出力段のみ | 入出力通し |
|---|---:|---:|---:|
| **ADG1407** | −114.3 dB | −96.1 dB | **−95.1 dB**（Rbias を上げても頭打ち＝出力側律速） |
| DG412（参考） | — | −92.9 dB | −90.0 dB |
| TMUX7612（現行） | −166.2 dB | −115.2 dB | −115.2 dB |

**ADG1407 は TMUX7612 に対し約20dB劣るが、PT2314自身の歪み（0.1%≈−60dB）は余裕で下回る。**
DG412 が却下された理由（Rbias を上げても改善しない＝出力側律速）と同じ症状が出ており、
DG412 よりは5dB良いが同じ弱点を共有する。IC 2個で済むメリットとのトレードオフ。

**この抽出の未解決点:** 同じ Figure 7（±10/12/13.5/15/16.5V の5本重ね書き）から±13.5V条件の
カーブを分離して flatness を再計算すると 2.46 Ω となり、表の「1.6 Ω typ」と約1.5倍の開きがある
（5本の重なりで色の対応付けが厚みのある推定になった可能性。x軸の実データ範囲＝供給電圧に応じた
プロット幅からの推定で色を同定したが、確信度はFigure 10単独の抽出より低い）。**Figure 10 自体
（1本のグラフに温度4本のみ、混雑が少なく色分離の曖昧さが小さい）は単独では内的整合性が高い**
（4本が物理的に妥当な単調順序＝高温ほど高Ron、を示す）ので、上表はFigure 10由来の数値として
相応の信頼度で扱ってよいが、他部品より一段低い confidence として扱うこと。

## `switch_offiso.py --broadcast` — 入力ブロードキャスト構成でのBUS合成誤差（2026-09-02）

`solve()`（既存）は「入力OFF→DUT→出力OFF」の2段OFFモデルで、旧アーキテクチャ
（入出力とも切替）向け。**入力を全DUTへ常時配信し出力だけ切替える**構成では前提が違う
——非選択9chも選択chと**同じ強さの信号**を出しているので、「弱い幽霊信号の漏れ」ではなく
「ほぼ同一信号を出す9台がCoff経由でBUSに相乗りする合成誤差」になる。`solve_broadcast()`
を追加し、非選択9chに意図的なゲイン/位相ミスマッチとDUT自身のTHDを持たせる感度分析も
できるようにした（`--broadcast --gain-pct --phase-deg --dut-thd`）。

**結果: 確認した4部品（TMUX7612/TMUX4821/ADG1407/DG507B）すべてで、BUS合成誤差は無視できる。**

| | 誤差なし・20kHz | ±1%gain/±1°phase(最悪ケース)・20kHz | DUT自身THD(-94dB)漏れ・20kHz |
|---|---:|---:|---:|
| TMUX7612 | 0.0000 dB | −0.0000 dB | −203.7 dB |
| TMUX4821 | 0.0000 dB | −0.0008 dB | −148.9 dB |
| ADG1407 | 0.0000 dB | −0.0000 dB | −190.6 dB |
| DG507B | 0.0000 dB | −0.0000 dB | −189.7 dB |

理由は単純: `Coff` がどの部品も sub-pF〜約100pF しかなく、20kHz でもインピーダンスが
（選択ch側の `Ron+47Ω` に対して）桁違いに高い。非選択chが選択chと**同じ信号**を出している
分、漏れても「相関のある信号がわずかに位相/振幅ズレて足される」だけで、独立ノイズのように
は効かない。**この構成では OFF isolation は事実上どの候補でも決め手にならない**（ON経路の
THD——`switch_thd.py`側——が支配的）。TMUX4821 だけ ±1%/±1° 感度で −0.0008dB と非ゼロだが、
これも実用上無視できる水準。

## `switch_compare.py` — 候補5部品の同条件比較（2026-09-02）

入力ブロードキャスト＋出力のみMUX構成での最終比較。条件は
**±15V電源 / ゲイン2 / 出力最大 9.2Vrms(±13Vpk) / 負荷50kΩ / Riso 47Ω / 1kHz**。

    python3 AudioV2/spice/switch_compare.py

| 部品 | IC数 | 確度 | 4.0Vrms | 7.07Vrms | 8.0Vrms | **9.2Vrms** |
|---|---:|---|---:|---:|---:|---:|
| TMUX7612 (4×SPST) | 5 | 実カーブ | −166.2 | −166.8 | −136.1 | **−115.2 dB** |
| ADG1407 (dual 8:1) | 2 | 実カーブ | −117.8 | −105.3 | −101.6 | **−96.1 dB** |
| DG507B (dual 8:1) | 2 | 実カーブ | −84.6 | −75.6 | −72.5 | **−70.3 dB** |
| MAX14753 (dual 4:1) | 3 | モデル | −158.1 | −148.5 | −146.4 | **−144.0 dB** |
| MAX14778 (dual 4:1) | 3 | モデル | −168.7 | −167.3 | −166.5 | **−165.3 dB** |

`|V|≤13V` での Ron(V) の広がり（これが歪みを決める。絶対Ronではない）:

| 部品 | Ron@0V | flatness |
|---|---:|---:|
| TMUX7612 | 1.11 Ω | 0.313 Ω |
| ADG1407 | 7.82 Ω | 2.758 Ω |
| DG507B | 139.8 Ω | 62.151 Ω |
| MAX14753 | 60.0 Ω | 0.013 Ω |
| MAX14778 | 0.84 Ω | 0.001 Ω |

**絶対 Ron は歪みをほとんど決めない。** MAX14753 は Ron 60Ω で TMUX7612 の44倍あるが、
歪みは29dB良い。50kΩ負荷では Ron 130Ω（max）でも挿入損失は −0.031dB に過ぎない。
効くのは信号振幅にわたる Ron の変動幅だけ。

**TMUX7612 の 8.0→9.2Vrms で 21dB 落ちる**のが平坦領域の膝（±11V）。
7.07Vrms なら −166.8dB で MAX14778 と並ぶ。**出力振幅を下げれば TMUX7612 は依然最強**。

### データ確度の違い（重要）

- **実カーブ**（TMUX7612 / DG412 / ADG1407 / DG507B）: データシートの Ron vs 信号電圧
  グラフをベクタパスから数値抽出。
- **モデル**（MAX14753 / MAX14778）: flatness スペックを満たす対称パラボラの仮定形状。
  MAX14753 はグラフのy軸分解能（0.0816Ω/px）が 0.03Ω の flatness を解像できず、
  MAX14778 は Ron(V) グラフ自体が存在しない。**実チップにキンクや非対称があれば外れる。**

### 手法の妥当性検証（DG507B で取れた）

DG507B のデータシートは THD **0.04% @ RL=10kΩ, 5Vrms** を公称している。
抽出カーブによる計算は 4.0Vrms/50kΩ で −84.6dB。負荷を 10k→50k にすると +14dB
効くので、公称値 −68dB は 50kΩ換算で約 −82dB に相当し、**振幅差を考えれば一致する**。
メーカー実測値と抽出＋シミュレーションが合った初めての例で、手法の裏付けになる。

## `max14753` / `max14778` の Ron(V) について（2026-09-02）

**MAX14753**: p.10「ON-RESISTANCE vs. VOUT (DUAL SUPPLIES)」はモノクロで線種違い。
色分離できないので、各水平ダッシュ群の x 範囲（=その電源条件でプロットされている
信号範囲）で同定した。

| 電源 | Ron | プロット範囲 |
|---|---:|---|
| ±35V | 55.00 Ω | −35.0 .. +34.7 V |
| ±30V | 54.91 Ω | −30.0 .. +29.7 V |
| ±20V | 54.60 Ω | −20.1 .. +19.8 V |
| ±10V | 54.40 Ω | −10.1 .. +9.8 V |

**4本とも完全にフラットで、±10V電源でもレールぎりぎりまでフラット。**
これが TMUX7612（±15V電源で±11Vから膝）との決定的な差。
なお表の flatness 0.03Ω の測定条件は **±35V電源/±20V信号**（レールまで15Vの余裕）で、
うちの ±15V/±13V ではない。グラフが「±10V電源でもレールまでフラット」を示しているので
外挿してよい、という理屈で使っている。

**MAX14778**: Ron(V) グラフが存在しない。THD+N の公称 0.003% も
**振幅条件がテーブルにもグラフにも書かれていない**（`RS=RL=1kΩ, f=20Hz to 20kHz` のみ）
ため 9.2Vrms 条件との直接比較には使えない。flatness 3mΩ（−25V≤VIN≤+25V 全域、
ICOM=−300mA）だけが手がかり。

## MAX14778 の charge-pump スプリアスと ADC エイリアス（2026-09-02）

MAX14778 は内部に3つのチャージポンプを持つ。p.9「CHARGE PUMP NOISE — SWITCH ENABLED」
（MEASURED AT BCOM, RBW=5.1kHz）をベクタ抽出したピーク:

| 周波数 | レベル |
|---:|---:|
| 35 MHz | **−74.6 dB** |
| 71 MHz | **−76.4 dB** |
| （フロア） | −101 dB |

AudioV2 の計測系は `PCM1804`、**48kHz / 256fs（SCKI=12.288MHz）マスタ**。
前段のアンチエイリアスは `R709-712 (1kΩ) + C713-716 (1.8nF C0G)` の**1次RC、fc≈88kHz**。
1次なので 35MHz で約 52dB、71MHz で約 58dB の減衰。
スプリアス −75dB を仮に dBV とすると 178µV、RC 後で約 0.45µV。
PCM1804 は FS ±2.5V・DR 約112dB なので自身の雑音フロアが約 8.9µV あり、
**最悪（帯域内へ丸ごと折り返した場合）でも ADC 雑音フロアより約26dB下**。

エイリアス先も、12.288MHz でも 64fs=3.072MHz でも 35/71MHz は整数倍から外れており
可聴帯域には落ちない（帯域内に落ちる確率は1本あたり数%程度）。

**結論: ブロッカーではない。ただし実測1回で確認する価値はある**（グラフのdB基準が
明示されていないため、上の 178µV は dBV 仮定）。

## `input_topology.py` — 入力側 A案 vs B案（2026-09-02）

入力ブロードキャスト化にあたり、バイアスの持たせ方2案を比較した。

    A案: TONE ─┬─[C]─┬─Rb(100k)─GND      B案: TONE ─[C]─┬─Rb_c(10k)─GND
               │     └─ DUT1 +in                        ├─[Rs]─ DUT1 +in
               ⋮（×10）                                  ⋮（×10）

PT2314 の負荷を同じ 10kΩ に揃えると、A案は 100k×10並列、B案は 10k単体になる。

| | A案 | B案 |
|---|---|---|
| 部品 | 20点（C×10 + R×10） | 12点（C×1 + R×1 + Rs×10）。**フィルムC×9個分の面積が浮く** |
| 入力雑音 @1kHz | **0.177 nV/√Hz** | Rs=10Ω: 0.443 / Rs=100Ω: 1.295 / Rs=1kΩ: 4.061 |
| DC オフセット | 自分の Ib のみ（他chと独立） | **全10石の Ib の合計**で決まる |
| 差し替えの影響 | その ch のみ | **全 ch の動作点が動く** |

雑音はどちらも PT2314 の出力抵抗 1.9Ω が支配的で、**開放端 √(4kTR) で
100k/220k を評価してはいけない**（それだと 40〜60nV/√Hz という2桁過大な値になる）。
B案は直列 Rs 自身の熱雑音が上乗せされるので Rs は小さいほどよい。

DC オフセットは、同じ石を10個挿す場合は両案とも同値になる（PT2314 の負荷条件で
縛られているため）。差が出るのは**混載**のとき: LT1364+NE5532+MUSES02+OPA1612+FET×6
なら B案の共通ノードは 9.6mV typ / 35.5mV max で、**LT1364 を1個抜くと全chが 6mV 動く**。

**→ A案を推す。** 出力は 47Ω+2.2µF で AC 結合されるので DC 自体に実害は無いが、
「他chに影響されない」ことがこの装置の目的そのもの。面積を優先するなら B案 + Rs≤10Ω。

## 前提と限界

- オペアンプは理想（電圧源）で置いている。GBW・スルーレート・出力インピーダンスは見ていない
- スイッチは ngspice の `SW` モデルに `Ron` と漏れ電流を与えただけ。
  チャージインジェクションと寄生容量は入っていない
- **切替時のクリック音そのもの**（チャージインジェクション由来）は別問題で、
  ここでは扱っていない。TMUX7612 の 2 pC は ADG1412 の 1/10
